# Deemix audio source

Deemix is an optional audio source, disabled by default. Configure it in
**Settings → Audio sources**, below slskd, and enable it in the source order.
It requires your own compatible Deemix server and a Deezer account entitled
to the requested quality. It does not provide a subscription or bypass one.

## Credentials and shared folders

Keep Deemix's normal per-session login mode. Do not enable single-user
mode on an unprotected server: its connect endpoint returns the shared ARL.

Mount a private file containing your Deezer ARL into Downtify, readable only
by its service account, and set `DOWNTIFY_DEEMIX_ARL_FILE` to that path.
The ARL is read only when opening a cookie session. It is never stored in
settings, returned to the browser or logged. Treat it like a password;
obtain and replace it privately, not in issues or chat. The integration
never changes Deemix's server-wide login or download settings.
The connection test does not enqueue downloads.

| Setting                       | Purpose                                                            |
| ----------------------------- | ------------------------------------------------------------------ |
| Server URL                    | Internal address of Deemix, e.g. `http://deemix:6595`              |
| Download folder inside Deemix | Usually `/downloads`                                               |
| Same folder inside Downtify   | Shared bind mount, e.g. `/deemix`; read-only is supported          |
| Quality                       | MP3 128, MP3 320 or FLAC; unsupported entitlements fail explicitly |

The shared folder is registered as an external library folder when saved.
Files stay there in Deemix's artist/album organization. Downtify preserves
their format, tags, artwork and `.lrc` sidecars without rewriting them.
Existing embedded lyrics and same-name `.lrc` files are read by the player.
No audio or lyrics are deleted, moved, or generated by this integration.

A Deezer track link selects that recording. Cross-catalog downloads require
an unambiguous exact artist/title match, matching album and duration when
provided. An ambiguous match falls through to the next enabled source.
Deemix's queue completion is followed by a file and duration/quality check.
The integration never clears, cancels or changes manual Deemix jobs.
Explicit YouTube links retain their current direct-download behavior.

This source does not automatically replace or delete an existing library
track. Library deduplication and manual audio replacement remain separate.
