# Импорт плейлистов из добавленных папок

Библиотека → Плейлисты → Импортировать плейлисты из папок сканирует настроенные дополнительные папки с музыкой на файлы M3U и M3U8 в UTF-8. Просмотрите доступные, отсутствующие и повторяющиеся записи, выберите нужные плейлисты и явно добавьте выбор. Общие файлы `playlist.m3u8` берут имя содержащей их папки, как обычно генерирует Deemix. Относительные записи разрешаются от папки плейлиста.

Импорты создают приватные редактируемые плейлисты Downtify, ссылающиеся на существующее аудио. Они никогда не изменяют исходные плейлисты или аудио, никогда не перемещают внешние файлы и никогда не импортируют все кандидаты автоматически. Повторный импорт для того же аккаунта использует уже созданный импортированный плейлист. Разные аккаунты получают независимые копии, а сталкивающимся именам добавляется суффикс. Пустые файлы остаются видимыми в предпросмотре; недоступные записи исключаются из итогового плейлиста.

Принимается только существующее аудио внутри настроенных музыкальных корней. URL и пути, выходящие за эти корни, исключаются. Изменённый источник нужно просмотреть заново. Ограничения: 2 МиБ и 20 000 строк на файл, 500 кандидатов / 100 000 просмотренных записей и 50 выбранных плейлистов на запрос. Отключённые папки и пределы сканирования показываются.
