# Ξεκινώντας

Το Downtify είναι μια web εφαρμογή που φιλοξενείς μόνος σου και κατεβάζει μουσική από το Spotify — χωρίς κλειδιά API, χωρίς λογαριασμό, χωρίς συνδρομή Premium. Όλα τρέχουν μέσα σε ένα μόνο κοντέινερ Docker.

## Τι χρειάζεσαι

- **Docker** (ή Docker Compose) — η μοναδική απαίτηση στον κεντρικό υπολογιστή
- Ένα μηχάνημα με πρόσβαση στο internet
- Έναν τόμο/φάκελο όπου θα αποθηκεύεται η μουσική σου

## Διάλεξε τρόπο εγκατάστασης

<div class="doc-cards">

- <DocIcon name="docker" /> **Docker run**

  Ο πιο γρήγορος τρόπος να ξεκινήσεις. Μία εντολή, έτοιμο σε λιγότερο από ένα λεπτό.

  [Εγκατάσταση →](installation.md)

- <DocIcon name="file-code" /> **Docker Compose**

  Προτείνεται για μόνιμες εγκαταστάσεις. Πιο εύκολο στην ενημέρωση και τη διαχείριση.

  [Docker Compose →](docker-compose.md)

- <DocIcon name="house" /> **Εγκατάσταση με ένα κλικ**

  Χρησιμοποιείς Umbrel, CasaOS ή HomeDock OS; Εγκατέστησέ το απευθείας από τα καταστήματα εφαρμογών τους.

  [Εγκατάσταση με ένα κλικ →](one-click.md)

</div>

## Επόμενα βήματα

Όταν το Downtify τρέχει, άνοιξε το [http://localhost:8000](http://localhost:8000) στον browser σου. Επικόλλησε τη διεύθυνση ενός κομματιού, άλμπουμ ή λίστας του Spotify στη γραμμή αναζήτησης και πάτησε **Λήψη**.

Εξερεύνησε την υπόλοιπη τεκμηρίωση για τις [ρυθμίσεις λήψης](../features/download-settings.md), την [παρακολούθηση λιστών](../features/playlist-monitor.md), το [ενσωματωμένο πρόγραμμα αναπαραγωγής](../features/player.md) και πολλά ακόμη.
