# Ρυθμίσεις διακομιστή

Στο **Ρυθμίσεις → Διακομιστής** βρίσκεται το πώς τρέχει ο ίδιος ο διακομιστής. Το βλέπουν μόνο οι διαχειριστές (δες [Χρήστες και σύνδεση](users.md#admins-and-users)).

## Αλλαγή θύρας

Το Downtify ακούει στη θύρα **8000**. Ένας διαχειριστής μπορεί να επιλέξει άλλη στο **Ρυθμίσεις → Διακομιστής → Θύρα** (1024–65535):

- Το **Αποθήκευση** την κρατά για την επόμενη εκκίνηση του διακομιστή.
- Το **Αποθήκευση και επανεκκίνηση** επανεκκινεί αμέσως τον διακομιστή σε αυτήν. Οι λήψεις που τρέχουν σταματούν, και οι σελίδες και οι εφαρμογές επανασυνδέονται. Μια σελίδα ανοιγμένη στη διεύθυνση του ίδιου του διακομιστή (π.χ. `http://nas:8000`) περιμένει τον διακομιστή και ανοίγει μόνη της τη νέα διεύθυνση· παραμένεις συνδεδεμένος.

Όταν η θύρα προέρχεται από τη μεταβλητή περιβάλλοντος `DOWNTIFY_PORT` (ή `PORT`) ή από το `--port` στη γραμμή εντολών — που υπερισχύουν πάντα —, το πεδίο δείχνει τη θύρα που χρησιμοποιείται αλλά δεν επεξεργάζεται, και η σελίδα λέει ποιο την ορίζει. Αφαίρεσέ το (και επανεκκίνησε) για να επιλέξεις τη θύρα από τις Ρυθμίσεις.

::: warning Το δίκτυο bridge του Docker αντιστοιχίζει σταθερή θύρα
Στην προεπιλεγμένη εγκατάσταση Docker (`ports: - '8000:8000'`), η θύρα του κοντέινερ πρέπει να ταιριάζει με την αντιστοίχιση. Αφού την αλλάξεις στις Ρυθμίσεις, άλλαξε την αντιστοίχιση στη νέα θύρα (`'9000:9000'`) και ξαναδημιούργησε το κοντέινερ — ή τρέξε με `network_mode: host`. Διαφορετικά το Downtify δεν είναι προσβάσιμο. Για να μπεις ξανά, όρισε το `DOWNTIFY_PORT` στην παλιά θύρα: υπερισχύει των Ρυθμίσεων.
:::

Πίσω από [reverse proxy](mobile-apps.md#behind-a-reverse-proxy), στρέψε και τον proxy στη νέα θύρα. Οι [συνδεδεμένες εφαρμογές](mobile-apps.md) χρησιμοποιούν τη διεύθυνση που τους δόθηκε: μετά από αλλαγή θύρας, βάλε τη νέα στην εφαρμογή.
