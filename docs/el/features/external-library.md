# Υπάρχοντες φάκελοι μουσικής

Η Βιβλιοθήκη του Downtify χτίζεται από τα αρχεία που κατέβασε — συν τους **πρόσθετους φακέλους** που του υποδεικνύεις. Αυτοί οι φάκελοι δεν αντιγράφονται στο `/downloads`. Το Downtify διαβάζει τα tags κάθε αρχείου (τίτλος, καλλιτέχνης, άλμπουμ, αριθμός κομματιού, έτος), παραλείπει τα τραγούδια που έχεις ήδη και κατατάσσει τα υπόλοιπα κάτω από τον αντίστοιχο καλλιτέχνη στη Βιβλιοθήκη και στο player.

## Προσθήκη φακέλων

1. Προσάρτησε τον φάκελο του κεντρικού υπολογιστή στο κοντέινερ (Docker). Η διαδρομή που πληκτρολογείς στις Ρυθμίσεις είναι αυτή **μέσα στο κοντέινερ**, ο ίδιος κανόνας με τον [φάκελο λήψεων του slskd](slskd-navidrome.md).
2. Άνοιξε **Ρυθμίσεις → Βιβλιοθήκη**.
3. Στο **Υπάρχοντες φάκελοι μουσικής**, πρόσθεσε μία ή περισσότερες διαδρομές (π.χ. `/music/collection`). Το πεδίο προτείνει καταλόγους καθώς πληκτρολογείς.
4. Πάτα **Αποθήκευση** αν θέλεις να τις κρατήσεις χωρίς ακόμη συγχρονισμό, ή **Συγχρονισμός φακέλων** — αυτό αποθηκεύει τη λίστα και σαρώνει αμέσως.

```yaml
services:
  downtify:
    volumes:
      - ./downloads:/downloads
      - /path/on/host/to/mp3s:/music/collection
      - downtify_data:/data
```

Τότε ο φάκελος στις Ρυθμίσεις είναι `/music/collection`.

::: warning Τα αρχεία μένουν εκεί που είναι
Ο συγχρονισμός δεν αντιγράφει αρχεία στο `/downloads`. Όταν ο φάκελος είναι εγγράψιμος, **γράφει** σε αυτά τα αρχεία τα ίδια πρόσθετα που θα έγραφε μια λήψη: στίχους (και ένα συνοδευτικό `.lrc` — δίπλα στο αρχείο ή στον φάκελο που επέλεξες στις Ρυθμίσεις), ένα εξώφυλλο αν το αρχείο δεν έχει, και το είδος από το iTunes όταν μπορεί. Ένας μεταγενέστερος συγχρονισμός γράφει ένα συνοδευτικό αρχείο που λείπει ακόμη κι αν οι στίχοι υπάρχουν ήδη στα tags, και **μετακινεί** ένα υπάρχον `.lrc` στη θέση που έχει επιλεγεί τώρα στις Ρυθμίσεις όταν εκείνο το αρχείο προέλευσης είναι εγγράψιμο. Η διαγραφή ενός κομματιού από τη Βιβλιοθήκη εξακολουθεί να διαγράφει εκείνο το αρχείο στον δίσκο.
:::

::: tip Προσαρτήσεις μόνο για ανάγνωση
Προσάρτησε τη συλλογή με `:ro` αν δεν θέλεις το Downtify να ξαναγράφει τα MP3. Ο συγχρονισμός τα ευρετηριάζει ούτως ή άλλως. Βάλε τα αρχεία `.lrc` στον [φάκελο στίχων](lyrics.md#sidecar-lrc-file) (απενεργοποίησε το **Κράτα το .lrc δίπλα στο αρχείο ήχου**). Τα εξώφυλλα που λείπουν αποθηκεύονται στο `/data/cover_cache` (το endpoint εξωφύλλων της Βιβλιοθήκης), όχι στο MP3. Το είδος του iTunes αποθηκεύεται στη βάση μεταδεδομένων της βιβλιοθήκης του Downtify, όχι στο αρχείο. Ένα `.lrc` που βρίσκεται ήδη δίπλα σε αρχείο μόνο για ανάγνωση **αντιγράφεται** στον φάκελο στίχων και μένει στη θέση του.
:::

## Τι κάνει ο συγχρονισμός

1. Διατρέχει κάθε ρυθμισμένο φάκελο για αναπαραγώγιμο ήχο (οι ίδιες μορφές με την υπόλοιπη βιβλιοθήκη: MP3, M4A, FLAC, OGG, WAV, AAC, OPUS).
2. Διαβάζει τα ενσωματωμένα tags. Ένα αρχείο χωρίς τίτλο/καλλιτέχνη καταφεύγει στο `Καλλιτέχνης - Τίτλος` του ονόματος αρχείου, όπως οι άλλες γραμμές της βιβλιοθήκης.
3. **Παραλείπει** ένα αρχείο όταν η βιβλιοθήκη έχει ήδη εκείνο το τραγούδι (ίδιος καλλιτέχνης + τίτλος και διάρκεια με διαφορά λίγων δευτερολέπτων όταν είναι γνωστές και οι δύο) — είτε το κατέβασε το Downtify είτε προήλθε από άλλον πρόσθετο φάκελο.
4. **Αντιστοιχίζει καλλιτέχνες** με ονόματα που υπάρχουν ήδη στη βιβλιοθήκη (το `The Beatles` και το `Beatles` γίνονται ένας καλλιτέχνης). Ονόματα που δεν ταιριάζουν με γνωστό καλλιτέχνη εμφανίζονται ως νέος καλλιτέχνης. Οι νέοι καλλιτέχνες μπαίνουν στην ουρά για την ίδια συμπλήρωση προφίλ (φωτογραφία/βιογραφικό όταν αυτές οι ρυθμίσεις είναι ενεργές) με μια ολοκληρωμένη λήψη.
5. **Βάζει tags όπως μια λήψη** όταν ο φάκελος είναι εγγράψιμος. Για κάθε εισαγόμενο κομμάτι χρησιμοποιεί τους ίδιους παρόχους στίχων, την ίδια αναζήτηση εξωφύλλου (μόνο όταν το αρχείο δεν έχει εικόνα) και την ίδια αναζήτηση είδους iTunes που θα χρησιμοποιούσε μια λήψη. Οι στίχοι μπαίνουν στο αρχείο· ένα συνοδευτικό `.lrc` γράφεται δίπλα στον ήχο ή στον [φάκελο στίχων](lyrics.md#sidecar-lrc-file) που επέλεξες στις Ρυθμίσεις. Το εξώφυλλο και το είδος ακολουθούν τις [Ρυθμίσεις λήψης](download-settings.md) (`download_cover_art`, `download_lyrics`). Σε προσάρτηση **μόνο για ανάγνωση** το MP3 δεν ξαναγράφεται: ένα εξώφυλλο που λείπει αποθηκεύεται στο `/data/cover_cache`, το είδος αποθηκεύεται στον κατάλογο της βιβλιοθήκης και τα αρχεία `.lrc` πηγαίνουν στον φάκελο στίχων αν έχεις επιλέξει έναν. Οι αναζητήσεις τρέχουν σε παρτίδες μεγέθους **Ταυτόχρονες λήψεις**· μια **Παύση μεταξύ συγχρονισμού** στο Ρυθμίσεις → Λήψεις και αρχεία περιμένει ανάμεσα στις παρτίδες ώστε οι μεγάλοι φάκελοι να μην χτυπούν τα όρια ρυθμού των παρόχων.
6. Ακυρώνει την κρυφή μνήμη διαδρομών της βιβλιοθήκης ώστε η σελίδα της Βιβλιοθήκης και το player να βλέπουν το αποτέλεσμα χωρίς να περιμένουν το συνηθισμένο σύντομο TTL σάρωσης.

Ο συγχρονισμός τρέχει **στο παρασκήνιο**. Μπορείς να φύγεις από τις Ρυθμίσεις· αν επιστρέψεις όσο ακόμη δουλεύει, φαίνεται ότι συγχρονίζει. Όταν τελειώσει, οι Ρυθμίσεις δείχνουν το **τελευταίο αρχείο καταγραφής συγχρονισμού** (εισήχθησαν / διπλότυπα / σφάλματα, μαζί με σημειώσεις για στίχους/εξώφυλλα).

Τρέξε ξανά το **Συγχρονισμός φακέλων** αφού ρίξεις κι άλλα αρχεία σε αυτούς τους φακέλους. Η αποθήκευση της λίστας φακέλων χωρίς συγχρονισμό τούς περιλαμβάνει επίσης στην επόμενη σάρωση της βιβλιοθήκης (περίπου ένα λεπτό, ή στην επόμενη λήψη/διαγραφή).

Η αφαίρεση ενός φακέλου από τη λίστα τον **αποσυνδέει**: εκείνα τα κομμάτια φεύγουν από τη Βιβλιοθήκη και το player, και τα πρόσθετα που έφτιαξε το Downtify (συνοδευτικά `.lrc`, εξώφυλλα στην κρυφή μνήμη) διαγράφονται. Τα αρχεία ήχου στον δίσκο μένουν στη θέση τους.

Οι φάκελοι που δεν υπάρχουν ή δεν είναι αναγνώσιμοι αναφέρονται μετά τον συγχρονισμό· οι υπόλοιποι σαρώνονται κανονικά.

## Διαδρομές βιβλιοθήκης

Τα αρχεία πρόσθετων φακέλων χρησιμοποιούν εικονική διαδρομή `ext/<id>/…` (το id είναι hash της διαδρομής του φακέλου, ώστε η λίστα να μπορεί να αναδιατάσσεται). Το player και το `GET /media/…` χρησιμοποιούν αυτή τη διαδρομή, όπως το `slskd/…` για αρχεία Soulseek που αφήνονται στη θέση τους.

Ένας φάκελος που βρίσκεται ήδη **μέσα** στο `/downloads` (ή στον φάκελο πηγής του slskd) αγνοείται εδώ — αυτό το δέντρο είναι ήδη η βιβλιοθήκη.

## API

| Μέθοδος | Διαδρομή                      | Περιγραφή                                                                        |
| ------ | ----------------------------- | -------------------------------------------------------------------------------- |
| `POST` | `/api/library/external/sync`  | Ξεκινά σάρωση στο παρασκήνιο. Προαιρετικό σώμα `{folders: ["/path", …]}` αποθηκεύεται πρώτα. |
| `GET`  | `/api/library/external/sync`  | Εργασία σε εξέλιξη ή το τελευταίο ολοκληρωμένο αρχείο καταγραφής.                |
| `POST` | `/api/library/external/unmap` | Αφαιρεί έναν φάκελο από τη βιβλιοθήκη χωρίς να διαγράψει τον ήχο.                |

Δες την [αναφορά API](../api-reference.md#post-apilibraryexternalsync) για τη μορφή της απάντησης.

## Κύριος φάκελος βιβλιοθήκης

Διάλεξε **Ρυθμίσεις → Βιβλιοθήκη → Primary library folder** για να προτιμήσεις έναν από τους
καταχωρισμένους εξωτερικούς φακέλους. Η προεπιλογή διατηρεί την υπάρχουσα συμπεριφορά.
Απαιτούνται ταιριαστός καλλιτέχνης, πλήρης τίτλος (μαζί με την έκδοση) και άλμπουμ·
τα άγνωστα μεταδεδομένα δεν κρύβουν άλλο αρχείο. Μια επιλεγμένη πηγή μπορεί να αντιπροσωπεύει
μια ηχογράφηση της οποίας το άλλο αντίγραφο περιλαμβάνει εισαγωγές ή κατακλείδες κλιπ.

Πρόκειται για προτίμηση καταχώρισης, όχι για μετάβαση. Τα αρχεία πηγής, οι αποθηκευμένες διαδρομές λιστών,
η ιδιοκτησία, τα αγαπημένα και οι κανόνες ορατότητας δεν ξαναγράφονται ούτε διαγράφονται.
Τα σήματα λιστών συνδυάζονται στον αντιπρόσωπο που εμφανίζεται· οι λίστες που έχουν αποθηκευτεί ρητά
παίζουν ακόμη τις αρχικές τους διαδρομές. Διαφορετικά άλμπουμ και εκδόσεις στον
επιλεγμένο φάκελο μένουν ξεχωριστά. Ένας κενός ή μη διαθέσιμος φάκελος επιστρέφει στην υπόλοιπη βιβλιοθήκη.
Η αφαίρεσή του επαναφέρει την προτίμηση.
