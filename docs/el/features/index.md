# Λειτουργίες

Το Downtify καλύπτει ό,τι χρειάζεσαι για να χτίσεις και να συντηρήσεις μια τοπική μουσική βιβλιοθήκη από το Spotify.

## Επισκόπηση

| Λειτουργία | Τι κάνει |
|---------|-------------|
| [Λίστες επιτυχιών](charts.md) | Περιηγήσου στην παγκόσμια λίστα του Deezer και κατέβασε ό,τι είναι τάση |
| [Παρόμοια](similar.md) | Όρισε έναν καλλιτέχνη ή ένα κομμάτι· το YouTube Music απαντά με παρόμοια κομμάτια που παίζουν ολόκληρα και κατεβαίνουν, χωρίς κλειδί |
| [Εξερευνητής](finder.md) | Αναζήτησε στο Deezer και μετά περιηγήσου σε έναν καλλιτέχνη, τα άλμπουμ του και τα κομμάτια κάθε άλμπουμ σε στήλες |
| [Ρυθμίσεις λήψης](download-settings.md) | Επίλεξε μορφή (MP3/FLAC/M4A/OGG/OPUS), bitrate, ταυτόχρονες λήψεις και παύση μεταξύ λήψεων |
| [Ουρά λήψεων](download-queue.md) | Βάλε τις λήψεις σε παύση πριν αλλάξεις ρυθμίσεις ή κάνεις ενημέρωση: όσες τρέχουν ολοκληρώνονται, καμία νέα δεν ξεκινά και τα τραγούδια σε αναμονή μένουν μετά από επανεκκίνηση |
| [Παρακολούθηση λιστών](playlist-monitor.md) | Παρακολούθησε λίστες και καλλιτέχνες Spotify ή YouTube Music και κατέβασε αυτόματα νέα κομμάτια και κυκλοφορίες |
| [Κρυμμένα τραγούδια λίστας](hidden-playlist-songs.md) | Βγάλτε από μια κατεβασμένη ή παρακολουθούμενη λίστα τα τραγούδια που δεν θέλετε και κρατήστε τα εκτός· τα αρχεία μένουν στη βιβλιοθήκη |
| [Δημοφιλέστερα τραγούδια](top-songs.md) | Επικόλλησε τον σύνδεσμο ενός καλλιτέχνη και κατέβασε τα δημοφιλέστερα τραγούδια του, προαιρετικά ως λίστα |
| [Εισαγωγή βιβλιοθήκης (CSV)](library-import.md) | Εισήγαγε μια εξαγωγή βιβλιοθήκης από Soundiiz, TuneMyMusic ή Exportify και βάλε τα πάντα στην ουρά |
| [Ενσωματωμένο πρόγραμμα αναπαραγωγής](player.md) | Παίξε τη βιβλιοθήκη σου στον browser: διαχείριση ουράς, συγχρονισμένοι στίχοι, χρονοδιακόπτης ύπνου, πληκτρολόγιο και πλήκτρα πολυμέσων |
| [Κανονικοποίηση έντασης](playback-normalization.md) | Όλα τα τραγούδια σε παρόμοια ένταση, με μετρήσεις που ξεκινά ένας διαχειριστής· τα αρχεία ήχου δεν αλλάζουν ποτέ |
| [Αγαπημένα τραγούδια](liked-songs.md) | Βάλε καρδιά σε ένα τραγούδι· μια λίστα με όσα έχεις αγαπήσει εμφανίζεται μόνη της |
| [Podcasts](podcasts.md) | Εγγράψου σε μια εκπομπή με ροή RSS, σύνδεσμο Spotify ή όνομα· τα νέα επεισόδια κατεβαίνουν και επισημαίνονται μόνα τους |
| [Χρήστες και σύνδεση](users.md) | Σύνδεση με όνομα χρήστη και κωδικό (`admin` / `downtify` σε νέο διακομιστή), λογαριασμοί διαχειριστή και απλού χρήστη, προτιμήσεις ανά χρήστη και αρχείο δραστηριότητας με συνδέσεις και τι ακούει ο καθένας |
| [Σήμανση ακατάλληλου περιεχομένου](explicit-marker.md) | Το «E» δίπλα σε τραγούδια με ακατάλληλους στίχους — στην αναζήτηση, στη Βιβλιοθήκη και στο player — και στα tags του αρχείου |
| [Αντικατάσταση ήχου](replace-audio.md) | Λάθος τραγούδι ή έκδοση; Διάλεξε τη σωστή στο YouTube Music ή στο YouTube· το αρχείο κρατά όνομα, tags και λίστες |
| [Ρυθμίσεις διακομιστή](server.md) | Η θύρα στην οποία ακούει το Downtify, αλλάζει από τις Ρυθμίσεις (διαχειριστές), με άμεση επανεκκίνηση αν θέλεις |
| [Εφαρμογές κινητού](mobile-apps.md) | Σύνδεσε εφαρμογές κινητού με QR code και μετάδωσε σε αυτές τη βιβλιοθήκη (αρχική ή μετατρεμμένη) |
| [Ανακάλυψη](discover.md) | Καλλιτέχνες, άλμπουμ και λίστες που δεν έχεις ακόμη, προτεινόμενα από τη βιβλιοθήκη, τα αγαπημένα και όσα ακούς· κρύψε όσα δεν θέλεις |
| [slskd και Navidrome](slskd-navidrome.md) | Λήψη από το Soulseek μέσω slskd, καθρέφτισμα λιστών στο Navidrome και παρακολούθηση λήψεων λιστών |
| [Κατάλογος βιβλιοθήκης και συγχρονισμός διαδρομών](library-catalog.md) | Πώς το Downtify παρακολουθεί αρχεία και λίστες της βιβλιοθήκης, λίστες που δημιουργείς στη Βιβλιοθήκη και διόρθωση διαδρομών μετά τη μετακίνηση αρχείων |
| [Υπάρχοντες φάκελοι μουσικής](external-library.md) | Δείξε στο Downtify φακέλους ήχου που ήδη έχεις· ο συγχρονισμός διαβάζει tags, αντιστοιχίζει καλλιτέχνες και παραλείπει τραγούδια που υπάρχουν ήδη στη βιβλιοθήκη |
| [Αναβάθμιση βιβλιοθήκης](library-upgrade.md) | Σάρωσε μουσική που έχεις ήδη κατεβάσει και επισκεύασε μικρά εξώφυλλα, στίχους που λείπουν και ελλιπή tags |
| [Χώρος και χρήση](storage-usage.md) | Δες πόσο μεγάλη είναι η βιβλιοθήκη και πόσο γρήγορα μεγαλώνει, από ποια πηγή ήρθε κάθε μέρος της, πώς κατέληξαν οι λήψεις και πόσο χώρο πιάνουν τα διπλότυπα, τα αντίγραφα του slskd και τα απομεινάρια |
| [Εξαγωγή M3U](m3u-export.md) | Αυτόματα παραγόμενα αρχεία λιστών για Jellyfin, Navidrome, Plex και κάθε εφαρμογή πολυμέσων |
| [Εξώφυλλα λιστών](playlist-cover-art.md) | Αποθήκευσε την εικόνα εξωφύλλου της λίστας δίπλα στο αρχείο M3U της |
| [Φωτογραφία, banner και βιογραφικό καλλιτέχνη](artist-images.md) | Διάλεξε πραγματική φωτογραφία και banner για έναν καλλιτέχνη από YouTube Music, Deezer, Spotify ή δικό σου ανέβασμα, και φέρε βιογραφικό, καταγωγή και συνδέσμους από Apple Music και Deezer, αυτόματα ή κατά παραγγελία |
| [Στηρίξτε τον καλλιτέχνη](support-artists.md) | Βρείτε πού να αγοράσετε ένα τραγούδι, άλμπουμ ή καλλιτέχνη: το προϊόν στο iTunes Store με την τιμή του, Bandcamp και Qobuz, ο ιστότοπος του καλλιτέχνη |
| [Οργάνωση αρχείων](file-organization.md) | Επίπεδη διάταξη ή υποφάκελοι ανά καλλιτέχνη |
| [Στίχοι](lyrics.md) | Αυτόματη λήψη και ενσωμάτωση στίχων (απλών και συγχρονισμένων)· `.lrc` δίπλα στο αρχείο ή σε φάκελο της επιλογής σου |
| [Cookies του YouTube](youtube-cookies.md) | Ανέβασε ένα `cookies.txt` από τη web διεπαφή για λήψη ακατάλληλων/περιορισμένης ηλικίας κομματιών |
| [Διεθνοποίηση](internationalization.md) | Αγγλικά συν εννέα ακόμη γλώσσες έτοιμες, και η τεκμηρίωση σε όλες |
| [Ειδοποιήσεις ενημέρωσης](updates.md) | Ωριαίος έλεγχος στα GitHub Releases· μια ειδοποίηση εμφανίζεται στην πλαϊνή στήλη όταν βγει νεότερη έκδοση |

## Τύποι εισόδου

Το Downtify δέχεται διάφορους τύπους εισόδου στη γραμμή αναζήτησης:

| Είσοδος | Παράδειγμα |
|-------|---------|
| URL κομματιού, άλμπουμ, λίστας ή καλλιτέχνη Spotify | `https://open.spotify.com/track/…` |
| URL YouTube / YouTube Music | `https://www.youtube.com/watch?v=…` |
| URL λίστας ή καλλιτέχνη YouTube Music | `https://music.youtube.com/playlist?list=…` |
| URL κομματιού, άλμπουμ, λίστας ή καλλιτέχνη Deezer | `https://www.deezer.com/track/…` |
| Αναζήτηση ελεύθερου κειμένου | `The Night Owls Do I Still Recall` |

Οι αναζητήσεις ελεύθερου κειμένου πηγαίνουν απευθείας στο YouTube Music — δεν χρειάζεται σύνδεσμος Spotify.
