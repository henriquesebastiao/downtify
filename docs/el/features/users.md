# Χρήστες και σύνδεση

Όποιος χρησιμοποιεί το Downtify συνδέεται με **όνομα χρήστη και κωδικό**, και κάθε άτομο μπορεί να έχει δικό του λογαριασμό. Ένας admin διαχειρίζεται τους λογαριασμούς στις **Ρυθμίσεις → Χρήστες** και βλέπει τι κάνει ο καθένας στις **Ρυθμίσεις → Δραστηριότητα**.

## Πρώτη σύνδεση

Ένας νέος διακομιστής έχει έναν λογαριασμό:

| Όνομα χρήστη | Κωδικός |
|----------|----------|
| `admin` | `downtify` |

Συνδέσου με αυτόν και **άλλαξε τον κωδικό** στις **Ρυθμίσεις → Γενικά → Λογαριασμός**: όποιος ξέρει το Downtify ξέρει τον προεπιλεγμένο κωδικό. Μέχρι να το κάνεις, το Downtify σου το υπενθυμίζει μετά τη σύνδεση και δείχνει προειδοποίηση στις Ρυθμίσεις.

::: warning Άλλαξε τον προεπιλεγμένο κωδικό πριν εκθέσεις τον διακομιστή
Ο προεπιλεγμένος κωδικός δεν προστατεύει τίποτα. Άλλαξέ τον πριν κάνεις το Downtify προσβάσιμο από έξω από το οικιακό σου δίκτυο — και χρησιμοποίησε HTTPS εκεί (δες [Πίσω από reverse proxy](mobile-apps.md#behind-a-reverse-proxy)).
:::

### Αναβάθμιση από παλαιότερη έκδοση

Ένας διακομιστής που έτρεχε έκδοση χωρίς λογαριασμούς παίρνει τον ίδιο λογαριασμό `admin`, και η σελίδα σύνδεσης το λέει μία φορά — μέχρι να συνδεθεί ένας admin — με το όνομα χρήστη και τον κωδικό που πρέπει να χρησιμοποιηθούν:

- Αν είχες ορίσει κωδικό στην παλιά επιλογή **Απαίτηση σύνδεσης**, αυτός ο κωδικός συνεχίζει να ισχύει για τον `admin`.
- Διαφορετικά είναι `downtify`.

Τα προγράμματα περιήγησης που ήταν συνδεδεμένα πριν την αναβάθμιση συνδέονται ξανά. Τα κινητά που είχαν συζευχθεί πριν παραμένουν συζευγμένα και πλέον ανήκουν στον `admin`.

## Admin και χρήστες

| | Admin | Χρήστης |
|---|---|---|
| Ακρόαση, αναζήτηση, λήψη, «μου αρέσει», Ανακάλυψη, Λίστες επιτυχιών, Finder, podcast | ✓ | ✓ |
| Σύζευξη εφαρμογών κινητού (στον δικό τους λογαριασμό) | ✓ | ✓ |
| Ρυθμίσεις → Γενικά (ο δικός τους λογαριασμός και προτιμήσεις), Εφαρμογές, Σχετικά | ✓ | ✓ |
| Κάθε άλλη ρύθμιση (πηγές, αρχεία, tags, Navidrome, βιβλιοθήκη, διακομιστής), μετονομασία του διακομιστή | ✓ | |
| [Κοινοποίηση των δικών τους λιστών](#sharing-playlists) (μόνο προβολή), ακολούθηση δημόσιων, αποθήκευση αντιγράφων | ✓ | ✓ (όταν το επιτρέπει ο admin) |
| Διαγραφή αρχείων και λιστών (ένας χρήστης μόνο [όσα κατέβασε](#deleting-songs) και τις δικές του λίστες), διαχείριση των δικών του παρακολουθήσεων λιστών και συνδρομών podcast, αντικατάσταση του ήχου ενός κομματιού, επεξεργασία φωτογραφιών καλλιτεχνών | ✓ | ✓ (μόνο τα δικά του) |
| [Απόκρυψη τραγουδιών, άλμπουμ και καλλιτεχνών από τους χρήστες](#hiding-from-users) | ✓ | |
| Διαχείριση χρηστών, προβολή του αρχείου δραστηριότητας | ✓ | |

Ένας χρήστης που δοκιμάζει κάτι που χρειάζεται admin παίρνει ένα μήνυμα που το λέει.

## Η βιβλιοθήκη σου

Η βιβλιοθήκη είναι κοινή: κάθε λογαριασμός βλέπει κάθε τραγούδι που κατέβασε οποιοσδήποτε — στη Βιβλιοθήκη, στα αποτελέσματα αναζήτησης που σημειώνονται ως κατεβασμένα και σε ένα συζευγμένο κινητό. Τα αρχεία δεν αποθηκεύονται ποτέ δύο φορές: όταν δύο άτομα κατεβάζουν το ίδιο τραγούδι, καταλήγει στον δίσκο μία φορά, με έναν ιδιοκτήτη το καθένα.

Τα «μου αρέσει», οι λίστες (κατεβασμένες και δημιουργημένες στη Βιβλιοθήκη) και η ουρά λήψεων μένουν δικά σου, εκτός αν είσαι admin — ή [κοινοποιήσεις μια λίστα](#sharing-playlists) ώστε να τη δουν άλλοι. Η ακρόαση είναι κοινή — ο καθένας μπορεί να παίξει, να ακούσει προεπισκόπηση ή να μεταδώσει οποιοδήποτε κομμάτι, και να προσθέσει οτιδήποτε στις δικές του λίστες. Το να ζητήσεις ένα κομμάτι που κατεβάζει ήδη κάποιος άλλος μπαίνει στη δική του εργασία αντί να το φέρει δύο φορές: μία γραμμή στην ουρά, μία λήψη και μία κυριότητα ο καθένας — όποιος περιμένει βλέπει τη θέση του στην ουρά.

Τα podcast, οι παρακολουθήσεις λιστών και το ιστορικό της Ανακάλυψης λειτουργούν με τον ίδιο τρόπο: κάθε λογαριασμός γράφεται στις δικές του εκπομπές, ακολουθεί τις δικές του λίστες και καλλιτέχνες και εκπαιδεύει τις δικές του προτάσεις. Ένας admin βλέπει τις γραμμές κάθε λογαριασμού. Η ίδια η ακρόαση μένει κοινή — ο καθένας μπορεί να παίξει, να ακούσει προεπισκόπηση ή να μεταδώσει οποιοδήποτε κομμάτι.

### Κοινοποίηση λιστών

Μια λίστα είναι ιδιωτική για τον ιδιοκτήτη της (και τους admin) μέχρι να την κοινοποιήσει ο ιδιοκτήτης, από το **Κοινοποίηση…** στη σελίδα της λίστας ή στο μενού **⋯** της. Η αναπαραγωγή είναι ήδη κοινή ανάμεσα στους λογαριασμούς· εδώ μιλάμε μόνο για το ποιος μπορεί να *βλέπει* μια λίστα. Κάθε λίστα μπορεί να κοινοποιηθεί εκτός από τα *Αγαπημένα τραγούδια*, και οι εισαγμένες.

| Ορατότητα | Ποιος τη βλέπει |
|------------|-------------|
| **Ιδιωτική** | Μόνο ο ιδιοκτήτης και οι admin — η προεπιλογή |
| **Συγκεκριμένα άτομα** | Τα ονόματα χρήστη που διάλεξε ο ιδιοκτήτης |
| **Δημόσια** | Όλοι στον διακομιστή |

Οι λίστες των άλλων δεν ανακατεύονται ποτέ με τις δικές σου. Η καρτέλα **Λίστες** της Βιβλιοθήκης τις απαριθμεί σε δύο ενότητες κάτω από τις δικές σου, με κάθε εγγραφή σημειωμένη με τον ιδιοκτήτη της:

- **Κοινοποιημένες σε μένα** — λίστες που απευθύνονται σε σένα ονομαστικά, πάντα ορατές. Μια νεοκοινοποιημένη φέρει σήμανση **Νέα** μέχρι να την ανοίξεις.
- **Δημόσιες λίστες** — οι δημόσιες όλων, ταξινομημένες κατά ιδιοκτήτη και όνομα, με αναζήτηση μέσω του φίλτρου της καρτέλας, που δείχνουν τον ιδιοκτήτη, τον αριθμό τραγουδιών και αν την ακολουθείς. Η ενότητα ξεκινά διπλωμένη, και μπορείς να την κρύψεις εντελώς με το **Ρυθμίσεις › Γενικά › Εμφάνιση δημόσιων λιστών** (ενεργό από προεπιλογή· είναι δικό σου, όπως το θέμα).

Η πλαϊνή μπάρα δείχνει επίσης μερικές από όσες έχουν κοινοποιηθεί σε σένα και από τις δημόσιες λίστες που ακολουθείς.

**Τι μπορεί να κάνει όποιος τη βλέπει:** να παίξει, να ανακατέψει, να προσθέσει στην ουρά, να κατεβάσει ως ZIP (ή σε εφαρμογή κινητού ή υπολογιστή), να **Ακολουθήσει** μια δημόσια λίστα ώστε να μένει στις λίστες του — ακόμη και με το *Εμφάνιση δημόσιων λιστών* απενεργοποιημένο — και να ακολουθεί τις αλλαγές του ιδιοκτήτη της, και να **Αποθηκεύσει αντίγραφο**: μια ιδιωτική, επεξεργάσιμη δική του λίστα, με τα τραγούδια που μπορεί να δει. Όποιος τη βλέπει δεν μπορεί να επεξεργαστεί, να μετονομάσει, να διαγράψει, να κοινοποιήσει ή να αποσυνδέσει τη λίστα κάποιου άλλου.

**Κατάργηση κοινοποίησης:** όταν ο ιδιοκτήτης κάνει ξανά ιδιωτική μια λίστα, ή αφαιρέσει κάποιον από τη λίστα, εξαφανίζεται αμέσως από τις λίστες του (ακολουθούμενη ή μη)· μια λίστα που παύει να είναι δημόσια δεν ακολουθείται πια. Τα αντίγραφα που οι άνθρωποι έχουν ήδη αποθηκεύσει μένουν σε αυτούς. Η μετονομασία μιας κοινοποιημένης λίστας τη διατηρεί κοινοποιημένη· η διαγραφή της παίρνει μαζί και την κοινοποίηση. Τα τραγούδια που ένας admin [κρύβει από τους χρήστες](#hiding-from-users) παραλείπονται από τα κομμάτια μιας κοινοποιημένης λίστας γι' αυτούς, όπως παντού.

Ένας admin μπορεί να τα απενεργοποιήσει όλα με το **Ρυθμίσεις › Βιβλιοθήκη › Να επιτρέπεται στους χρήστες η κοινοποίηση λιστών** (ενεργό από προεπιλογή). Όσο είναι απενεργοποιημένο, κάθε κοινοποίηση κρύβεται και κανείς δεν μπορεί να κοινοποιήσει ή να ακολουθήσει — οι κοινοποιήσεις επιστρέφουν όταν ενεργοποιηθεί ξανά.

Οι συζευγμένες εφαρμογές παίρνουν τις ίδιες λίστες: το [`GET /api/v1/playlists`](../api-reference.md#get-apiv1playlists) λέει ποιος είναι ο ιδιοκτήτης της καθεμιάς και αν είναι μόνο για προβολή, και το `playlists_changed` στο WebSocket τους λέει να ανανεωθούν.

### Απόκρυψη από τους χρήστες

Οι admin αποφασίζουν τι βλέπουν οι άλλοι λογαριασμοί. Όλα είναι ορατά σε όλους μέχρι να κρύψει ένας admin κάτι: ένα **τραγούδι**, ένα ολόκληρο **άλμπουμ** ή έναν ολόκληρο **καλλιτέχνη**. Τα κρυμμένα στοιχεία φεύγουν από τη Βιβλιοθήκη, από τις ενδείξεις «στη βιβλιοθήκη» της αναζήτησης, από τις λίστες κομματιών των λιστών και από όσα συγχρονίζει ένα συζευγμένο κινητό — για τους χρήστες, όχι για τους admin.

- **Στη Βιβλιοθήκη**, άνοιξε το μενού `…` ενός τραγουδιού, άλμπουμ ή καλλιτέχνη και διάλεξε **Απόκρυψη από τους χρήστες** (ή **Εμφάνιση στους χρήστες** για να το αναιρέσεις). Στην καρτέλα Κομμάτια, επίλεξε πολλά τραγούδια και χρησιμοποίησε το **Απόκρυψη από τους χρήστες** στη γραμμή επιλογής.
- Οι admin συνεχίζουν να τα βλέπουν όλα. Ό,τι είναι κρυμμένο φέρει ένα μικρό διαγραμμένο μάτι, και η επεξήγησή του λέει γιατί: κρυμμένο από μόνο του, με το άλμπουμ του ή με τον καλλιτέχνη του.
- Το **Ρυθμίσεις › Χρήστες › Κρυφά από τους χρήστες** απαριθμεί κάθε κρυμμένο καλλιτέχνη, άλμπουμ και τραγούδι, με **Εμφάνιση στους χρήστες** δίπλα στο καθένα.
- Ένα κρυμμένο τραγούδι μένει κρυμμένο όταν μετακινείται σε άλλον φάκελο, και όταν η [Αναβάθμιση βιβλιοθήκης](library-upgrade.md) ή η [Αντικατάσταση ήχου](replace-audio.md) ξαναγράφουν το αρχείο του. Η διαγραφή του αρχείου ξεχνά τον κανόνα.
- Ένας κανόνας άλμπουμ ταιριάζει με τον καλλιτέχνη και τον τίτλο του άλμπουμ, και ένας κανόνας καλλιτέχνη με τον καλλιτέχνη κάτω από τον οποίο η Βιβλιοθήκη ομαδοποιεί το τραγούδι — τα ίδια ονόματα που χρησιμοποιούν οι καρτέλες Άλμπουμ και Καλλιτέχνες της Βιβλιοθήκης.

::: info Η απόκρυψη αφορά ό,τι εμφανίζεται σε λίστες
Ελέγχει τι βλέπουν οι λογαριασμοί στην εφαρμογή, όχι ποιος μπορεί να φέρει ένα αρχείο του οποίου ήδη γνωρίζει τη διεύθυνση. Μην τη χρησιμοποιείς για να προστατεύσεις ευαίσθητα αρχεία.
:::

Η απόκρυψη και η εμφάνιση καταγράφονται στο [αρχείο δραστηριότητας](#activity).

### Διαγραφή τραγουδιών

Η διαγραφή ενός τραγουδιού το αφαιρεί από τον δίσκο για όλους, οπότε ακολουθεί όποιον το κατέβασε. Ένας admin μπορεί να διαγράψει οτιδήποτε. Ένας χρήστης μπορεί να διαγράψει ένα τραγούδι που κατέβασε ο ίδιος· όταν κι άλλος κατέβασε το ίδιο τραγούδι, η διαγραφή απλώς παραιτείται από τη δική του αξίωση και το τραγούδι μένει στην κοινή βιβλιοθήκη. Ένα τραγούδι που κανείς δεν κατέβασε μέσω λογαριασμού (μια σάρωση της παρακολούθησης λιστών, μια λήψη από πριν τους λογαριασμούς, ένας [επιπλέον φάκελος](external-library.md)) μπορεί να διαγραφεί μόνο από admin. Η διαγραφή μιας δικής σου λίστας δεν παίρνει ποτέ μαζί της αρχεία κάποιου άλλου.

### Χρήση ανά λογαριασμό

Το **Ρυθμίσεις › Χρήστες** απαριθμεί, κάτω από κάθε λογαριασμό, τι κατέχει: κομμάτια και το μέγεθός τους, «μου αρέσει», λίστες, παραγγελμένες λήψεις και κίνηση προς τις δύο κατευθύνσεις (ανακτημένη από την πηγή έναντι σερβιρισμένης σε πελάτες), με τα σύνολα όλων από κάτω. Τα «Κομμάτια» μετρούν τα τραγούδια που κατέβασε ένας λογαριασμός, όχι όσα μπορεί να δει.

## Ο λογαριασμός και οι προτιμήσεις σου

Οι **Ρυθμίσεις → Γενικά** ξεκινούν με τον **Λογαριασμό** σου: άλλαξε το όνομα χρήστη ή τον κωδικό σου, ή αποσυνδέσου. Μπορείς επίσης να αποσυνδεθείς από την πλαϊνή μπάρα (ή **Περισσότερα** στο κινητό).

Τα υπόλοιπα των **Γενικά** — θέμα, γλώσσα, εμφάνιση στίχων στο πρόγραμμα αναπαραγωγής, άλμπουμ στα αποτελέσματα αναζήτησης — είναι **δικά σου**: σε ακολουθούν σε κάθε πρόγραμμα περιήγησης όπου συνδέεσαι και δεν αλλάζουν τίποτα για κανέναν άλλον.

Οι **Ρυθμίσεις → Εφαρμογές** απαριθμούν τα κινητά που έχουν συζευχθεί με τον λογαριασμό σου (ένας admin βλέπει όλων, με τον ιδιοκτήτη τους). Το **Αποσύνδεση παντού** αποσυζεύγνυει τις εφαρμογές σου και σε αποσυνδέει από κάθε πρόγραμμα περιήγησης.

## Διαχείριση χρηστών

Στις **Ρυθμίσεις → Χρήστες** ένας admin μπορεί να:

- **Προσθέσει χρήστη** — όνομα χρήστη (3 έως 32 γράμματα, ψηφία, `.`, `-` ή `_`), κωδικός (τουλάχιστον 8 χαρακτήρες) και ρόλος.
- **Επεξεργαστεί** έναν χρήστη — να τον μετονομάσει, να τον κάνει admin ή χρήστη, ή να του δώσει νέο κωδικό (που τον αποσυνδέει από τα προγράμματα περιήγησής του· οι εφαρμογές του μένουν συζευγμένες).
- **Διαγράψει** έναν χρήστη — οι εφαρμογές του αποσυζεύγνυνται και τα προγράμματα περιήγησής του αποσυνδέονται. Τα αρχεία του μένουν στον δίσκο (οι admin μπορούν ακόμη να τα δουν)· τα «μου αρέσει», οι λίστες, οι συνδρομές podcast, οι παρακολουθήσεις, το ιστορικό προτάσεων και οι μετρητές κίνησης φεύγουν μαζί του.
- **Αποσυνδέσει όλους** — κάθε εφαρμογή κάθε χρήστη αποσυζεύγνυται και κάθε πρόγραμμα περιήγησης αποσυνδέεται, και το δικό σου.

Υπάρχει πάντα τουλάχιστον ένας admin: ο τελευταίος δεν μπορεί να διαγραφεί ή να γίνει χρήστης, και δεν μπορείς να διαγράψεις τον δικό σου λογαριασμό.

## Δραστηριότητα

Η **Ρυθμίσεις → Δραστηριότητα** (admin) δείχνει, όπως ο πίνακας ελέγχου του Jellyfin:

- **Παίζει τώρα** — τι παίζει κάθε πρόγραμμα περιήγησης και εφαρμογή, από ποιον, πού βρίσκεται στο τραγούδι και αν είναι σε παύση. Ανανεώνεται κάθε λίγα δευτερόλεπτα.
- **Ιστορικό** — συνδέσεις (και αποτυχημένες, με τη διεύθυνση από την οποία ήρθαν), αποσυνδέσεις, τραγούδια που παίχτηκαν, λήψεις, «μου αρέσει», διαγραμμένα αρχεία, τραγούδια που κρύφτηκαν από ή εμφανίστηκαν στους χρήστες, εφαρμογές που συζεύχθηκαν και αποσυζεύχθηκαν, λογαριασμοί που προστέθηκαν, άλλαξαν ή διαγράφηκαν, κωδικοί και ρυθμίσεις που άλλαξαν. Φιλτράρισε κατά χρήστη ή είδος. Οι αποθηκευμένες ρυθμίσεις απαριθμούνται μόνο με το όνομα, ποτέ με τις τιμές τους. Οι εγγραφές διατηρούνται για 90 ημέρες.

Οι εφαρμογές αναφέρουν κι εκείνες τι παίζουν — δες το [συμβόλαιο πελάτη κινητού](../mobile-client-contract.md#8-report-plays).

## Απενεργοποίηση των λογαριασμών

Ένας διακομιστής που τον φτάνεις μόνο εσύ — στον δικό σου υπολογιστή, ή πίσω από κάτι που ήδη ζητά κωδικό — μπορεί να μη χρειάζεται καθόλου λογαριασμούς. Όρισε `DOWNTIFY_DISABLE_AUTH=true` (δες [Μεταβλητές περιβάλλοντος](../getting-started/environment-variables.md#mobile-apps-and-sign-in)):

```yaml
environment:
  - DOWNTIFY_DISABLE_AUTH=true
```

Τότε:

- Δεν υπάρχει σελίδα σύνδεσης: όποιος ανοίγει το Downtify το χρησιμοποιεί ως ο πρώτος admin (`admin` σε νέο διακομιστή).
- Τα κουμπιά αποσύνδεσης, οι **Ρυθμίσεις → Χρήστες**, το τμήμα **Λογαριασμός** των **Ρυθμίσεις → Γενικά** και το **Αποσύνδεση παντού** στις **Ρυθμίσεις → Εφαρμογές** εξαφανίζονται.
- Τα κινητά μπορούν ακόμη να συζευχθούν (σε αυτόν τον admin), και οι **Ρυθμίσεις → Δραστηριότητα** δείχνουν ακόμη τι παίζει πού.
- Το θέμα, η γλώσσα και οι άλλες προτιμήσεις των **Γενικά** διατηρούνται ως του admin αυτού.

::: warning Όποιος φτάνει στον διακομιστή μπορεί να κάνει τα πάντα
Με τους λογαριασμούς απενεργοποιημένους, τίποτα δεν ρωτά ποιος είσαι: όλοι στο δίκτυό σου — ή στο διαδίκτυο, αν η θύρα είναι εκτεθειμένη — μπορούν να αλλάξουν ρυθμίσεις, να διαγράψουν μουσική και να συζεύξουν ένα κινητό. Μην απενεργοποιείς τους λογαριασμούς σε διακομιστή που φτάνουν και άλλοι.
:::

Όρισέ το `false` (ή αφαίρεσέ το) και η σύνδεση απαιτείται ξανά, με τους λογαριασμούς, τους κωδικούς και τις εφαρμογές όπως ήταν.

## Ξέχασες τον κωδικό;

Τρέξε αυτό στον διακομιστή — ο `admin` παίρνει πίσω τον κωδικό `downtify` (και ξαναδημιουργείται ως admin αν είχε μετονομαστεί ή διαγραφεί)· οι άλλοι λογαριασμοί και οι συζευγμένες εφαρμογές μένουν ανέγγιχτοι:

```bash
docker exec downtify python main.py auth-reset
```

Εκτός Docker, τρέξε `python main.py auth-reset` (ή `uv run python main.py auth-reset`) στον φάκελο του Downtify. Μετά συνδέσου και άλλαξε τον κωδικό.

## Scripts και το API

Κάθε κλήση API χρειάζεται πλέον διαπιστευτήρια (δες την [αναφορά API](../api-reference.md#server-and-sign-in)). Ένα script μπορεί να συνδεθεί με `POST /api/auth/login` και να κρατήσει το cookie `downtify_session`, ή να χρησιμοποιήσει το διακριτικό μιας συζευγμένης συσκευής.
