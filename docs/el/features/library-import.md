# Εισαγωγή βιβλιοθήκης (CSV)

Έχεις ήδη εξαγάγει τη βιβλιοθήκη σου από άλλη υπηρεσία; Εισήγαγε το CSV και βάλε όλα τα κομμάτια στην ουρά λήψης με μία κίνηση, αντί να προσθέτεις τραγούδια ένα ένα.

## Υποστηριζόμενα εργαλεία εξαγωγής

| Εργαλείο | Σημειώσεις |
|------|-------|
| [Soundiiz](https://soundiiz.com/) | |
| [TuneMyMusic](https://www.tunemymusic.com/) | |
| [Exportify](https://github.com/watsonbox/exportify) | |

Το Downtify δεν κωδικοποιεί σκληρά το ακριβές σχήμα στηλών κανενός εργαλείου. Αντίθετα, ταιριάζει τη γραμμή κεφαλίδας του CSV, χωρίς διάκριση πεζών-κεφαλαίων, με ένα σύνολο γνωστών ψευδωνύμων (`Title` / `Track` / `Track Title` / `Track Name` / `Song` / …, `Artist` / `Artists` / `Artist Name` / `Artist Name(s)` / … και `Album` / `Album Name` / `Album Title` / …), οπότε οι εξαγωγές οποιουδήποτε από τα τρία — ή ενός CSV φτιαγμένου με το χέρι με τα ίδια ονόματα στηλών — λειτουργούν χωρίς να μετονομάσεις τίποτα.

Ο τίτλος και ο καλλιτέχνης είναι υποχρεωτικά. Το άλμπουμ διαβάζεται όταν υπάρχει και αποθηκεύεται ως όνομα άλμπουμ του κομματιού (Ουρά, ταίριασμα και tags αρχείου). Άλλες στήλες που περιλαμβάνουν ορισμένα εργαλεία (ISRC, URI κομματιού Spotify, διάρκεια) αγνοούνται. Κάθε γραμμή επιλύεται όπως μια αναζήτηση ελεύθερου κειμένου, μέσω YouTube Music.

## Πώς γίνεται η εισαγωγή

1. Στην αρχική σελίδα, πάτα **Εισαγωγή CSV (Soundiiz, Exportify…)** κάτω από το πλαίσιο αναζήτησης.
2. Διάλεξε το εξαγόμενο αρχείο `.csv`.

Το αρχείο διαβάζεται εξ ολοκλήρου στον browser σου και στέλνεται στον διακομιστή ως απλό κείμενο — δεν ανεβαίνει πουθενά αλλού. Το Downtify το αναλύει, βάζει στην ουρά κάθε αναγνωρισμένη γραμμή και καταλήγεις στην Ουρά λήψεων, όπου η πρόοδος έρχεται μέσω WebSocket ακριβώς όπως σε κάθε άλλη μαζική λήψη.

Η εισαγόμενη παρτίδα παίρνει το όνομα του αρχείου (το όνομά του χωρίς `.csv`) και, όπως κάθε άλλη λήψη λίστας, αποκτά [αρχείο M3U](m3u-export.md) αν η ρύθμιση είναι ενεργή.

## Όρια και χειρισμός σφαλμάτων

- Έως **2.000 γραμμές** ανά αρχείο. Χώρισε μεγαλύτερες εξαγωγές σε πολλά αρχεία.
- Οι γραμμές χωρίς τίτλο ή καλλιτέχνη παραλείπονται αθόρυβα. Μια στήλη άλμπουμ που λείπει ή ένα κενό κελί άλμπουμ είναι εντάξει — το YouTube Music μπορεί να συμπληρώσει το άλμπουμ αργότερα.
- Πολλοί καλλιτέχνες σε ένα κελί (χωρισμένοι με `,` ή `;`) διαχωρίζονται σε λίστα.
- Αν η κεφαλίδα δεν περιέχει αναγνωρίσιμη στήλη τίτλου/καλλιτέχνη, ολόκληρη η εισαγωγή απορρίπτεται εξαρχής με σφάλμα που ονομάζει τις στήλες που βρέθηκαν — τίποτα δεν μπαίνει στην ουρά.

## Αποφυγή ορίων ρυθμού

Η εισαγωγή μιας μεγάλης βιβλιοθήκης βάζει στην ουρά πολλές αναζητήσεις και λήψεις YouTube Music σε σύντομο χρόνο, κάτι που οδηγεί εύκολα σε περιορισμό ρυθμού. Πριν εισαγάγεις ένα μεγάλο αρχείο, σκέψου να μειώσεις τις **[Ταυτόχρονες λήψεις](download-settings.md#parallel-downloads)** και να ενεργοποιήσεις την **[Παύση μεταξύ λήψεων](download-settings.md#delay-between-downloads)** στις Ρυθμίσεις.

## API

Δες το [`POST /api/download/csv`](../api-reference.md#post-apidownloadcsv) στην αναφορά API για το υποκείμενο endpoint.
