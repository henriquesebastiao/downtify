# Ειδοποιήσεις ενημέρωσης

Το Downtify ελέγχει τη δική του [σελίδα Releases στο GitHub](https://github.com/henriquesebastiao/downtify/releases) μία φορά την ώρα. Όταν υπάρχει νεότερη έκδοση, εμφανίζεται μια ειδοποίηση στο κάτω μέρος της πλαϊνής στήλης σε κάθε σελίδα — στα κινητά, μια τελεία στην καρτέλα **Περισσότερα** και μια γραμμή στην κορυφή του φύλλου της — καθώς και στο **Ρυθμίσεις → Σχετικά**:

> ✦ Διαθέσιμη ενημέρωση 3.0.1

Πάτησέ την για να ανοίξεις αυτή την έκδοση στο GitHub.

## Πώς λειτουργεί

- Μια εργασία παρασκηνίου στο backend (`downtify/update_check.py`) παίρνει την τελευταία έκδοση από το API του GitHub μία φορά αμέσως κατά την εκκίνηση και μετά κάθε ώρα. Είναι «στείλε και ξέχνα»: τίποτα στη διεπαφή δεν την περιμένει.
- Η web διεπαφή διαβάζει το αποθηκευμένο αποτέλεσμα από το `GET /api/check_update` (δες την [Αναφορά API](../api-reference.md)) μία φορά την ώρα και εμφανίζει την ειδοποίηση όταν βρεθεί νεότερη έκδοση.
- Οι εκδόσεις συγκρίνονται αριθμητικά (το `2.10.0` < `2.9.0` είναι ψευδές, σε αντίθεση με μια απλή σύγκριση κειμένου) και το προαιρετικό πρόθεμα `v` στην ετικέτα της έκδοσης αγνοείται.

## Αν το GitHub δεν είναι προσβάσιμο

Ένας αποτυχημένος έλεγχος (μηχάνημα εκτός σύνδεσης, όριο αιτημάτων του GitHub) καταγράφεται και απλώς επαναλαμβάνεται στον επόμενο ωριαίο κύκλο — το προηγούμενο αποτέλεσμα, αν υπάρχει, ισχύει μέχρι τότε. Ο έλεγχος δεν μπλοκάρει ποτέ τίποτα άλλο στο Downtify· δεν υπάρχει σφάλμα που να εμφανίζεται στον χρήστη.

## Τίποτα δεν κατεβαίνει αυτόματα

Αυτό απλώς σε *ενημερώνει* ότι υπάρχει νέα έκδοση — το Downtify δεν ενημερώνεται μόνο του. Για να ενημερώσεις πραγματικά, κατέβασε τη νέα εικόνα και ξαναδημιούργησε το κοντέινερ:

```bash
docker compose pull
docker compose up -d
```
