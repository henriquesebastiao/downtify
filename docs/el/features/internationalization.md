# Διεθνοποίηση

Το Downtify μεταφράζεται σε δύο ανεξάρτητα σημεία: την **εφαρμογή** (τη διεπαφή της) και αυτή την **τεκμηρίωση**. Η προεπιλεγμένη γλώσσα και των δύο είναι τα **αγγλικά**, με εννέα ακόμη γλώσσες ενσωματωμένες.

## Αλλαγή γλώσσας

### Η εφαρμογή

Πήγαινε στις **Ρυθμίσεις → Γλώσσα** και διάλεξε την προτιμώμενη γλώσσα σου. Η επιλογή αποθηκεύεται στο `localStorage` του προγράμματος περιήγησης και εφαρμόζεται άμεσα χωρίς ανανέωση της σελίδας. Η σελίδα ενημερώνει επίσης τον διακομιστή (η εγγραφή `ui_language` του `settings.json`, δες [`POST /api/settings/update`](../api-reference.md#post-apisettingsupdate)), σε κάθε φόρτωση και όποτε την αλλάζεις, ώστε η εργασία που τρέχει χωρίς πρόγραμμα περιήγησης να γνωρίζει τη γλώσσα σου - το βιογραφικό ενός καλλιτέχνη, που ανακτάται στο παρασκήνιο όταν τελειώσει η λήψη ενός κομματιού του, έρχεται σε αυτήν (δες [Όταν τελειώνει μια λήψη](artist-images.md#when-a-download-finishes)). Δεν χρειάζεται να κάνεις τίποτα: αν είχες διαλέξει γλώσσα πριν υπάρξει αυτό, παραλαμβάνεται την επόμενη φορά που θα ανοίξεις το Downtify. Με πολλά προγράμματα περιήγησης ρυθμισμένα σε διαφορετικές γλώσσες, κερδίζει το τελευταίο που τη φόρτωσε ή την άλλαξε.

### Η τεκμηρίωση

Η τεκμηρίωση ανοίγει στη γλώσσα που προτιμά το πρόγραμμα περιήγησής σου, όταν είναι μεταφρασμένη σε αυτήν, και στα αγγλικά διαφορετικά. Το **κουμπί υδρογείου** δεξιά στην πάνω μπάρα αλλάζει γλώσσα οποιαδήποτε στιγμή και σε κρατά στην ίδια σελίδα (και ενότητα). Η επιλογή σου θυμάται στο πρόγραμμα περιήγησης και από τότε υπερισχύει της γλώσσας του προγράμματος περιήγησης μέχρι να διαλέξεις άλλη.

Μια σελίδα που δεν έχει μεταφραστεί ακόμη δείχνει μια σημείωση και το αγγλικό κείμενο, οπότε κάθε γλώσσα έχει πάντα κάθε σελίδα.

## Διαθέσιμες γλώσσες

| Κωδικός | Γλώσσα | Εφαρμογή | Τεκμηρίωση |
| ------- | ------------------ | --- | ---- |
| `en` | English (προεπιλογή) | ✓ | ✓ |
| `es` | Español | ✓ | ✓ |
| `pt-BR` | Português (Brasil) | ✓ | ✓ |
| `fr` | Français | ✓ | ✓ |
| `tr` | Türkçe | ✓ | ✓ |
| `el` | Ελληνικά | ✓ | ✓ |
| `hu` | Magyar | ✓ | ✓ |
| `bg` | Български | ✓ | ✓ |
| `de` | Deutsch | ✓ | ✓ |
| `ko` | 한국어 | ✓ | ✓ |

Οι σελίδες αναφοράς που προορίζονται για προγραμματιστές — η [αναφορά API](../api-reference.md), το [συμβόλαιο πελάτη κινητού](../mobile-client-contract.md) και το αρχείο αλλαγών — μένουν στα αγγλικά σε κάθε γλώσσα.

## Συνεισφορά μετάφρασης

Μπορείς να μεταφράσεις την εφαρμογή, την τεκμηρίωση ή και τα δύο. Είναι ξεχωριστές δουλειές με ξεχωριστά αρχεία, οπότε ένα pull request μπορεί να περιέχει το ένα ή το άλλο — ή μια γλώσσα μπορεί να προστεθεί πρώτα στο ένα και αργότερα στο άλλο.

| Μεταφράζεις | Πού είναι τα αρχεία | Έχει τελειώσει όταν |
| ------------- | ------------------- | --------- |
| **Μόνο την εφαρμογή** | `frontend/src/i18n/locales/<code>.js` | η γλώσσα εμφανίζεται στις **Ρυθμίσεις → Γλώσσα** |
| **Μόνο την τεκμηρίωση** | `docs/.vitepress/locales/<code>.mjs` και οι σελίδες Markdown στο `docs/<code>/` | η γλώσσα εμφανίζεται στο μενού υδρογείου της τεκμηρίωσης |
| **Και τα δύο** | όλα τα παραπάνω | και τα δύο |

Μια γλώσσα δεν χρειάζεται να υπάρχει στην εφαρμογή για να προστεθεί στην τεκμηρίωση, ούτε το αντίστροφο.

## Μετάφραση της εφαρμογής

Η προσθήκη μετάφρασης στην εφαρμογή γίνεται σε τρία βήματα:

### 1. Αντίγραψε το αγγλικό αρχείο γλώσσας

Τα αρχεία γλώσσας βρίσκονται στο `frontend/src/i18n/locales/`. Κάθε αρχείο εξάγει ένα μόνο αντικείμενο του οποίου τα κλειδιά ταιριάζουν με τη δομή του `en.js`. Χρησιμοποίησε μια [ετικέτα γλώσσας IETF](https://en.wikipedia.org/wiki/IETF_language_tag) για το όνομα αρχείου.

```bash
cp frontend/src/i18n/locales/en.js frontend/src/i18n/locales/it.js
```

### 2. Μετάφρασε τις τιμές

Άφησε αμετάβλητα τα κλειδιά, τα σύμβολα κράτησης θέσης (π.χ. `{count}`, `{name}`, `{file}`) και τη γενική μορφή — μόνο οι συμβολοσειρές στη δεξιά πλευρά πρέπει να αλλάξουν. Όρισε το `language.name` στο **εγγενές** όνομα της γλώσσας (`"Français"`, `"Deutsch"`, …) — είναι η ετικέτα που εμφανίζεται στον επιλογέα γλώσσας.

### 3. Δήλωσε τη γλώσσα

Πρόσθεσε ένα import και μια εγγραφή στο `AVAILABLE_LOCALES` στο `frontend/src/i18n/index.js`:

```js
import it from './locales/it.js'

export const AVAILABLE_LOCALES = [
  { code: 'en', name: 'English', messages: en },
  { code: 'es', name: 'Español', messages: es },
  // …
  { code: 'it', name: 'Italiano', messages: it }, // new
]
```

Ξαναχτίσε το frontend και η γλώσσα σου θα εμφανιστεί αυτόματα στις **Ρυθμίσεις → Γλώσσα**:

```bash
cd frontend && npm run build
```

### Συμβουλές για τη μετάφραση της εφαρμογής

- Τα κλειδιά που λείπουν επιστρέφουν στα αγγλικά, οπότε οι μερικές μεταφράσεις λειτουργούν μια χαρά — στείλε ένα PR με ό,τι έχεις.
- Οι συμβολοσειρές που εξαρτώνται από αριθμό είναι αντικείμενα με πληθυντικές μορφές, π.χ. `tracks: { one: '{count} track', other: '{count} tracks' }`. Η μορφή επιλέγεται με το [`Intl.PluralRules`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) του προγράμματος περιήγησης για τη γλώσσα σου, οπότε πρόσθεσε τις μορφές που χρησιμοποιεί η γλώσσα σου (`zero`, `one`, `two`, `few`, `many`, `other`) — το `other` είναι υποχρεωτικό. Οι αριθμοί μορφοποιούνται αυτόματα για τη γλώσσα.
- Τα σύμβολα κράτησης θέσης όπως `{count}` ή `{file}` πρέπει να μένουν αμετάβλητα· αντικαθίστανται κατά την εκτέλεση.
- Κράτα τις συμβολοσειρές σύντομες — η διεπαφή είναι σφιχτά διαμορφωμένη και πολύ μεγάλες μεταφράσεις μπορεί να σπάνε άσχημα.
- Μετά τη μετάφραση, τρέξε `npm run dev` από το `frontend/` και πλοηγήσου σε κάθε σελίδα στη γλώσσα σου για να εντοπίσεις ό,τι ξεχειλίζει ή ακούγεται περίεργο στο πλαίσιο.

## Μετάφραση της τεκμηρίωσης

Τα αγγλικά είναι η πηγή: βρίσκεται στο `docs/`. Κάθε άλλη γλώσσα έχει έναν φάκελο με το όνομα του κωδικού της (`docs/pt-BR/`) με **τα ίδια ονόματα αρχείων** με τα αγγλικά, συν ένα αρχείο για τα δικά του κείμενα του ιστότοπου (`docs/.vitepress/locales/pt-BR.mjs`: οι τίτλοι της πλαϊνής μπάρας, το πεδίο αναζήτησης, το υποσέλιδο, οι ετικέτες των πλαισίων επισήμανσης). Μια σελίδα που δεν έχει μεταφραστεί ακόμη είναι ένα μικρό προσχέδιο που δείχνει μια σημείωση και συμπεριλαμβάνει την αγγλική σελίδα.

### Μετάφραση μιας σελίδας υπάρχουσας γλώσσας

Από το `docs/`:

```bash
npm install
npm run i18n -- status pt-BR           # what is translated, what is English-only, what is out of date
npm run i18n -- start pt-BR features/users.md
```

Το `start` αντικαθιστά το προσχέδιο `docs/pt-BR/features/users.md` με αντίγραφο της αγγλικής σελίδας. Μετάφρασέ το επιτόπου και μετά έλεγξέ το:

```bash
npm test             # the translated pages must keep the English page's structure
npm run dev          # read it in the browser, in your language
```

Άνοιξε ένα pull request όταν η σελίδα διαβάζεται καλά· και η μερική δουλειά είναι ευπρόσδεκτη — οι σελίδες που δεν άγγιξες απλώς μένουν στα αγγλικά.

### Προσθήκη γλώσσας στην τεκμηρίωση

1. Αντίγραψε το `docs/.vitepress/locales/en.mjs` στο `docs/.vitepress/locales/<code>.mjs` και μετάφρασέ το: το εγγενές `name`, τα κείμενα του ιστότοπου (`ui`), τις ετικέτες των πλαισίων επισήμανσης (`containers`) και τους τίτλους της πλαϊνής μπάρας (`nav`).
2. Δήλωσέ το στο `docs/.vitepress/locales/index.mjs`.
3. Δημιούργησε τις σελίδες, ως προσχέδια μόνο στα αγγλικά: `npm run i18n -- stubs <code>`.
4. Μετάφρασε τις σελίδες μία-μία με `npm run i18n -- start <code> <page>`.

Η γλώσσα εμφανίζεται στο μενού υδρογείου και στην ανίχνευση γλώσσας του προγράμματος περιήγησης μόλις δηλωθεί.

### Τι να κρατήσεις και τι να μεταφράσεις

- **Μετάφρασε** το κείμενο, τις επικεφαλίδες, τα κελιά των πινάκων, τους τίτλους των πλαισίων επισήμανσης και τις τιμές `title`/`text` στο front matter της αρχικής σελίδας.
- **Κράτα ως έχουν** τα μπλοκ κώδικα, τον ενσωματωμένο `code`, τα URL, τις μεταβλητές περιβάλλοντος, τις διαδρομές και τα ονόματα πεδίων του API, τα ονόματα αρχείων και φακέλων, και τα κλειδιά του front matter και τις τιμές των `icon:` και `link:`. Η μετάφραση ενός σχολίου μέσα σε μπλοκ κώδικα είναι αποδεκτή.
- **Σύνδεσμοι**: κράτα ακριβώς τους σχετικούς συνδέσμους `.md` της αγγλικής σελίδας (`[Στίχοι](lyrics.md#sidecar-lrc-file)`). Ένας σύνδεσμος προς σελίδα που υπάρχει μόνο στα αγγλικά λειτουργεί ακόμη. Στην αρχική σελίδα, οι σύνδεσμοι γράφονται με το πρόθεμα γλώσσας (`/pt-BR/features/player/`).
- **Επικεφαλίδες**: κράτα τις ίδιες επικεφαλίδες, με την ίδια σειρά και στα ίδια επίπεδα. Οι σύνδεσμοι προς μια ενότητα (`#sidecar-lrc-file`) συνεχίζουν να λειτουργούν σε κάθε γλώσσα επειδή η μεταφρασμένη σελίδα επαναχρησιμοποιεί τα αγγλικά ids επικεφαλίδων — δεν γράφεις ούτε μεταφράζεις ποτέ id.
- **Ονόματα κουμπιών και ρυθμίσεων**: η εφαρμογή έχει τη δική της μετάφραση για κάθε ετικέτα. Χρησιμοποίησέ την, με έντονη γραφή, ώστε η σελίδα να ταιριάζει με ό,τι βλέπει ο αναγνώστης στην οθόνη: αναζήτησε την ετικέτα στο `frontend/src/i18n/locales/<code>.js`. Αν η εφαρμογή δεν έχει μεταφραστεί ακόμη σε αυτή τη γλώσσα, κράτα την αγγλική ετικέτα.
- **Πλαίσια επισήμανσης** (`::: tip Τίτλος`): κράτα το είδος (`info`, `tip`, `warning`, `danger`) και μετάφρασε τον τίτλο. Ένα πλαίσιο χωρίς τίτλο φέρει ως ετικέτα τη λέξη από τα `containers` στο αρχείο γλώσσας.
- **Ύφος**: γράψε για τον αναγνώστη εκείνης της γλώσσας — οι σελίδες είναι οδηγοί, όχι αποδόσεις λέξη προς λέξη.

### Διατήρηση των μεταφράσεων ενημερωμένων

Όταν αλλάζει μια αγγλική σελίδα, οι μεταφράσεις της δεν χρειάζεται να αλλάξουν στο ίδιο pull request: μια μεταφρασμένη σελίδα συνεχίζει να λειτουργεί, και το `npm run i18n -- status <code>` απαριθμεί τις σελίδες των οποίων η αγγλική πηγή άλλαξε μετά τη μετάφρασή τους. Η ενημέρωσή τους είναι μια καλή πρώτη συνεισφορά.

Τα τεστ (`npm test` στο `docs/`) ελέγχουν ότι κάθε γλώσσα έχει κάθε σελίδα και κάθε κείμενο του ιστότοπου, και ότι μια μεταφρασμένη σελίδα έχει ακόμη τις επικεφαλίδες, τα μπλοκ κώδικα, τους πίνακες, τα πλαίσια επισήμανσης και τους συνδέσμους της αγγλικής σελίδας.
