# 원클릭 설치

Downtify는 가장 인기 있는 홈 서버 플랫폼의 앱 스토어에서 제공됩니다. 명령줄이 필요 없습니다.

## 지원 플랫폼

| 플랫폼 | 스토어 링크 |
|----------|-----------|
| **Umbrel** | [apps.umbrel.com/app/downtify](https://apps.umbrel.com/app/downtify) |
| **CasaOS** | [casaos.zimaspace.com](https://casaos.zimaspace.com/) |
| **HomeDock OS** | [homedock.cloud/apps/downtify](https://www.homedock.cloud/apps/downtify/) |

각 플랫폼이 Docker 이미지, 볼륨, 재시작 정책을 자동으로 처리합니다. 설치한 뒤에는 플랫폼의 대시보드에서 Downtify를 여세요. 기본 포트는 **8000**입니다.

## 업데이트

업데이트는 플랫폼의 앱 스토어에서 관리합니다. Downtify 항목을 열고 새 버전이 있을 때 **Update**를 클릭하세요. 음악 라이브러리와 설정은 자동으로 보존됩니다.

## 사용자 지정 설정

환경 변수([환경 변수](environment-variables.md) 참고)는 보통 각 플랫폼의 앱 설정 패널에서 지정할 수 있습니다. 정확한 위치는 사용 중인 플랫폼의 문서를 참고하세요.
