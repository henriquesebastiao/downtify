# 성인 콘텐츠 표시

노골적인 가사(어린이에게 적합하지 않은 표현)가 있는 곡은 Spotify처럼 제목 옆에 작은 **E**가 붙습니다. 곡을 만나는 모든 곳에서, 다운로드 전에도 후에도 표시되며 파일에 그대로 남습니다.

## 어디에서 보이나요

- **검색 결과, 붙여넣은 링크, 차트, 파인더** — 서비스가 선정적(explicit)이라고 표시한 모든 곡에서. 다운로드하기 전에 알 수 있습니다.
- **라이브러리** — 트랙 탭, 앨범·아티스트·재생목록 페이지, "곡 추가" 선택기에서.
- **플레이어** — 플레이어 바의 제목 옆, **현재 재생 중**, **다음 재생 곡**에서.

**E**에 마우스를 올리면(또는 화면 낭독기가 읽으면) "선정적 콘텐츠 (Explicit)"가 보입니다.

## 표시는 어디서 오나요

다운로드하는 서비스가 결정합니다. Spotify, YouTube Music, Deezer는 각자 자기 서비스의 선정적인 곡에 표시를 하며, Downtify는 선택한 서비스가 알려 주는 대로 따릅니다. Downtify가 YouTube Music에서 곡을 내려받을 때 표시는 **실제로 내려받는 영상**을 기준으로 합니다. 곡이 Spotify에서는 선정적이지만 Downtify가 클린 버전과 매칭했다면 파일에 표시하지 않고, Spotify에서는 클린이라고 하지만 매칭된 영상이 선정적이면 표시합니다.

서비스가 표시하지 않은 곡에는 아무 표시도 붙지 않습니다. 이는 클린임이 인증되었다는 뜻이 아니며, Downtify는 "클린" 표시를 절대 기록하지 않습니다.

## 파일 안에서

표시는 iTunes와 같은 방식으로 파일의 태그에 기록되므로, 이를 이해하는 미디어 서버와 플레이어도 사용할 수 있습니다. Navidrome은 바로 이 태그를 트랙의 선정적 콘텐츠 상태로 읽습니다.

| 형식 | 태그 |
|--------|-----|
| MP3 | `ITUNESADVISORY` 텍스트 프레임(`TXXX`), 값 `1` |
| FLAC, OGG, OPUS | `ITUNESADVISORY` 주석, 값 `1` |
| M4A | `rtng` 아톰, 값 `1` |

이미 가지고 있던 파일도 같은 방식으로 읽습니다. iTunes, MusicBrainz Picard 같은 태그 편집기가 `1`(또는 이전 값 `4`)로 표시한 파일은 [추가 폴더](external-library.md)의 곡을 포함해 모두 **E**가 표시됩니다.

::: info 이 버전 이전에 내려받은 곡
표시 기능이 생기기 전에 Downtify가 기록한 파일은 태그에 아무것도 없으므로, 곡이 선정적이더라도 **E**가 표시되지 않습니다. 표시하려면 [오디오 교체](replace-audio.md)나 처음부터 다시 다운로드하세요. [라이브러리 업그레이드](library-upgrade.md)나 오디오 교체가 파일을 다시 쓸 때도 표시는 유지됩니다. 표시는 추가만 되고 지워지지 않습니다.
:::

업데이트 후 라이브러리를 처음 불러올 때 Downtify는 코덱과 장르를 표시하도록 배웠을 때처럼 모든 파일의 태그를 다시 읽어 표시를 찾습니다. 느린 디스크의 큰 라이브러리라면 한 번 잠시 걸립니다.

## 앱 개발자용

[모바일 클라이언트 규약](../mobile-client-contract.md)과 [API 레퍼런스](../api-reference.md#get-tracks)에 `explicit` 필드가 설명되어 있습니다. 선정적인 트랙에는 `true`, 그렇지 않으면 없습니다.
