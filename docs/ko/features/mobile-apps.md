# 모바일 앱

Downtify는 휴대폰의 앱을 지원할 수 있습니다. 앱은 서버에서 직접 라이브러리를 둘러보고 스트리밍하며, 오프라인 청취를 위해 곡을 휴대폰에 보관합니다. 앱에 필요한 모든 것은 **설정 → 앱 연동**에서 설정합니다: 휴대폰 연결과 서버 이름입니다. 서버를 누가 사용할 수 있는지는 [사용자와 로그인](users.md)의 계정으로 정해집니다.

::: warning 앱은 아직 개발 중입니다
**설정 → 앱 연동**은 *실험적 기능*으로 표시되어 있습니다. 이 페이지에서 설명하는 서버 쪽은 완성되어 동작하지만, **Android 앱은 아직 어떤 버전도 공개되지 않았으므로** 지금은 설치할 것이 없고, 연결과 스트리밍의 세부 사항은 Downtify 버전 사이에 바뀔 수 있습니다.

앱은 [henriquesebastiao/downtify-android](https://github.com/henriquesebastiao/downtify-android)에서 공개적으로 개발되고 있습니다. 같은 API를 기반으로 다른 앱도 만들 수 있습니다 — [모바일 클라이언트 규약](../mobile-client-contract.md)을 참고하세요.
:::

## 앱에서 로그인하기

서버 주소를 입력하거나 **이 네트워크에서 찾음**에서 고른 다음, 웹 페이지와 **같은 사용자 이름과 비밀번호**로 로그인합니다. 휴대폰은 아래에서 코드로 연결한 것과 똑같이 **연결된 앱 기기**에 나타납니다. 내 이름으로 재생하고, 자신만의 키를 보관하며(비밀번호는 휴대폰에 저장되지 않습니다), **연결 해제**로 막을 수 있습니다.

틀린 비밀번호는 웹 페이지 로그인과 함께 횟수가 제한됩니다. 계정이 꺼져 있는 동안(`DOWNTIFY_DISABLE_AUTH`)에는 로그인할 방법이 없으니 코드로 연결하세요.

## 휴대폰 연결하기

연결은 휴대폰에 비밀번호가 필요 없습니다. 웹 페이지가 이미 열려 있을 때나, 비밀번호를 입력하고 싶지 않은 휴대폰에서 편리합니다.

1. **설정 → 앱 연동**을 열고 **스마트폰 연결**을 누릅니다.
2. 앱에서 **코드 스캔**을 선택해 카메라를 QR 코드에 비추거나, 그 아래에 표시된 8자 코드(`K7QM-2XPD`, 대소문자와 하이픈은 상관없음)를 입력합니다.
3. 휴대폰이 연결되면 대화상자가 알려 주고, **연결된 앱 기기**에 나타납니다.

휴대폰은 **내 계정**에 연결됩니다. 내 이름으로 재생하며 내 활동에 표시됩니다. 계정이 있는 사람은 누구나 자신의 휴대폰을 연결할 수 있습니다.

코드는 **한 번**, **5분** 동안만 유효하며, 틀린 코드를 시도하는 횟수는 제한됩니다. 휴대폰은 자신만의 키를 받아 보관하고, 서버는 그 해시만 저장합니다.

**연결된 앱 기기**에는 내 휴대폰이 플랫폼, 마지막으로 확인된 시점, 접속한 주소와 함께 나열됩니다(관리자는 모든 사람의 기기를 소유자와 함께 봅니다). **연결 해제**는 휴대폰을 즉시 막습니다 — 다음 요청이 실패하고, 열려 있는 연결이 닫히며, 그 기기가 공유한 링크([캐스트](#casting) 참고)가 작동하지 않게 됩니다. 다시 쓰려면 다시 연결하세요.

## 연결된 앱이 할 수 있는 일

연결된 앱은 둘러보기, 재생, 좋아요, 곡 오프라인 보관, 서버에 음악 다운로드 요청을 할 수 있지만, 설정이나 자격 증명을 바꾸거나 파일을 삭제할 수는 없습니다. 그러려면 관리자로 로그인한 웹 페이지가 필요합니다.

**설정 → 앱 연동 → 모든 기기에서 로그아웃**은 내 모든 앱의 연결을 해제하고 이 브라우저를 포함한 모든 브라우저에서 로그아웃시킵니다. 로그인, 계정, 잊어버린 비밀번호는 [사용자와 로그인](users.md)에 있습니다.

## 네트워크에서 서버 찾기

서버는 로컬 네트워크에 자신을 알립니다(mDNS / Bonjour, `_downtify._tcp`). 그래서 앱은 아무것도 입력하지 않아도 **이 네트워크에서 찾음** 아래에 서버의 이름, 주소, 버전을 나열합니다. 이름은 **설정 → 앱 연동 → 서버 이름**에서 정한 것입니다(바꾸기 전에는 머신의 호스트 이름).

::: info Docker 기본 네트워크는 알림을 숨깁니다
Docker의 기본 *bridge* 네트워크에서는 알림이 Docker 안에 머물러 휴대폰이 보지 못합니다. 컨테이너를 `network_mode: host`로 실행하거나([Docker Compose](../getting-started/docker-compose.md#finding-the-server-from-the-apps) 참고) 앱에 서버 주소를 직접 입력하세요 — 나머지는 똑같이 동작합니다.
:::

알리기를 멈추려면 `DOWNTIFY_DISCOVERY=false`로 설정하세요.

## 스트리밍 품질

앱은 파일을 있는 그대로(**원본**) 재생하거나 서버에 더 작은 사본을 요청합니다. 96–320 kbps의 Opus, AAC, MP3이며 모바일 데이터에서 유용합니다. 서버는 곡이 그렇게 처음 재생될 때 ffmpeg로 사본을 만들고(보통 곡이라면 몇 초) 보관하므로, 탐색은 다른 파일처럼 동작하고 다음 재생은 즉시 됩니다.

- 이미 충분히 작은 파일(요청한 비트레이트 이하의 손실 파일)은 있는 그대로 스트리밍되며 재인코딩되지 않습니다.
- 사본은 `/data/transcode_cache`에 기본 최대 2 GB까지 보관되며, 가장 오래 재생되지 않은 것부터 삭제됩니다. 한 번에 최대 두 개까지 만듭니다. 두 제한 모두 [환경 변수](../getting-started/environment-variables.md#mobile-apps-and-sign-in)입니다.
- 사본을 만드는 도중 휴대폰이 포기하면 서버도 만들기를 멈춥니다.

## 볼륨 정규화

Android 앱도 웹 플레이어와 같은 측정값으로 곡을 비슷한 음량으로 재생할 수 있습니다. 앱의 **Settings → Playback**에서 **Normalize volume**을 켜세요. 다음 곡부터 적용되며, 측정값이 없는 곡은 원래 음량으로 재생됩니다. 오프라인 사본은 전체를 다운로드했고 서버가 측정한 파일과 일치할 때만 측정값을 사용합니다. [볼륨 정규화](playback-normalization.md)를 참고하세요.

## 캐스트

앱은 곡을 Chromecast나 오디오를 스스로 가져오는 다른 플레이어로 보낼 수 있습니다. 앱은 서버에서 그 곡 하나에 대해 제한된 시간(기본 한 시간) 동안, 그리고 휴대폰이 연결된 상태일 때만 유효한 링크를 받으며, 휴대폰의 키는 그 안에 들어가지 않습니다.

## 리버스 프록시 뒤에서

Downtify가 nginx, Caddy, Traefik 등의 뒤에 있다면(HTTPS를 위해서나 외부에서 접속하기 위해):

- **WebSocket을 통과시키세요.** `/api/ws`는 `Upgrade`/`Connection` 헤더가 전달되어야 합니다(Caddy와 Traefik은 기본으로 그렇게 하고, nginx는 `proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade";`가 필요합니다).
- **Range 요청**을 그대로 통과시키고 오디오 응답을 버퍼링하지 마세요(nginx: `/api/v1/`과 `/downloads/`에 `proxy_buffering off;`). 그렇지 않으면 탐색과 큰 파일에 문제가 생깁니다.
- **어느 프록시를 신뢰할지 Downtify에 알려 주세요.** `DOWNTIFY_TRUSTED_PROXIES`를 프록시의 주소(예: `172.18.0.0/16`)로 설정하세요. 그래야만 Downtify가 클라이언트 주소(시도 제한, 연결된 앱 기기의 "마지막 확인")에 `X-Forwarded-For`를, 로그인 쿠키를 secure로 표시하고 요청의 출처를 확인하는 데 `X-Forwarded-Proto`/`X-Forwarded-Host`를 사용합니다. 설정하지 않으면 이 헤더들은 무시됩니다 — 누구나 보낼 수 있기 때문입니다.
- 서버가 외부에서 접근 가능하다면 **HTTPS를 사용하세요**. 비밀번호와 앱의 키가 모든 요청과 함께 오갑니다.

## 앱 개발자를 위해

앱이 따르는 전체 흐름 — 검색, 연결, 라이브러리 동기화, 스트리밍, 재생 보고 — 은 [모바일 클라이언트 규약](../mobile-client-contract.md)에 있으며, 모든 엔드포인트는 [API 레퍼런스](../api-reference.md#server-and-sign-in)에 있습니다.
