# 유사 음악

**유사 음악**은 YouTube Music 자체의 라디오 믹스(YouTube가 내 트랙 다음에 재생해 주는 곡)를 이용해, 입력한 트랙과 비슷한 소리의 곡을 찾아 줍니다. API 키도, 별도 설정도 필요 없습니다.

## 사용 방법

사이드바에서 **유사 음악**을 엽니다(**차트** 아래, 휴대폰에서는 **더보기** 시트에 있습니다). **아티스트**나 **트랙**을 입력하고(둘 중 하나면 충분하며, 아티스트만 입력하면 대표 히트곡에서 시작합니다) **유사 음악 찾기**를 누르세요.

직접 입력하지 않아도 됩니다. 앱의 모든 트랙 행에는 **유사 음악** 버튼이 있습니다(다운로드 버튼 옆의 지팡이 아이콘이며, 검색·차트·둘러보기에서는 다운로드 버튼처럼 채워진 모양, 인기곡과 붙여넣은 링크에서는 은은한 아이콘, 라이브러리·앨범·아티스트·재생목록의 트랙에서는 컨텍스트 메뉴 항목입니다). 누르면 해당 트랙을 이미 검색한 상태로 이 페이지가 열립니다. 검색 결과는 다운로드 없이 행에서 바로 전체 재생할 수도 있습니다.

- **전체 재생** — 커버를 탭하면 다운로드 여부와 관계없이 이 서버에서 내장 플레이어로 곧바로 스트리밍됩니다.
- **다운로드** — 모든 행에는 이미 해당 영상이 연결되어 있어 바로 다운로드됩니다. Downtify는 다른 모든 다운로드와 같은 [매칭 파이프라인](../how-it-works.md)으로 결과를 대기열에 넣습니다. 그 뒤로 행에는 그 다운로드의 진행 상황이 표시되고, 곡이 라이브러리에 들어오면 체크 표시가 나타납니다.
- **끝없는 목록** — 끝까지 스크롤하면 마지막 트랙의 믹스에서 다음 페이지를 불러오며, 마지막 행을 지나 재생해도 같은 방식으로 대기열이 끝없이 늘어납니다.
