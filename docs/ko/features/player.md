# 내장 플레이어

Downtify에는 웹 플레이어가 포함되어 있어 별도의 앱 없이 내려받은 음악을 들을 수 있습니다. 라이브러리의 트랙, 앨범, 아티스트, 재생목록 — 또는 대기열의 완료된 다운로드 — 에서 재생을 누르면 플레이어가 시작됩니다.

## 플레이어 바

트랙이 로드되어 있는 동안 모든 페이지 아래쪽에 플레이어 바가 떠 있습니다: 커버, 제목과 아티스트, 셔플, 이전, 재생/일시정지, 다음, 반복, 경과/전체 시간, 그리고 가사와 다음 재생 곡 패널로 가는 단축 버튼(가사 버튼은 [숨길](#hiding-the-lyrics) 수 있음)이 있습니다. 넓은 화면에서는 볼륨 슬라이더와 위쪽 가장자리를 따라 탐색 바도 있고, 휴대폰에서는 핵심만 남기고 가는 진행선을 표시합니다.

제목 옆에는 [곡에 좋아요](liked-songs.md)를 누르는 하트가 있습니다. 휴대폰에서는 제목 공간을 위해 바에서 빼고 **현재 재생 중**과 트랙 목록에 둡니다.

제목이나 커버, 또는 확대 버튼을 클릭하면 **현재 재생 중**이 열립니다.

## 현재 재생 중

현재 앨범 커버에서 뽑은 색으로 물든 전체 화면 보기입니다.

- **큰 커버**, 제목, 아티스트(아티스트나 *재생 출처* 라벨을 클릭하면 해당 아티스트, 앨범, 재생목록으로 이동), 제목 옆에 [곡에 좋아요](liked-songs.md)를 누르는 하트. 커버와 가사는 창 크기에 따라 줄어들어 — 높이만 바꿀 때도 — 헤더 아래에 머뭅니다.
- **탐색 바** — 클릭하거나 끌고, 포커스가 있을 때는 화살표 키를 사용합니다. 트랙이 재생되는 동안 앨범 커버에서 뽑은 색의 부드러운 물결이 재생된 부분 위를 흐르며, 일시정지하면 평평해지고 시스템이 동작 줄이기를 요청하면 멈춰 있습니다
- **재생 컨트롤** — 셔플, 이전, 재생/일시정지, 다음, 반복(끔 → 전체 반복 → 한 곡 반복)
- **볼륨**과 음소거 버튼, 세션 간에 저장됩니다. 하드웨어 버튼으로 음량을 조절하는 휴대폰에서는 숨겨집니다
- **수면 타이머** — 15, 30, 45, 60, 90분 뒤 또는 현재 트랙이 끝나면 재생을 멈춥니다. 남은 시간이 타이머 버튼 옆에 표시됩니다
- **파일 정보** — 재생 중인 파일의 형식과 크기

넓은 화면에서는 네 개의 패널이 커버 옆에 놓이고, 휴대폰에서는 커버를 대신합니다.

- **가사** — 시간에 맞춘 가사는 현재 줄을 강조하고 곡과 함께 스크롤됩니다. 줄을 클릭하면 그곳으로 이동합니다. 일반 가사는 그대로 표시됩니다. 가사는 트랙 옆의 `.lrc` 파일이나 태그에 포함된 가사에서 옵니다 — [가사](lyrics.md)를 참고하세요. 이 패널은 숨길 수 있습니다 — [가사 숨기기](#hiding-the-lyrics)를 참고하세요.
- **다음 재생 곡** — 재생 대기열. 트랙을 끌어 순서를 바꾸고, 개별 트랙을 제거하거나, 현재 곡 뒤의 모든 것을 비웁니다.
- **세부정보** — 제목, 아티스트, 앨범, 트랙 번호, 연도, 길이, 형식, 크기, 추가한 날짜, 파일 경로.
- **이퀄라이저** — 열 개의 주파수 대역으로 소리를 다듬습니다. [이퀄라이저](#equalizer)를 참고하세요.

현재 재생 중은 페이지 주소의 일부이므로(`?np=1`, 그리고 `&panel=lyrics|queue|details|equalizer`), 브라우저의 뒤로 가기 버튼으로 닫히고 새로고침하면 열린 채 유지됩니다.

## 가사 숨기기

가사 없이 아트워크와 대기열을 선호하시나요? **설정 → 일반 → 플레이어 → 플레이어에 가사 표시**를 끄세요. 즉시 적용되며 플레이어에서 가사로 이어지는 모든 것을 없앱니다.

- **가사** 패널과 그 탭(휴대폰에서는 현재 재생 중 하단의 버튼)
- 플레이어 바의 가사 버튼
- `L` 단축키 — 단축키 목록(`?`)에서도 빠집니다.

그러면 현재 재생 중은 **다음 재생 곡**에서 열립니다. 끄기 전의 `&panel=lyrics` 링크도 빈 탭이 아니라 그곳으로 연결됩니다. 가사가 숨겨져 있는 동안 플레이어는 트랙의 가사를 아예 요청하지 않습니다.

::: info 숨기기는 삭제가 아닙니다
이는 플레이어가 보여주는 것만 바꿉니다. 파일에는 Downtify가 포함한 가사가 그대로 남고, 옆의 `.lrc` 파일도 제자리에 있으므로 미디어 서버와 다른 플레이어는 여전히 볼 수 있습니다. 다운로드도 계속 가사를 가져옵니다 — 그것은 **태그 및 가사** 아래의 별도 설정 **가사 다운로드**입니다([가사](lyrics.md) 참고).
:::

테마와 이퀄라이저처럼 이 선택은 브라우저(`localStorage`)에 저장되므로, Downtify 서버별이 아니라 기기별, 브라우저별입니다 — 휴대폰에서는 가사를 숨기고 데스크톱에서는 유지할 수 있습니다.

## 이퀄라이저

현재 재생 중의 **이퀄라이저** 패널(또는 `E` 누르기)에 있는 10밴드 그래픽 이퀄라이저입니다. **실험적 기능**으로 표시되어 있어 아직 바뀔 수 있고 일부 브라우저에서 제대로 동작하지 않을 수 있습니다([브라우저 지원](#browser-support) 참고).

- 31, 62, 125, 250, 500 Hz와 1, 2, 4, 8, 16 kHz의 **대역**, 각각 0.5 dB 단위로 ±12 dB. 31 Hz와 16 kHz 대역은 셸프이므로 그 아래/위의 모든 것도 높이거나 줄입니다. 대역을 끌거나, 포커스를 두고 화살표 키를 사용하세요(1 dB는 `Page Up`/`Page Down`, 한계값은 `Home`/`End`). 더블클릭하면 0으로 되돌립니다.
- **프리셋** — 플랫, 저음 강조, 고음 강조, 보컬, 록, 일렉트로닉, 어쿠스틱. 이후 어떤 대역이든 움직이면 프리셋이 **사용자 지정**으로 바뀝니다.
- **프리앰프** — 모든 것 위에 ±12 dB.
- **켜기/끄기 스위치**와 **초기화**(플랫, 프리앰프 0, 꺼짐으로 되돌림). 대역을 움직이거나 프리셋을 고르면 이퀄라이저도 켜집니다.
- 슬라이더 뒤의 곡선은 모든 대역을 합친 응답입니다.

대역을 높이면 큰 소리의 음악이 최대 레벨을 넘어 왜곡되므로, Downtify는 곡선의 가장 큰 증폭량만큼 볼륨을 자동으로 낮춥니다 — 패널에 얼마인지 표시됩니다. 이렇게 하면 피크가 0 dB에 머물러, 증폭된 프리셋이 소리를 단순히 키우는 대신 모양을 바꿉니다. 프리앰프를 0 dB 위로 올리면 이 안전 여유가 사라지며, 패널이 큰 소리 구간이 왜곡될 수 있다고 경고합니다.

설정은 브라우저(`localStorage`)에 저장되며 바꿀 때까지 모든 탭에서 재생하는 모든 것에 적용됩니다. Downtify 서버별이 아니라 브라우저별입니다.

### 브라우저 지원

이퀄라이저는 모든 최신 브라우저에서 사용할 수 있는 Web Audio API를 씁니다. 켜기 전까지 재생은 Web Audio를 전혀 건드리지 않습니다. 켜면 방문이 끝날 때까지 오디오가 그것을 거치며, 끄면 모든 대역이 평평해질 뿐입니다.

::: warning iPhone과 iPad의 Safari
iOS는 화면이 잠기거나 앱을 전환할 때 Web Audio를 일시정지할 수 있어, 이퀄라이저가 켜져 있으면 재생이 멈춥니다. 화면을 끈 채 들으신다면 이퀄라이저를 끄고 페이지를 새로고침하세요.
:::

## 대기열 구성하기

앨범, 아티스트, 재생목록, 트랙 목록을 재생하면 고른 곡부터 순서대로 그 트랙들이 대기열에 들어갑니다. 컬렉션에서 **셔플**은 무작위 순서로 시작합니다. 내려받지 않은 트랙은 서버의 스트림 캐시에서 제공되어 대기열에서 바로 전체 재생됩니다. 하나가 재생되는 동안 다음 곡은 한 곡 앞서 이미 준비되고 있어, 내려받지 않은 행들을 멈춤 없이 지나갑니다 — 브라우저가 직접 YouTube에 접근할 수 없는 곳에서도 마찬가지입니다. 스트리밍된 트랙은 저장되거나, 좋아요가 되거나, 새로고침 후에 기억되지 않습니다.

각 트랙의 메뉴(**⋯** 버튼, 데스크톱에서는 마우스 오른쪽 클릭)에는 다음이 있습니다.

- **다음 곡으로 재생** — 현재 트랙 바로 뒤에 삽입
- **대기열에 추가** — 끝에 추가
- **앨범으로 이동** / **아티스트로 이동**
- **이 기기에 저장** — 브라우저로 파일 다운로드
- **라이브러리에서 삭제**

라이브러리에서 여러 트랙을 선택했을 때도 같은 동작이 적용됩니다.

대기열, 현재 트랙, 위치, 셔플과 반복은 기억되므로 Downtify를 다시 열면 중단한 곳에서 이어집니다(2000곡이 넘는 대기열은 기억되지 않음). 삭제된 파일은 대기열에서 자동으로 빠집니다.

## 키보드와 미디어 키

| 키 | 동작 |
|-----|--------|
| `Space` | 재생 / 일시정지 |
| `←` / `→` | 5초 탐색 |
| `Shift` + `←` / `→` | 이전 / 다음 트랙 |
| `↑` / `↓` | 볼륨 |
| `M` | 음소거 |
| `S` | 셔플 |
| `R` | 반복 |
| `L` | 가사 열기([숨김](#hiding-the-lyrics)이 아닐 때) |
| `Q` | 다음 재생 곡 열기 |
| `E` | 이퀄라이저 열기 |
| `Ctrl` / `⌘` + `K` 또는 `/` | 검색 |
| `Ctrl` / `⌘` + `F` | 재생목록 검색 (재생목록 페이지에서) |
| `G` 다음 `L` / `D` | 라이브러리 / 대기열로 이동 |
| `Esc` | 현재 재생 중 닫기 |
| `?` | 모든 단축키 표시 |

필드에 입력 중이거나 대화상자가 열려 있을 때는 단축키가 무시됩니다.

플레이어는 현재 트랙을 운영 체제(Media Session)에도 알리므로, 잠금 화면 컨트롤, 헤드셋 버튼, 키보드 미디어 키가 작동하며, 시스템이 지원하는 곳에서는 커버가 표시됩니다.

## 작동 방식

트랙은 각 파일의 태그에서 제목, 아티스트, 앨범, 트랙 번호, 연도, 길이를 읽는 라이브러리 목록(`GET /tracks`)에서 옵니다. 파일은 `/downloads` 정적 마운트에서 제공되며, [그대로 둔](slskd-navidrome.md#leave-files-in-place) slskd 다운로드는 `/media/slskd/…`를 통해 재생됩니다. 커버는 `/cover`에서, 가사는 `/lyrics`에서 옵니다 — [API 레퍼런스](../api-reference.md#file-management)를 참고하세요.

재생은 브라우저 기본 HTML5 오디오를 씁니다. 플러그인도, 추가 프로세스도 없습니다.

## 지원 형식

플레이어는 브라우저의 HTML5 오디오 엔진이 지원하는 모든 형식을 재생할 수 있습니다. 보통 모든 최신 브라우저에서 MP3, M4A/AAC, OGG, OPUS가 포함됩니다. FLAC 지원은 다양합니다 — Chrome과 Edge는 기본 지원하고, Firefox와 Safari는 지원하지 않을 수 있습니다.
