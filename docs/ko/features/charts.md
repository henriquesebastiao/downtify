# 차트

**차트**는 Deezer가 직접 집계한 글로벌 차트(장르 필터 없이 지금 전 세계에서 인기를 끄는 곡)를 보여 줍니다. Deezer 계정이나 API 키는 필요 없습니다.

## 사용 방법

사이드바(휴대폰에서는 **더보기** 시트)에서 **차트**를 엽니다. 네 개의 탭이 같은 차트를 읽습니다: **트랙**, **앨범**, **아티스트**, **재생목록**.

- **트랙** — 순위가 매겨진 목록입니다. 다운로드하기 전에 하나를 누르거나(또는 행을 탭하면) YouTube에서 전체를 내장 플레이어로 바로 스트리밍해 들을 수 있습니다. 행을 다운로드하는 방식은 검색 결과와 같습니다. Downtify는 트랙의 제목, 아티스트, 길이에 가장 잘 맞는 결과를 YouTube Music(없으면 일반 YouTube)에서 찾으며, 다른 모든 다운로드와 같은 [매칭 파이프라인](../how-it-works.md)을 씁니다. 트랙이 다운로드되면 그 행은 스트리밍하는 대신 라이브러리에 있는 파일을 재생합니다.
- **앨범**, **아티스트**, **재생목록** — 커버 아트 그리드입니다. 하나를 클릭하면 해당 Deezer 링크를 검색창에 직접 붙여넣은 것과 똑같이 해석되고([`GET /api/url/resolve`](../api-reference.md#get-apiurlresolve)), 트랙 목록이 불러와져 바로 고르고 다운로드할 수 있습니다.

## 트랙은 여기서 바로 다운로드되고(전체 재생도 되고), 앨범·아티스트·재생목록은 먼저 페이지가 열리는 이유

차트의 트랙은 다운로드하는 데 해석 단계가 필요 없습니다. Deezer가 이미 제목, 아티스트, 앨범 이름을 알려 주므로, 자유 입력 검색 결과와 마찬가지로 YouTube에서 검색하고 매칭하기에 충분합니다. 반면 앨범, 아티스트, 재생목록은 링크를 트랙 목록으로 바꾸는 해석 단계가 필요하므로, 그리드에서 바로 다운로드하지 않고 해석된 페이지를 엽니다. 트랙 행을 재생하면 YouTube에서 전체를 스트리밍합니다(앨범, 아티스트, 재생목록에는 해당하지 않습니다). 다른 모든 트랙 행과 같은 스트리밍이며, 차트의 제목과 아티스트를 넘겨 줄 뿐입니다.
