# 기능

Downtify는 Spotify에서 로컬 음악 라이브러리를 만들고 유지하는 데 필요한 모든 것을 다룹니다.

## 개요

| 기능 | 하는 일 |
|---------|-------------|
| [차트](charts.md) | Deezer의 글로벌 차트를 둘러보고 인기 있는 곡을 내려받기 |
| [유사 음악](similar.md) | 아티스트나 트랙을 입력하면 YouTube Music이 전체 재생과 다운로드가 가능한 비슷한 트랙을 알려 줍니다. 키 불필요 |
| [파인더](finder.md) | Deezer를 검색한 뒤 아티스트, 앨범, 앨범의 트랙을 열 단위로 탐색 |
| [다운로드 설정](download-settings.md) | 형식(MP3/FLAC/M4A/OGG/OPUS), 비트레이트, 동시 다운로드, 다운로드 간격 선택 |
| [다운로드 대기열](download-queue.md) | 설정을 바꾸거나 업데이트하기 전에 다운로드를 일시 중지: 진행 중인 다운로드는 끝나고, 새 다운로드는 시작되지 않으며, 대기 중인 곡은 다시 시작해도 유지 |
| [재생목록 모니터](playlist-monitor.md) | Spotify 또는 YouTube Music 재생목록과 아티스트를 지켜보다가 새 트랙과 발매작을 자동으로 내려받기 |
| [재생목록에서 숨긴 곡](hidden-playlist-songs.md) | 다운로드했거나 감시 중인 재생목록에서 원하지 않는 곡을 빼고 다시 들어오지 않게 합니다. 파일은 라이브러리에 남습니다 |
| [인기곡](top-songs.md) | 아티스트 링크를 붙여넣고 가장 인기 있는 곡을 내려받기(재생목록으로도 가능) |
| [라이브러리 가져오기(CSV)](library-import.md) | Soundiiz, TuneMyMusic, Exportify의 라이브러리 내보내기 파일을 가져와 전체를 대기열에 넣기 |
| [내장 플레이어](player.md) | 브라우저에서 라이브러리 재생: 대기열 관리, 동기화 가사, 수면 타이머, 키보드와 미디어 키 |
| [좋아요 표시한 곡](liked-songs.md) | 하트를 눌러 곡을 좋아요 표시하면 좋아요 한 곡의 재생목록이 저절로 생김 |
| [팟캐스트](podcasts.md) | RSS 피드, Spotify 링크 또는 이름으로 프로그램을 구독하면 새 에피소드가 자동으로 내려받아지고 태그가 입력됨 |
| [사용자와 로그인](users.md) | 사용자 이름과 비밀번호로 로그인(새 서버에서는 `admin` / `downtify`), 관리자와 일반 사용자 계정, 사용자별 설정, 로그인과 각자 듣는 곡의 활동 로그 |
| [성인 콘텐츠 표시](explicit-marker.md) | 노골적인 가사가 있는 곡 옆의 "E" — 검색, 라이브러리, 플레이어에서, 그리고 파일 태그에 |
| [음원 교체](replace-audio.md) | 곡이나 버전이 틀렸나요? YouTube Music이나 YouTube에서 맞는 것을 고르세요. 파일은 이름, 태그, 재생목록을 유지합니다 |
| [서버 설정](server.md) | Downtify가 수신하는 포트를 설정(관리자)에서 변경하고, 원하면 즉시 재시작 |
| [모바일 앱](mobile-apps.md) | QR 코드로 휴대폰 앱을 페어링하고 라이브러리를 스트리밍(원본 또는 트랜스코딩) |
| [둘러보기](discover.md) | 라이브러리, 좋아요, 청취 기록을 바탕으로 아직 없는 아티스트, 앨범, 재생목록을 추천받고 원치 않는 것은 숨기기 |
| [slskd와 Navidrome](slskd-navidrome.md) | slskd로 Soulseek에서 내려받고, 재생목록을 Navidrome에 반영하고, 재생목록 다운로드 추적 |
| [라이브러리 카탈로그와 경로 동기화](library-catalog.md) | Downtify가 라이브러리 파일과 재생목록을 추적하는 방식, 라이브러리에서 만드는 재생목록, 파일을 옮긴 뒤의 경로 수정 |
| [기존 음악 폴더](external-library.md) | 이미 가지고 있는 오디오 폴더를 Downtify에 지정. 동기화가 태그를 읽고 아티스트를 매칭하며 라이브러리에 이미 있는 곡은 건너뜀 |
| [라이브러리 업그레이드](library-upgrade.md) | 이미 내려받은 음악을 스캔해 작은 커버, 없는 가사, 불완전한 태그를 수리 |
| [M3U 내보내기](m3u-export.md) | Jellyfin, Navidrome, Plex 및 모든 미디어 앱을 위한 자동 생성 재생목록 파일 |
| [재생목록 커버 아트](playlist-cover-art.md) | 재생목록 고유의 커버 이미지를 M3U 파일 옆에 저장 |
| [아티스트 사진, 배너, 소개](artist-images.md) | YouTube Music, Deezer, Spotify 또는 직접 업로드한 실제 사진과 배너를 아티스트에 지정하고, Apple Music과 Deezer에서 소개, 출신지, 링크를 자동 또는 수동으로 가져오기 |
| [아티스트 응원하기](support-artists.md) | 곡, 앨범, 아티스트를 어디서 살 수 있는지 확인합니다: 가격이 표시된 iTunes Store 항목, Bandcamp와 Qobuz, 아티스트 웹사이트 |
| [파일 정리](file-organization.md) | 평면 구조 또는 아티스트별 하위 폴더 |
| [가사](lyrics.md) | 가사(일반 및 시간 동기화)를 자동으로 내려받아 포함. `.lrc`는 파일 옆 또는 지정한 폴더에 |
| [YouTube 쿠키](youtube-cookies.md) | 웹 UI에서 `cookies.txt`를 업로드해 선정적/연령 제한 트랙을 내려받기 |
| [다국어 지원](internationalization.md) | 영어와 9개 언어를 기본 제공하고, 문서도 모두 번역 |
| [업데이트 알림](updates.md) | GitHub Releases를 매시간 확인. 새 버전이 나오면 사이드바에 알림 표시 |

## 입력 유형

Downtify는 검색창에서 여러 유형의 입력을 받습니다.

| 입력 | 예 |
|-------|---------|
| Spotify 트랙, 앨범, 재생목록 또는 아티스트 URL | `https://open.spotify.com/track/…` |
| YouTube / YouTube Music URL | `https://www.youtube.com/watch?v=…` |
| YouTube Music 재생목록 또는 아티스트 URL | `https://music.youtube.com/playlist?list=…` |
| Deezer 트랙, 앨범, 재생목록 또는 아티스트 URL | `https://www.deezer.com/track/…` |
| 자유 입력 검색 | `The Night Owls Do I Still Recall` |

자유 입력 검색은 YouTube Music으로 바로 전달됩니다. Spotify 링크는 필요 없습니다.
