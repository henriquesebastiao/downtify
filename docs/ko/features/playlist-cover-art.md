# 재생목록 커버 아트

Downtify는 재생목록 고유의 커버를 [M3U 파일](m3u-export.md) 옆에 저장할 수 있어, 미디어 서버와 파일 탐색기가 일반 아이콘 대신 재생목록의 실제 이미지를 보여 줍니다.

기본으로 켜져 있습니다. **설정 → 다운로드 및 파일 → 재생목록 커버 아트 저장**에서 끌 수 있습니다.

## 파일이 놓이는 위치

커버는 **재생목록의 M3U와 같은 이름, 같은 폴더**에 확장자만 `.jpg`로 해서 기록됩니다.

```
<downloads>/<재생목록-이름>/<재생목록-이름>.m3u
<downloads>/<재생목록-이름>/<재생목록-이름>.jpg
```

*아티스트별로 정리* 또는 *앨범별로 정리*가 켜져 있으면 트랙이 아티스트 폴더에 흩어지고 M3U는 중앙의 `Playlists/` 디렉터리로 가며([파일 정리](file-organization.md) 참고), 커버도 함께 갑니다.

```
<downloads>/Playlists/<재생목록-이름>.m3u
<downloads>/Playlists/<재생목록-이름>.jpg
```

::: info M3U가 필요합니다
**M3U 재생목록 생성**이 꺼져 있으면 커버도 저장되지 않습니다. Downtify는 M3U의 경로를 기준으로 이미지를 놓으므로, M3U가 없으면 둘 곳이 없습니다. M3U 작성이 꺼져 있는 동안에는 이 설정이 숨겨집니다.
:::

## 출처와 해상도

| 출처 | 해상도 |
|--------|-----------|
| **Spotify** | 공개 임베드 페이지가 재생목록에 제공하는 가장 큰 이미지 — 트랙 커버에 이미 쓰는 것과 같은 이미지 |
| **YouTube Music** | 트랙별 커버에만 영향을 주는 [커버 아트 해상도](download-settings.md#cover-art-resolution)와 관계없이 항상 1200×1200으로 요청 |

두 서비스 모두 원본이 PNG여도 이 URL에는 JPEG를 제공하므로, 파일은 항상 `.jpg`로 저장됩니다.

## 다운로드되는 시점

두 경우 모두 **트랙보다 먼저** 받습니다. 폴더가 채워지는 동안 이미 재생목록처럼 보이고, 다운로드 도중 스캔하는 미디어 서버도 빈 폴더 대신 이미지를 찾습니다.

- **수동 재생목록 다운로드** — 재생목록 이름이 확인되면 첫 트랙이 시작되기 전에 한 번.
- **[재생목록 모니터](playlist-monitor.md)** — 내려받을 것이 있는 점검마다, 그 점검의 첫 트랙 전에 한 번. 새로운 것이 없는 점검은 다시 가져오지 않습니다.

커버를 확인하거나 내려받지 못해도(네트워크 오류, 이미지가 없는 재생목록) 기록만 남기고 건너뛰며, 다운로드 자체를 지연시키거나 실패시키지 않습니다.

## Downtify 인터페이스에서

고유 이미지가 있는 재생목록(Spotify나 YouTube 재생목록과 함께 다운로드한 것)은 라이브러리가 재생목록을 나열하는 모든 곳(격자, 재생목록 페이지, 사이드바, 플레이어)에서 그 이미지를 보여 줍니다. 이미지가 없는 재생목록과 라이브러리에서 직접 만든 재생목록은 서로 다른 트랙 커버 최대 네 장의 모자이크를 보여 줍니다. 두 장은 나란히, 세 장은 왼쪽에 긴 타일 하나와 오른쪽에 쌓인 두 개, 네 장은 2×2 격자입니다. 같은 콜라주는 Navidrome도 볼 수 있도록 수동 재생목록의 M3U 옆에 `<재생목록-이름>.jpg`로 기록되고, 곡을 추가하거나 제거할 때마다 다시 만들어집니다.

## Navidrome

설정할 것은 없습니다. Navidrome은 재생목록 이미지를 **사이드카 이미지**(같은 폴더에 있는 재생목록 이름의 파일)에서 가져오며, Downtify가 기록하는 것이 바로 그 파일입니다. Navidrome의 음악 폴더가 다운로드 폴더를 포함하는 한, 다음 스캔 때 이미지가 나타납니다. Downtify의 API 호출은 관여하지 않습니다. [slskd와 Navidrome](slskd-navidrome.md#navidrome)을 참고하세요.

## 정리

라이브러리 페이지에서 재생목록을 삭제하면 M3U 및 트랙과 함께 커버도 삭제됩니다. [재생목록 삭제](slskd-navidrome.md#deleting-a-playlist)를 참고하세요.
