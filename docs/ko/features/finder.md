# Finder

**Finder**는 다운로드하기 전에 Deezer 카탈로그를 둘러보는 방법입니다. Deezer에서 검색한 뒤 아티스트를 열면, macOS Finder의 열 보기처럼 세 개의 열이 나란히 나타납니다. 아티스트, 디스코그래피, 그리고 한 앨범의 트랙입니다. Deezer 계정이나 API 키는 필요 없습니다.

## 검색

사이드바에서 **둘러보기**를 여세요(휴대폰에서는 **더보기 → 둘러보기**). Finder의 검색창이 페이지 맨 위에 있고, 그 옆에 최근 Finder 검색이 표시됩니다. 검색하면 둘러보기의 추천 대신 검색 결과가 나타납니다. 곡, 앨범, 아티스트를 **전체 / 곡 / 앨범 / 아티스트** 칩으로 나눠 볼 수 있으며, 일반 검색 페이지와 같지만 Deezer 결과만 보여줍니다. 추천을 다시 보려면 검색창을 비우거나(**×**) 뒤로 가세요. 최근 검색은 한 번 클릭으로 다시 실행되고, **지우기**는 모두 지웁니다. 최근 검색은 이 브라우저에만 저장됩니다.

둘러보기가 추천한 아티스트의 **⋯** 메뉴에 있는 **곡 찾기**는 그 아티스트의 곡을 검색 결과처럼 여기에 보여줍니다. Deezer에서 아티스트 이름으로 검색한 뒤, 바로 그 아티스트의 곡만(Deezer id로 대조하므로 동명이인이나 이름만 같은 곡은 제외됩니다) 처음 수백 곡까지 나열합니다.

- **곡**은 전체를 스트리밍하며 다른 검색 결과처럼 다운로드할 수 있습니다. Downtify는 제목, 아티스트, 길이로 YouTube Music(없으면 YouTube)에서 곡을 찾아 맞춥니다. 곡 제목을 클릭하면 열 보기에서 해당 곡이 강조된 채 그 앨범이 열립니다.
- **앨범**은 해당 앨범이 선택된 채 아티스트 화면에서 열립니다. 커버의 다운로드 버튼은 앨범 전체를 대기열에 추가합니다.
- **아티스트**는 그 아티스트로 열 보기를 엽니다.

## 열 보기

| 열 | 표시 내용 |
| --- | --- |
| **아티스트** | 아티스트 사진과 앨범 수, 인터페이스 언어의 소개글(펼치기 가능), 가장 인기 있는 트랙 10곡, "유사 아티스트"(관련 아티스트). |
| **디스코그래피** | 모든 앨범, 싱글, EP, 컴필레이션을 최신순으로, 커버, 제목, 발매 유형, 연도, 트랙 수와 함께 보여줍니다. 칩으로 발매 유형별로 거를 수 있습니다. |
| **트랙** | 선택한 앨범의 커버와 제목, 아티스트, 연도, 트랙 수, 길이. 정보 패널에는 발매일, 레이블, 장르, 크레딧, UPC가 나열됩니다. 그 아래에 앨범의 트랙이 있고, 각 트랙은 다운로드되기 전까지 전체를 스트리밍하다가 이후에는 라이브러리에서 재생되며, **앨범 다운로드** 버튼으로 모두 대기열에 추가할 수 있습니다. |

인기 트랙을 클릭하면 그 앨범이 선택되고 트랙이 강조됩니다. 두 열은 부드럽게 스크롤되어 화면에 들어오며(시스템이 동작 줄이기로 설정되어 있으면 즉시), 앨범의 트랙이 화면에 나타나면 트랙이 전체 재생을 시작합니다. 스트리밍이거나, 이미 라이브러리에 있다면 그 곡 자체입니다. 재생 중에 다시 클릭해도 일시정지되지 않으며, 트랙을 가리키는 링크로 페이지를 열면 아무것도 시작되지 않습니다. 관련 아티스트를 클릭하면 그 아티스트가 열리고, 브라우저의 뒤로 가기 버튼으로 이전 아티스트로 돌아갑니다. 열 위의 경로 표시줄(**둘러보기 › 아티스트 › 앨범**)은 검색(열이 검색에서 열린 게 아니라면 둘러보기)이나 아티스트로만 돌아가게 해 줍니다. 열려 있는 내용은 URL에 저장되므로 새로고침해도 유지되고 북마크할 수 있습니다.

넓은 화면에서는 두 열 사이의 경계를 끌어서 열을 넓히거나 좁히고, 경계에 포커스를 둔 채 화살표 키를 써도 됩니다. 더블클릭하면 기본 너비로 돌아갑니다. 아티스트 열과 디스코그래피 열 맨 위의 화살표 버튼은 열을 이미지만 남기고 접습니다. 아티스트 사진, 인기 트랙의 커버, 관련 아티스트의 사진, 또는 앨범 커버입니다. 각 이미지는 여전히 전체 행처럼 동작하고, 이름은 마우스를 올리면 표시됩니다. 너비와 접힌 열은 페이지에 있는 동안만 유지됩니다. 저장되지 않으므로 새로고침하거나 Finder를 떠나면 초기화됩니다.

휴대폰에서는 열이 나란히 놓이고 스와이프로 오갑니다. 앨범을 고르면 그 트랙으로 넘어갑니다.

::: info 트랙 수가 잠시 뒤에 나타나는 이유
Deezer의 디스코그래피 목록에는 트랙 수가 없어서, Downtify는 앨범마다 따로, 한 번에 몇 개씩, Deezer의 5초당 50회 요청 제한 아래에서 가져옵니다. 숫자는 보는 동안 나타나고 Downtify가 재시작될 때까지 기억됩니다. 수를 가져오지 못한 앨범은 `…`로 표시됩니다.
:::
