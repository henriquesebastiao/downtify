# 좋아요 표시한 곡

곡의 하트를 탭하면 좋아요가 표시됩니다. 곡 하나라도 좋아요를 누르면 Downtify가 좋아요 표시한 모든 곡을 담은 **좋아요 표시한 곡** 재생목록을 유지하므로, 즐겨 듣는 곡을 한 번의 클릭으로 열 수 있습니다. Downtify에서도, 라이브러리를 가리키는 모든 미디어 서버에서도 마찬가지입니다.

따로 켤 것은 없습니다.

하트는 누른 사람의 것입니다. 계정이 여러 개인 서버에서는 각자 자기만의 좋아요 곡을 가집니다([사용자와 로그인](users.md#your-library) 참고). 디스크의 재생목록 파일에는 관리자의 하트가 담기고, 다른 모든 사람의 좋아요는 라이브러리 데이터베이스에 저장되며 앱에서도 똑같이 동작합니다.


## 곡에 좋아요 누르기

하트는 라이브러리의 모든 곡 옆에 있습니다. 다운로드한 곡과 [기존 음악 폴더](external-library.md)의 트랙 모두 해당됩니다.

- 트랙 목록(라이브러리, 앨범, 아티스트, 재생목록)에서
- [플레이어 바](player.md#player-bar)에서(너비 640px 이상 화면)
- [지금 재생 중](player.md#now-playing)에서, 곡 제목 옆에

탭하면 좋아요, 다시 탭하면 취소됩니다. 초록색으로 채워지고 변경 사항은 즉시 서버에 반영되므로, 휴대폰에서 누른 하트가 데스크톱에도 그대로 나타납니다. 열려 있는 탭과 기기도 알아서 따라옵니다.

라이브러리에 있는 곡만 좋아요를 누를 수 있습니다. 아직 다운로드하지 않은 검색 결과에는 하트가 없으니 먼저 다운로드하세요.

## 재생목록

첫 번째 좋아요가 재생목록을 만들고, 짧은 알림이 열어 볼지 물어봅니다. 사이드바, 홈 페이지, **라이브러리 → 재생목록**에서 다른 재생목록처럼 표시되지만 항상 **맨 앞**에 놓이고, 커버 대신 하트가 표시됩니다. 곡은 가장 최근에 좋아요를 누른 순서로 맨 위부터 정렬됩니다.

마지막 좋아요를 취소하면 재생목록도 다시 사라지므로, 빈 **좋아요 표시한 곡**이 남아 있는 일은 없습니다.

제목은 [언어](internationalization.md) 설정을 따릅니다. 디스크에서 재생목록은 이름이 고정된 일반 [M3U 파일](m3u-export.md)입니다.

```
<downloads>/Playlists/Downtify Liked Songs.m3u
```

Jellyfin, Navidrome, Plex 등이 이것을 보여 주는 이유도 같은 파일을 읽기 때문입니다. 이름은 일부러 예약되어 있습니다. Spotify에는 *Liked Songs*라는 이름의 재생목록이 흔한데, 같은 이름으로 다운로드한 재생목록이 있으면 같은 파일에 덮어쓰게 되기 때문입니다.

## 모든 좋아요 삭제

재생목록을 열고 **⋯ → 모든 좋아요 삭제**를 선택한 뒤 확인하세요. 모든 하트가 지워지고 재생목록이 사라집니다.

::: info 곡은 그대로 남습니다
좋아요를 삭제해도 오디오는 지워지지 않습니다. 하트와 재생목록만 제거되며 파일은 라이브러리에 그대로 있습니다. 다운로드한 재생목록을 삭제하면 그 곡들이 삭제되는 것과는 다르며, **좋아요 표시한 곡**은 절대 그렇게 처리되지 않습니다. 삭제를 요청하면(앱에서든 [API](../api-reference.md#delete-apilibraryplaylist)로든) 좋아요만 지워집니다.
:::

## 좋아요를 파일과 맞춰 두기

좋아요는 눌렀던 파일을 따라갑니다.

| 파일에 일어나는 일 | 좋아요에 일어나는 일 |
|--------------------------|--------------------------|
| Downtify에서 곡을 삭제함 | 좋아요도 함께 사라지고 재생목록이 다시 작성됨 |
| 파일을 옮기고 [라이브러리 경로 수정](library-catalog.md#fix-library-paths)을 실행함 | 좋아요가 파일을 따라 새 위치로 이동함 |
| Downtify 밖에서 사라짐(마운트 해제된 드라이브, 수동 삭제) | 좋아요는 유지되지만, 파일이 돌아올 때까지 곡은 재생목록에서 빠짐 |

없는 파일의 좋아요를 유지하므로, 드라이브를 잠시 분리해도 하트를 잃지 않습니다. 파일을 직접 삭제했고 좋아요도 없애고 싶다면 **모든 좋아요 삭제**를 쓰거나, 곡을 삭제하기 전에 좋아요를 취소하세요.

## 알아 두면 좋은 점

- 좋아요는 오디오 파일이 아니라 라이브러리 데이터베이스(`/data` 볼륨의 `downtify_library.db`)에 저장됩니다. 곡의 태그에는 아무것도 기록되지 않습니다.
- 이 재생목록은 Downtify가 [Navidrome](slskd-navidrome.md)에 만들지 않습니다. 일반 M3U 파일이므로 미디어 서버가 이것으로 무엇을 하는지는 그 서버가 M3U 파일을 읽는 방식에 달려 있습니다.
- 다운로드 설정에서 *M3U 재생목록 작성*이 꺼져 있어도 [재생목록 파일](m3u-export.md)은 작성됩니다. 이 기능의 핵심이 재생목록이기 때문입니다.

## API

`GET /api/likes`, `PUT /api/likes`, `POST /api/likes/clear`와 [`GET /playlists`](../api-reference.md#get-playlists)의 `liked` 플래그가 있습니다. [API 레퍼런스](../api-reference.md#likes)를 참고하세요.
