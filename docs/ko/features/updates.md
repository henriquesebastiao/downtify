# 업데이트 알림

Downtify는 한 시간에 한 번 자체 [GitHub Releases 페이지](https://github.com/henriquesebastiao/downtify/releases)를 확인합니다. 더 새로운 버전이 나오면 모든 페이지의 사이드바 하단에 알림이 표시되고, 휴대폰에서는 **더보기** 탭에 점이, 그 시트 상단에 안내 줄이 나타납니다. **설정 → 정보**에서도 확인할 수 있습니다.

> ✦ 3.0.1 업데이트 사용 가능

클릭하면 해당 릴리스가 GitHub에서 열립니다.

## 작동 방식

- 백엔드의 백그라운드 작업(`downtify/update_check.py`)이 시작 직후 한 번, 그 뒤로는 매시간 GitHub API에서 최신 릴리스를 가져옵니다. "실행하고 잊는" 방식이라 UI는 이를 기다리지 않습니다.
- 웹 UI는 한 시간에 한 번 `GET /api/check_update`([API 레퍼런스](../api-reference.md) 참고)에서 캐시된 결과를 읽고, 더 새로운 버전이 있으면 알림을 표시합니다.
- 버전은 숫자로 비교하며(`2.10.0` < `2.9.0`은 단순 문자열 비교와 달리 거짓), 릴리스 태그의 선택적 `v` 접두사는 무시합니다.

## GitHub에 접속할 수 없을 때

확인에 실패하면(오프라인 호스트, GitHub 요청 제한) 로그에 기록되고 다음 시간 주기에 다시 시도됩니다. 이전 결과가 있다면 그때까지 그대로 유지됩니다. 이 확인은 Downtify의 다른 어떤 동작도 막지 않으며, 사용자에게 보이는 오류도 없습니다.

## 자동으로 내려받는 것은 없습니다

이 기능은 새 버전이 있다는 것을 *알려줄* 뿐이며, Downtify는 스스로 업데이트하지 않습니다. 실제로 업데이트하려면 새 이미지를 가져와 컨테이너를 다시 만드세요.

```bash
docker compose pull
docker compose up -d
```
