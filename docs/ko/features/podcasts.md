# 팟캐스트

프로그램을 구독하면 새 에피소드가 알아서 내려받아집니다 — 매주 링크를 다시 붙여넣을 필요가 없습니다. 팟캐스트는 처음부터 끝까지 음악과 다르게 처리됩니다. 에피소드는 이미 RSS `<enclosure>` URL에 놓인 완성된 오디오 파일이므로 YouTube 매칭이나 트랜스코딩이 없고, 다운로드와 태그 쓰기만 있습니다.

사이드바에서 **팟캐스트**를 여세요(휴대폰에서는 **더보기 → 팟캐스트**).

구독은 구독한 사람의 것입니다. 계정마다 자기 프로그램을 따르며(같은 피드를 두 번 구독하면 폴더 두 곳에 저장됨), 에피소드, 이어 듣기 위치, 숨김도 각자 가집니다. 관리자는 모든 구독을 봅니다.

## 구독하기

**팟캐스트 추가** 입력란에 다음 중 하나를 붙여넣거나, 이름을 입력해 검색하세요.

| 입력 | 동작 |
|-------|--------------|
| 팟캐스트의 RSS 피드 URL | 바로 가져와 분석합니다 |
| Spotify 프로그램 링크(`open.spotify.com/show/…`) | Spotify에서 프로그램 이름을 읽은 뒤, iTunes 팟캐스트 디렉터리를 통해 공개 RSS 피드와 매칭합니다 |
| Spotify 에피소드 링크(`open.spotify.com/episode/…`) | 프로그램 링크와 같으며, 제목을 피드에서 찾을 수 있으면 해당 에피소드가 강조됩니다 |
| 프로그램 이름(자유 텍스트) | iTunes 팟캐스트 디렉터리에서 검색합니다 |

::: info Spotify 독점 프로그램은 다운로드할 수 없습니다
Spotify에만 있는 프로그램(공개 피드 없음)은 그대로 그렇다고 알립니다 — Downtify는 추측하거나 다른 것으로 대체하지 않습니다. 독점이라고 단정하기 전에 이름으로 프로그램을 검색해 다시 확인해 보세요.
:::

확인하기 전에 다음을 선택합니다.

- **보관할 에피소드** — 아래 [다운로드되는 에피소드 수](#how-many-episodes-are-downloaded)를 참고하세요.
- **간격** — 피드에서 새 에피소드를 확인하는 빈도로, 15분마다부터 한 달에 한 번까지입니다. 구독은 [재생목록 모니터](playlist-monitor.md)의 감시와 같은 일정으로 같은 백그라운드 점검을 통해 확인됩니다 — 모니터 입장에서는 또 하나의 감시 종류일 뿐입니다.

## 다운로드되는 에피소드 수

**보관할 에피소드** 설정에는 프로그램마다 한 번 선택하는 두 가지 동작이 있습니다.

- **모든 신규 에피소드** — 가장 최신 에피소드 하나만 바로 내려받고(구독이 프로그램의 지난 카탈로그 전체를 끌어오라는 초대는 아닙니다), 이후 점검마다 새로 나타나는 에피소드를 내려받습니다. 자동으로 삭제되는 것은 없습니다.
- **최신 *N*개 에피소드** — 이동하는 창입니다. 매 점검(처음 포함) 후 가장 최근에 게시된 *N*개 에피소드를 내려받고, 그보다 오래된 내려받은 에피소드는 자리를 만들기 위해 삭제됩니다. 나중에 *N*을 늘리면 삭제된 에피소드를 다시 내려받을 수 있게 됩니다. **다운로드 파일 삭제**로 직접 지운 에피소드는 이 방식으로 되돌아오지 않습니다 — [에피소드 삭제](#removing-episodes)를 참고하세요.

**보관할 에피소드**와 간격은 프로그램 페이지에서 언제든 바꿀 수 있습니다.

## 에피소드

프로그램 페이지에는 에피소드가 최신순으로 나열되며, 각각 게시일과 길이가 표시됩니다. 보관 정책에 포함되지 않는 에피소드도 여기에 표시됩니다 — **다운로드**를 눌러 아무리 오래되었어도 그 하나만 가져오세요.

### 에피소드 삭제

각 에피소드의 **⋯** 메뉴에는 **다운로드 파일 삭제**가 있어, 파일은 삭제하지만 에피소드는 목록에 남깁니다. 에피소드 파일이 사라지는 방법은 두 가지이며 결과가 다릅니다.

| 방법 | 자동으로 돌아오나요? |
|-----|----|
| 보관 정책이 밀어냄("최신 N개 보관" 창을 벗어난 오래된 에피소드) | 예, **보관할 에피소드**를 다시 늘리면 |
| 직접 **다운로드 파일 삭제**를 선택함 | 아니요 — 언제든 직접 다시 내려받으세요 |

### 재생 완료로 표시하기

에피소드의 **⋯** 메뉴로 직접 재생 완료 또는 미재생으로 표시하거나, 그냥 끝까지 재생되게 두세요 — 길이의 마지막 몇 초 안에 든 에피소드는 저절로 재생 완료로 표시됩니다.

## 에피소드 재생하기

에피소드는 음악과 같은 내장 플레이어에서 재생되며, 팟캐스트 에피소드에서만 나타나는 몇 가지 차이가 있습니다.

- 단일 에피소드에는 적용되지 않는 셔플과 반복 대신 **15초 뒤로 / 30초 앞으로**.
- 수면 타이머 옆의 **재생 속도**(0.75×~2×).
- **이어 듣기 위치**는 재생 중 약 10초마다, 그리고 일시정지할 때 한 번 더 서버에 저장되므로, 탭을 닫거나 다른 기기에서 Downtify를 열어도 멈춘 곳 가까이에서 에피소드가 이어집니다. 프로그램의 에피소드 목록은 중간까지 들은 것에 "… 에서 이어 듣기" 힌트를 보여줍니다.

하트(좋아요한 곡)와 "앨범/아티스트로 이동"은 에피소드에는 적용되지 않으며 에피소드에는 나타나지 않습니다.

## 라이브러리

팟캐스트는 자기만의 자리가 있습니다 — **라이브러리**에서 트랙, 앨범, 아티스트로 나타나지 않으며, [라이브러리 업그레이드](library-upgrade.md) 실행도 이들을 전혀 건드리지 않습니다(에피소드에는 태그를 새로 고칠 Spotify 트랙 ID도, 따로 찾을 가사도 없습니다).

에피소드 파일은 같은 다운로드 볼륨 아래 `Podcasts/<프로그램>/<날짜> - <에피소드>.<확장자>`에 있으므로, 라이브러리를 가리키는 모든 미디어 서버가 이것도 봅니다.

## 태그

Downtify는 팟캐스트 앱과 미디어 서버가 에피소드에서 이미 읽는 것을 씁니다: 제목, 앨범으로서의 프로그램, 아티스트로서의 프로그램 제작자, 게시 연도, 에피소드/시즌 번호, 프로그램 자체 아트워크(피드 자체 이미지와 iTunes 이미지 중 큰 쪽, [음악 커버 아트](download-settings.md#cover-art-resolution)와 같은 방식), 그리고 코멘트로서의 에피소드 설명. 쇼 노트는 일반 텍스트로 저장됩니다 — Downtify는 HTML을 렌더링하지 않고 제거합니다.

## 알아 두면 좋은 점

- **비디오 팟캐스트는 지원하지 않습니다.** 유일한 첨부가 비디오 파일인 에피소드는 완전히 건너뜁니다. 오디오만 지원됩니다.
- **챕터는 없습니다.** 챕터 마커가 있는 피드도 Downtify에는 아직 챕터가 반영되지 않습니다.
- **Navidrome에 반영되지 않습니다.** 재생목록과 달리 팟캐스트 구독은 Navidrome 라이브러리로 전달되지 않습니다 — 에피소드는 미디어 서버가 이미 스스로 보는 일반 파일입니다.
- 구독 취소(**⋯ → 구독 취소**)는 기본적으로 내려받은 에피소드를 삭제합니다. 파일을 그대로 두려면 **구독 취소 (다운로드된 에피소드 유지)**를 선택하세요.
