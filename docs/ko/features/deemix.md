# Deemix 음원

Deemix는 기본적으로 꺼져 있는 선택 음원입니다. **설정 → 음원 출처**의
slskd 아래에서 구성하고, 출처 순서에서 켜세요.
직접 운영하는 호환 Deemix 서버와, 요청한 음질을 이용할 수 있는 Deezer 계정이 필요합니다.
구독을 제공하거나 우회하지 않습니다.

## 자격 증명과 공유 폴더

Deemix의 일반적인 세션별 로그인 모드를 유지하세요. 보호되지 않은 서버에서는
단일 사용자 모드를 켜지 마세요. 연결 엔드포인트가 공유 ARL을 반환합니다.

Deezer ARL이 든 비공개 파일을 Downtify에 마운트하고 서비스 계정만 읽을 수 있게 한 뒤,
`DOWNTIFY_DEEMIX_ARL_FILE`을 그 경로로 설정하세요.
ARL은 쿠키 세션을 열 때만 읽습니다. 설정에 저장하거나 브라우저로 반환하거나
로그에 남기지 않습니다. 비밀번호처럼 다루세요. 이슈나 채팅이 아닌 비공개로
얻고 교체하세요. 이 통합은 Deemix의 서버 전체 로그인이나 다운로드 설정을 절대 바꾸지 않습니다.
연결 테스트는 다운로드를 대기열에 넣지 않습니다.

| 설정                          | 용도                                                               |
| ----------------------------- | ------------------------------------------------------------------ |
| 서버 URL                      | Deemix의 내부 주소(예: `http://deemix:6595`)                       |
| Deemix 내부의 다운로드 폴더   | 보통 `/downloads`                                                  |
| Downtify 내부의 같은 폴더     | 공유 바인드 마운트(예: `/deemix`), 읽기 전용도 지원                |
| 음질                          | MP3 128, MP3 320 또는 FLAC. 지원되지 않는 권한은 명시적으로 실패합니다 |

공유 폴더는 저장할 때 외부 라이브러리 폴더로 등록됩니다.
파일은 Deemix의 아티스트/앨범 구성 그대로 그곳에 남습니다. Downtify는
형식, 태그, 아트워크, `.lrc` 사이드카 파일을 다시 쓰지 않고 그대로 보존합니다.
내장 가사와 이름이 같은 `.lrc` 파일은 플레이어가 읽습니다.
이 통합은 오디오나 가사를 삭제하거나 이동하거나 생성하지 않습니다.

Deezer 트랙 링크는 해당 녹음을 선택합니다. 카탈로그 간 다운로드는
아티스트/제목이 모호하지 않게 정확히 일치해야 하며, 앨범과 길이가 제공되면 이것도 일치해야 합니다.
모호한 매칭은 다음으로 켜진 출처로 넘어갑니다.
Deemix 대기열이 끝나면 파일과 길이/음질을 확인합니다.
이 통합은 수동으로 만든 Deemix 작업을 비우거나 취소하거나 바꾸지 않습니다.
명시적인 YouTube 링크는 현재의 직접 다운로드 동작을 유지합니다.

이 출처는 라이브러리에 있는 기존 트랙을 자동으로 교체하거나 삭제하지 않습니다.
라이브러리 중복 제거와 수동 오디오 교체는 별개로 유지됩니다.
