# 서버 설정

**설정 → 서버**에는 서버 자체의 동작 방식이 모여 있습니다. 관리자만 볼 수 있습니다([사용자와 로그인](users.md#admins-and-users) 참고).

## 포트 변경

Downtify는 **8000** 포트에서 수신합니다. 관리자는 **설정 → 서버 → 포트**(1024–65535)에서 다른 포트를 고를 수 있습니다.

- **저장**은 다음에 서버가 시작될 때 쓰도록 보관합니다.
- **저장 후 재시작**은 서버를 즉시 해당 포트로 다시 시작합니다. 진행 중인 다운로드는 중단되고, 페이지와 앱은 다시 연결됩니다. 서버 자체 주소(예: `http://nas:8000`)로 열어 둔 페이지는 서버가 돌아올 때까지 기다렸다가 새 주소를 스스로 열며, 로그인 상태는 유지됩니다.

포트가 환경 변수 `DOWNTIFY_PORT`(또는 `PORT`)나 명령줄의 `--port`에서 오는 경우(항상 이쪽이 우선합니다) 필드에는 사용 중인 포트가 표시되지만 편집할 수 없으며, 페이지에 어느 쪽이 정하는지 알려 줍니다. 설정에서 포트를 고르려면 그것을 제거하고 재시작하세요.

::: warning Docker의 브리지 네트워크는 고정 포트를 매핑합니다
기본 Docker 설정(`ports: - '8000:8000'`)에서는 컨테이너의 포트가 매핑과 일치해야 합니다. 설정에서 포트를 바꾼 뒤에는 매핑도 새 포트(`'9000:9000'`)로 바꾸고 컨테이너를 다시 만들거나 `network_mode: host`로 실행하세요. 그렇지 않으면 Downtify에 접속할 수 없습니다. 다시 들어가려면 `DOWNTIFY_PORT`를 이전 포트로 설정하세요. 설정보다 우선합니다.
:::

[리버스 프록시](mobile-apps.md#behind-a-reverse-proxy) 뒤에서는 프록시도 새 포트로 향하게 하세요. [페어링된 앱](mobile-apps.md)은 받은 주소를 그대로 사용하므로, 포트를 바꾼 뒤에는 앱에 새 주소를 입력하세요.
