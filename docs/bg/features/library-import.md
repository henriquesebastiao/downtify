# Импорт на библиотека (CSV)

Вече сте експортирали библиотеката си от друга услуга? Импортирайте CSV файла и сложете всички песни на опашката за изтегляне наведнъж, вместо да добавяте песните една по една.

## Поддържани инструменти за експорт

| Инструмент | Бележки |
|------|-------|
| [Soundiiz](https://soundiiz.com/) | |
| [TuneMyMusic](https://www.tunemymusic.com/) | |
| [Exportify](https://github.com/watsonbox/exportify) | |

Downtify не е закодирал твърдо точната схема на колоните на нито един инструмент. Вместо това сравнява реда със заглавията на CSV файла, без значение от малки и главни букви, с набор от известни псевдоними (`Title` / `Track` / `Track Title` / `Track Name` / `Song` / …, `Artist` / `Artists` / `Artist Name` / `Artist Name(s)` / … и `Album` / `Album Name` / `Album Title` / …), така че експортите от всеки от трите — или от ръчно направен CSV със същите имена на колони — работят без нищо да се преименува.

Заглавието и изпълнителят са задължителни. Албумът се чете, когато го има, и се записва като име на албума на песента (Опашка, съпоставяне и тагове на файла). Други колони, които някои инструменти добавят (ISRC, Spotify URI на песен, продължителност), се игнорират. Всеки ред се разпознава както свободно текстово търсене, през YouTube Music.

## Как да импортирате

1. На началната страница натиснете **Импортирай CSV (Soundiiz, Exportify…)** под полето за търсене.
2. Изберете експортирания `.csv` файл.

Файлът се чете изцяло във вашия браузър и се изпраща на сървъра като обикновен текст — никога не се качва другаде. Downtify го разчита, слага на опашката всеки разпознат ред и стигате до Опашката за изтегляне, където напредъкът пристига през WebSocket точно както при всяко друго пакетно изтегляне.

Импортираният пакет получава името на файла (името му без `.csv`) и, както всяко друго изтегляне на плейлист, получава [M3U файл](m3u-export.md), ако тази настройка е включена.

## Ограничения и обработка на грешки

- До **2000 реда** на файл. По-големите експорти разделете на няколко файла.
- Редовете без заглавие или изпълнител се пропускат безшумно. Липсваща колона за албум или празна клетка за албум не е проблем — YouTube Music може да попълни албума по-късно.
- Няколко изпълнители в една клетка (разделени с `,` или `;`) се разделят в списък.
- Ако заглавният ред не съдържа разпознаваема колона за заглавие/изпълнител, целият импорт се отхвърля предварително с грешка, която назовава намерените колони — нищо не се слага на опашката.

## Избягване на ограничения по честота

Импортирането на голяма библиотека слага на опашката много търсения и изтегляния в YouTube Music за кратко време, а това лесно води до ограничаване. Преди да импортирате голям файл, обмислете да намалите **[Едновременни изтегляния](download-settings.md#parallel-downloads)** и да включите **[Пауза между изтеглянията](download-settings.md#delay-between-downloads)** в Настройките.

## API

Вижте [`POST /api/download/csv`](../api-reference.md#post-apidownloadcsv) в API справочника за съответния endpoint.
