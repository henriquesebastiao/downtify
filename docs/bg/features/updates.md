# Известия за обновяване

Downtify проверява собствената си [страница с Releases в GitHub](https://github.com/henriquesebastiao/downtify/releases) веднъж на час. Когато има по-нова версия, на всяка страница в долната част на страничната лента се появява известие — на телефоните точка върху раздела **Още** и ред най-горе в неговия лист — както и в **Настройки → Относно**:

> ✦ Налична е версия 3.0.1

Натиснете го, за да отворите тази версия в GitHub.

## Как работи

- Фонова задача в бекенда (`downtify/update_check.py`) взема най-новата версия от API-то на GitHub веднъж веднага при стартиране, после на всеки час. Тя е от типа „пусни и забрави“: нищо в интерфейса не я чака.
- Уеб интерфейсът чете кешираният резултат от `GET /api/check_update` (вижте [API справочника](../api-reference.md)) веднъж на час и показва известието, когато намери по-нова версия.
- Версиите се сравняват числово (`2.10.0` < `2.9.0` е невярно, за разлика от обикновеното сравнение на низове), а незадължителен префикс `v` в тага на версията се игнорира.

## Ако GitHub не е достъпен

Неуспешна проверка (хост без връзка, лимит на заявките в GitHub) се записва в лога и просто се повтаря при следващото почасово преминаване — предишният резултат, ако има такъв, остава в сила дотогава. Проверката никога не блокира нищо друго в Downtify; за нея няма грешка, видима за потребителя.

## Нищо не се сваля автоматично

Това само *съобщава*, че има нова версия — Downtify не се обновява сам. За да обновите наистина, изтеглете новия образ и пресъздайте контейнера:

```bash
docker compose pull
docker compose up -d
```
