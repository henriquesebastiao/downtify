# 播放列表显示名称

对导入或同步的播放列表使用 **Rename**，即可在 Downtify 中自定义其显示名称。此操作只更改显示名称；源 URL、源标识符、文件、共享权限和同步状态均保持不变。之后再次同步时仍会保留自定义名称。使用 **Restore source name** 可移除自定义名称。Downtify 不会在 Spotify、YouTube 或 Deezer 上重命名播放列表。

只有播放列表所有者或管理员可以重命名。已点赞歌曲使用保留名称。名称不能为空，长度不得超过 120 个字符，也不能与所有者可见的其他播放列表重名。

本地创建的播放列表仍保持原有的重命名行为。

移动播放列表响应新增 `display_name`；`name` 仍是稳定的查询键。兼容客户端应显示自定义标签，并继续使用 `name` 发送 API 请求。旧客户端会继续使用原始名称。
