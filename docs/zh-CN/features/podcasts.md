# 播客

订阅节目后，新单集会自动下载，无需每周重新粘贴链接。播客从头到尾都采用不同于音乐的处理方式：单集本身就是 RSS `<enclosure>` URL 上的完整音频文件，因此无需匹配 YouTube 或转码，只需下载并写入标签。

从侧边栏打开**播客**（手机上：**更多 → 播客**）。

订阅归订阅者所有：每个账户关注自己的节目，拥有独立的单集、续播位置和移除记录；同一订阅源被订阅两次，会保存到两个文件夹。管理员可看到所有订阅。

## 订阅节目

在**添加播客**输入框中粘贴以下内容之一，或输入名称搜索：

| 输入 | 处理方式 |
|-------|--------------|
| 播客 RSS 订阅源 URL | 直接获取并解析 |
| Spotify 节目链接（`open.spotify.com/show/…`） | 从 Spotify 读取节目名称，再通过 iTunes 播客目录匹配公开 RSS 订阅源 |
| Spotify 单集链接（`open.spotify.com/episode/…`） | 与节目链接相同；若能在订阅源中匹配单集标题，会突出显示对应单集 |
| 节目名称（自由文本） | 在 iTunes 播客目录中搜索 |

::: info 无法下载 Spotify 独家节目
仅在 Spotify 存在、没有公开订阅源的节目，会明确提示；Downtify 不会猜测或替换为其他节目。判断为独家节目之前，可按名称搜索再次确认。
:::

确认前可选择：

- **保留**：参见下方[下载多少单集](#how-many-episodes-are-downloaded)。
- **检查间隔**：检查新单集的频率，从每 15 分钟到每月一次。订阅与[播放列表监控](playlist-monitor.md)使用相同调度和后台检查，只是另一种监控类型。

## 下载多少单集

每个节目选择一种**保留**策略，两种行为不同：

- **所有新单集**：订阅后立即只下载最新一集，不会下载整个往期目录；之后每次检查会下载新增单集，不会自动删除任何内容。
- **最新 *N* 集**：使用滚动窗口。每次检查，包括首次检查，都会下载最近发布的 *N* 集，并删除更早的已下载单集腾出空间。以后增大 *N*，这些被策略移除的单集可再次下载；通过**移除下载**手动移除的单集不会自动恢复，参见[移除单集](#removing-episodes)。

可随时在节目页面修改**保留**策略和检查间隔。

## 单集

节目页面按最新优先列出单集，并显示发布日期和时长。不在保留策略范围内的单集仍会显示；无论发布多久，都可点击**下载单集**单独下载。

### 移除单集

每个单集的 **⋯** 菜单提供**移除下载**，删除文件但保留列表条目。文件移除的两种原因会带来不同结果：

| 原因 | 是否自动恢复？ |
|-----|----|
| 保留策略移除，即旧单集超出“保留最新 N 集”的范围 | 会，再次增大**保留**数量即可 |
| 你手动选择**移除下载** | 不会，但随时可手动重新下载 |

### 标记已播放

可通过单集 **⋯** 菜单手动标记为已播放或未播放，也可直接播放至结尾；播放进度进入最后几秒后，会自动标记为已播放。

## 播放单集

单集使用与音乐相同的内置播放器，但有几项仅在播客播放时出现的区别：

- **后退 15 秒 / 前进 30 秒**替代随机播放和循环，因为后两者不适用于单个单集。
- **播放速度**（0.75× 到 2×）位于睡眠定时器旁。
- **续播位置**大约每播放 10 秒保存到服务器，暂停时再保存一次，因此关闭标签页或在另一台设备上打开 Downtify，都能从接近上次停止的位置继续。节目单集列表会为播放到一半的单集显示“从……继续”提示。

喜欢歌曲的心形按钮和“前往专辑/艺人”不适用于播客，不会显示。

## 音乐库

播客有独立位置，不会作为歌曲、专辑或艺人出现在**音乐库**中；[升级音乐库](library-upgrade.md)也完全不会处理播客，因为单集没有可用于刷新标签的 Spotify 曲目 ID，也没有独立歌词需要查找。

单集文件仍保存在同一个下载卷中，路径为 `Podcasts/<Show>/<date> - <Episode>.<ext>`，因此指向音乐库目录的媒体服务器也能看到。

## 标签

Downtify 会写入播客应用和媒体服务器常用的单集标签：标题、以节目名作为专辑、节目作者作为艺人、发布年份、单集和季编号、节目封面，以及作为注释的单集描述。封面会选择订阅源图片和 iTunes 图片中更大的一个，与[音乐封面](download-settings.md#cover-art-resolution)的处理思路相同。节目说明保存为纯文本，Downtify 会移除 HTML，而不是渲染它。

## 注意事项

- **不支持视频播客。** 唯一 enclosure 为视频文件的单集会完全跳过，只支持音频。
- **不支持章节。** 订阅源中的章节标记目前不会在 Downtify 中提供。
- **不会同步到 Navidrome。** 与播放列表不同，播客订阅不会推送到 Navidrome 音乐库；单集是普通文件，媒体服务器本身就能读取。
- 取消订阅（**⋯ → 取消订阅**）默认会移除已下载单集；选择**取消订阅并保留已下载单集**可保留文件。

## API

`POST /api/podcasts/resolve`、`GET /api/podcasts/search`、`POST /api/podcasts/subscribe`、`GET/PATCH/DELETE /api/podcasts/shows/{id}`、`GET /api/podcasts/shows/{id}/episodes`、`POST /api/podcasts/episodes/{id}/download`、`DELETE /api/podcasts/episodes/{id}` 和 `PUT /api/podcasts/episodes/{id}/playback`。参见 [API 参考](../api-reference.md#podcasts)。
