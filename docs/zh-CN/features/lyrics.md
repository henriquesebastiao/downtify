# 歌词

Downtify 会在下载曲目时查找歌词并将其嵌入文件；如果歌词带有时间轴，还会生成 `.lrc` 侧车文件。

## 启用歌词

歌词**默认启用**。可在 **Settings → Tags & lyrics → Download lyrics** 中关闭。

## 提供方及回退顺序

不同歌词库收录内容各异：某个提供方没有的歌曲，往往能在另一个提供方找到。因此 Downtify 会按顺序逐一查询提供方，在第一个找到歌词的来源处停止。

| 提供方 | 歌词类型 | 说明 |
|----------|--------|-------|
| **[LRCLIB](https://lrclib.net)** | 普通歌词和同步歌词 | 免费社区数据库，无需密钥。按标题、主要艺人、专辑和时长匹配；找不到同步歌词时，还会尝试其搜索，按标题、艺人和时长（相差几秒内）接受结果。 |
| **网易云音乐** | 通常为同步歌词 | 曲库庞大，亚洲作品收录丰富，许多西方作品也可找到。按标题、艺人和时长匹配；若艺人名称拼写不同（例如繁体与简体中文），只有标题和时长都匹配时才接受该结果。 |
| **酷狗音乐** | 同步歌词 | 曲库庞大，中文作品丰富，也收录许多西方作品。匹配方式同网易云音乐；会去掉开头的标题行和词曲署名。 |

在 **Settings → Tags & lyrics → Providers** 中，可拖动提供方调整顺序，也可使用箭头移动，并单独关闭任一提供方。至少要保留一个提供方启用；如需完全停止查询歌词，请关闭 **Download lyrics**。如果你已保存过自己的列表，更新中新增的提供方默认关闭，请在那里打开。

### 仅限同步歌词

**Settings → Tags & lyrics → 仅限同步歌词**（默认关闭）只保留带时间轴的歌词：某个提供方只有纯文本歌词时视为没有找到，并继续询问下一个。[升级音乐库](library-upgrade.md)也会把只有纯文本歌词的歌曲算作缺少歌词。文件已有的同步歌词都算数：`.lrc` 附属文件、标签中带时间轴的歌词，或 ID3 `SYLT` 帧（其他应用下载的文件有时会有）。开启后，Downtify 找到的同步歌词会替换纯文本歌词：写入 `.lrc` 附属文件，也写入文件自身的歌词标签，这样只读取标签的播放器也能显示同步歌词。扫描结果还会说明缺少歌词的歌曲中有多少只有纯文本歌词。

### 为没有歌词的歌曲查找歌词

**音乐库 → 升级音乐库 → 扫描并查找歌词**会扫描音乐库中没有歌词的歌曲，并立即查找歌词，显示进度条。结束后会显示多少首歌曲添加了歌词、多少首未找到、多少首失败。参见[升级音乐库](library-upgrade.md#while-it-runs)。

::: info Genius、Musixmatch 和 AZLyrics 呢？
这些来源目前不可用，Downtify 也不再提供：

- **AZLyrics** 禁止第三方在页面中使用其歌词。
- **Musixmatch** 的桌面 API 在没有其不向应用提供的凭据时会返回空令牌。
- **Genius** 的 `robots.txt` 禁止访问查找歌曲页面所需的搜索端点。

仍包含这些来源名称的已保存设置不会受到影响：系统会忽略这些名称；如果列表中没有其他来源，则改用默认提供方。
:::

## 跳过未找到歌词的提供方

查询后，Downtify 会将每首歌曲的提供方响应情况（找到歌词或无结果）记录在 `/data` 下的 `downtify_library.db` 中。

某提供方对歌曲无结果后，**30 天内**不会再次查询该提供方，避免重新下载或大型媒体库扫描重复执行失败查询。30 天后会重试，因为曲库可能已经更新。曾经找到歌词的提供方不会被跳过，因此重新下载文件时仍可获取歌词。

## 内嵌标签

| 格式 | 普通歌词标签 | 同步歌词标签 |
|--------|-----------------|------------------|
| MP3 | `USLT` (ID3) | 含时间戳的 `USLT` |
| FLAC | `LYRICS` (Vorbis 注释) | 包含 LRC 内容的 `LYRICS` |
| M4A | `©lyr` | 包含 LRC 内容的 `©lyr` |
| OGG / OPUS | `LYRICS` (Vorbis 注释) | 包含 LRC 内容的 `LYRICS` |

## `.lrc` 侧车文件

找到同步歌词时，Downtify 还会保存 `.lrc` 文件。默认情况下，该文件与音频文件位于**同一目录**，主文件名也相同。在 **Settings → Tags & lyrics** 中，可以关闭此行为并指定单独的**歌词目录**（默认 `/data/lyrics`）。该目录必须位于 `/downloads`、slskd 目录和任何额外音乐目录之外；音频文件的相对路径会在该目录中重建（例如 `Artist/Album/track.lrc`）。支持外部歌词的播放器（以及[内置播放器](player.md#now-playing)）仍可读取该侧车文件。更改此设置后，对额外文件夹运行 **Sync** 会将现有 `.lrc` 文件复制到新位置；如果源目录可写，则会删除源文件；如果源目录为只读挂载，则会保留源文件。即使标签中已经内嵌歌词，仍会写入侧车文件。

在 Library 页面删除曲目时，其音频旁边以及专用歌词目录中的 `.lrc` 文件也会一并删除，避免留下孤立歌词文件。

## 调整时间

网上找到的歌词有时会比下载的音频稍早或稍晚：歌曲的另一个版本、更长的前奏。要修正一首歌，先播放它，打开 **正在播放 → 歌词**，再点歌词右上角的计时器按钮 **调整歌词时间**：

- **−** 让歌词提前显示，**+** 让歌词延后显示，每点一次 0.1 秒，两个方向最多各一分钟。歌词会立即按新时间显示，你可以边播放边调整。
- **保存** 会把它写入歌曲文件；**重置** 恢复到已保存的时间。

保存会改写时间戳本身：`.lrc` 文件，以及文件标签中带时间轴的歌词（包括 MP3 的 `SYLT` 帧）。因此读取 `.lrc` 或标签的其他播放器和应用也能看到修正。只读文件保留其标签，只有 `.lrc` 会改变。`.lrc` 中的 `[offset:N]` 行会在保存时并入时间戳，而 Downtify 的播放器在此之前就会遵循它。

只有带时间轴歌词的媒体库歌曲才会显示该按钮。任何已登录用户都可以调整；更改会以 **调整歌词时间** 出现在[活动记录](users.md#activity)中。端点是 [`POST /api/library/lyrics/offset`](../api-reference.md#post-apilibrarylyricsoffset)。

## 未找到歌词时

如果所有提供方都没有该歌曲的歌词，下载仍会正常继续：保存的音频文件不含歌词，也不会报错。
