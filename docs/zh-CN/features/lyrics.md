# 歌词

Downtify 会在下载曲目时查找歌词并将其嵌入文件；如果歌词带有时间轴，还会生成 `.lrc` 侧车文件。

## 启用歌词

歌词**默认启用**。可在 **Settings → Tags & lyrics → Download lyrics** 中关闭。

## 提供方及回退顺序

不同歌词库收录内容各异：某个提供方没有的歌曲，往往能在另一个提供方找到。因此 Downtify 会按顺序逐一查询提供方，在第一个找到歌词的来源处停止。

| 提供方 | 歌词类型 | 说明 |
|----------|--------|-------|
| **[LRCLIB](https://lrclib.net)** | 普通歌词和同步歌词 | 免费社区数据库，无需密钥。按标题、主要艺人、专辑和时长匹配。 |
| **网易云音乐** | 通常为同步歌词 | 曲库庞大，亚洲作品收录丰富，许多西方作品也可找到。按标题、艺人和时长匹配；若艺人名称拼写不同（例如繁体与简体中文），只有标题和时长都匹配时才接受该结果。 |

在 **Settings → Tags & lyrics → Providers** 中，可拖动提供方调整顺序，也可使用箭头移动，并单独关闭任一提供方。至少要保留一个提供方启用；如需完全停止查询歌词，请关闭 **Download lyrics**。

::: info Genius、Musixmatch 和 AZLyrics 呢？
这些来源目前不可用，Downtify 也不再提供：

- **AZLyrics** 禁止第三方在页面中使用其歌词。
- **Musixmatch** 的桌面 API 在没有其不向应用提供的凭据时会返回空令牌。
- **Genius** 的 `robots.txt` 禁止访问查找歌曲页面所需的搜索端点。

仍包含这些来源名称的已保存设置不会受到影响：系统会忽略这些名称；如果列表中没有其他来源，则改用默认提供方。
:::

## 跳过未找到歌词的提供方

查询后，Downtify 会将每首歌曲的提供方响应情况（找到歌词或无结果）记录在 `/data` 下的 `downtify_library.db` 中。

某提供方对歌曲无结果后，**30 天内**不会再次查询该提供方，避免重新下载或大型媒体库扫描重复执行失败查询。30 天后会重试，因为曲库可能已经更新。曾经找到歌词的提供方不会被跳过，因此重新下载文件时仍可获取歌词。

## 内嵌标签

| 格式 | 普通歌词标签 | 同步歌词标签 |
|--------|-----------------|------------------|
| MP3 | `USLT` (ID3) | 含时间戳的 `USLT` |
| FLAC | `LYRICS` (Vorbis 注释) | 包含 LRC 内容的 `LYRICS` |
| M4A | `©lyr` | 包含 LRC 内容的 `©lyr` |
| OGG / OPUS | `LYRICS` (Vorbis 注释) | 包含 LRC 内容的 `LYRICS` |

## `.lrc` 侧车文件

找到同步歌词时，Downtify 还会保存 `.lrc` 文件。默认情况下，该文件与音频文件位于**同一目录**，主文件名也相同。在 **Settings → Tags & lyrics** 中，可以关闭此行为并指定单独的**歌词目录**（默认 `/data/lyrics`）。该目录必须位于 `/downloads`、slskd 目录和任何额外音乐目录之外；音频文件的相对路径会在该目录中重建（例如 `Artist/Album/track.lrc`）。支持外部歌词的播放器（以及[内置播放器](player.md#now-playing)）仍可读取该侧车文件。更改此设置后，对额外文件夹运行 **Sync** 会将现有 `.lrc` 文件复制到新位置；如果源目录可写，则会删除源文件；如果源目录为只读挂载，则会保留源文件。即使标签中已经内嵌歌词，仍会写入侧车文件。

在 Library 页面删除曲目时，其音频旁边以及专用歌词目录中的 `.lrc` 文件也会一并删除，避免留下孤立歌词文件。

## 未找到歌词时

如果所有提供方都没有该歌曲的歌词，下载仍会正常继续：保存的音频文件不含歌词，也不会报错。
