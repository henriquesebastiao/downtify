# 用户与登录

每位使用 Downtify 的人都通过**用户名和密码**登录，并可拥有自己的账户。管理员在**设置 → 用户**中管理账户，并在**设置 → 活动**中查看所有人的操作。

## 首次登录

新服务器有一个账户：

| 用户名 | 密码 |
|----------|----------|
| `admin` | `downtify` |

用该账户登录后，请在**设置 → 常规 → 账户**中**修改密码**：熟悉 Downtify 的人都知道默认密码。修改前，Downtify 会在登录后提醒，并在设置中显示警告。

::: warning 对外开放服务器前请修改默认密码
默认密码无法提供保护。让 Downtify 可从家庭网络外访问之前，请先修改密码，并使用 HTTPS，参见[反向代理](mobile-apps.md#behind-a-reverse-proxy)。
:::

### 从旧版本升级

从不支持账户的版本升级后，服务器也会创建同一个 `admin` 账户。管理员首次登录之前，登录页会显示一次说明，并提供所需用户名和密码：

- 若旧的**要求登录**选项设置过密码，该密码仍可用于 `admin`；
- 否则密码为 `downtify`。

升级前已登录的浏览器需要重新登录。此前配对的手机保持配对，并归属 `admin`。

## 管理员与普通用户

| | 管理员 | 普通用户 |
|---|---|---|
| 收听、搜索、下载、添加喜欢、发现、排行榜、查找、播客 | ✓ | ✓ |
| 将手机应用配对到自己的账户 | ✓ | ✓ |
| 设置 → 常规（自己的账户和偏好）、应用、关于 | ✓ | ✓ |
| 其他所有设置（来源、文件、标签、Navidrome、音乐库、服务器），修改服务器名称 | ✓ | |
| [共享自己的播放列表](#sharing-playlists)（仅查看）、关注公开列表、保存副本 | ✓ | ✓（管理员允许时） |
| 删除文件和播放列表（普通用户仅限[自己下载的内容](#deleting-songs)和自己的播放列表），管理自己的播放列表监控与播客订阅，替换歌曲音频，编辑艺人照片 | ✓ | ✓（仅自己的内容） |
| [向普通用户隐藏歌曲、专辑和艺人](#hiding-from-users) | ✓ | |
| 管理用户、查看活动日志 | ✓ | |

普通用户尝试需要管理员权限的操作时，会收到提示。

## 你的音乐库

音乐库共享：每个账户都能看到任何人下载的每首歌曲，包括音乐库、标记为已下载的搜索结果和已配对手机。文件不会重复保存：两个人下载同一首歌时，磁盘上只保存一份，分别记录两人的所有权。

喜欢记录、播放列表（下载的或在音乐库中创建的）和下载队列归你自己，管理员可查看全部；你也可[共享播放列表](#sharing-playlists)，让他人看到。播放权限共享，任何人都可播放、试听或流式播放任意歌曲，并加入自己的播放列表。请求他人正在下载的歌曲时，会加入已有任务而不重复下载：只有一行队列和一次下载，但分别记录所有权，每位等待者都能看到自己的队列位置。

播客、播放列表监控和发现历史也是如此：每个账户订阅自己的节目，监控自己的播放列表和艺人，建立自己的推荐依据。管理员可看到所有账户的条目。播放本身仍共享，任何人都可播放、试听或流式播放任意歌曲。

### 共享播放列表

播放列表默认只对所有者和管理员可见，所有者可通过播放列表页面或 **⋯** 菜单中的**共享…**分享。账户之间本来就能播放歌曲，共享只决定谁能*看到*列表。除“喜欢的歌曲”外，所有播放列表均可共享，包括导入列表。

| 可见范围 | 可查看的人 |
|------------|-------------|
| **私有** | 只有所有者和管理员，默认选项 |
| **指定用户** | 所有者选择的用户名 |
| **公开** | 服务器上的所有人 |

其他人的播放列表不会混入你自己的列表。音乐库的**播放列表**标签页会在你的列表下方分为两部分，并为每项标明所有者：

- **与我共享**：指定共享给你的列表，始终显示。新共享的列表会带有**新增**标记，打开后消失。
- **公开播放列表**：所有人的公开列表，按所有者和名称排序，可用标签页筛选器搜索，并显示所有者、歌曲数量和是否关注。此部分默认折叠，也可通过**设置 › 常规 › 显示公开播放列表**完全隐藏；该选项默认开启，与主题一样属于个人偏好。

侧边栏也会显示部分与你共享的列表，以及你关注的公开列表。

**查看者可以做什么：**播放、随机播放、加入队列、下载为 ZIP 或保存到手机及桌面应用，**关注**公开播放列表，让它持续出现在自己的列表中并跟随所有者修改，即使关闭“显示公开播放列表”也一样；还可**保存副本**，创建包含自己可见歌曲的私有、可编辑播放列表。查看者不能编辑、重命名、删除、共享或解除他人列表的来源关联。音乐库播放列表的所有者还可将部分共享对象设为编辑者，允许添加和移除歌曲，参见[协作播放列表](collaborative-playlists.md)。

**取消共享：**所有者将列表重新设为私有，或移除某个共享对象后，列表会立即从该人的列表中消失，无论是否关注；不再公开的列表也会取消关注。别人已保存的副本仍保留。重命名共享列表不会取消共享，删除列表则同时移除共享。管理员[向普通用户隐藏](#hiding-from-users)的歌曲，也会像其他页面一样从其可见的共享列表中排除。

管理员可通过**设置 › 音乐库 › 允许用户共享播放列表**关闭整个功能，默认开启。关闭时，所有共享列表隐藏，任何人都不能共享或关注；重新开启后，共享会恢复。

已配对应用获取相同列表：[`GET /api/v1/playlists`](../api-reference.md#get-apiv1playlists) 会说明每个列表的所有者及是否只读，WebSocket 的 `playlists_changed` 会通知刷新。

### 向普通用户隐藏

管理员可决定其他账户能看到什么。默认全部内容对所有人可见，直到管理员隐藏某首**歌曲**、整张**专辑**或整位**艺人**。隐藏项会从普通用户的音乐库、搜索结果的已在音乐库标记、播放列表歌曲和手机同步内容中移除，管理员不受影响。

- **在音乐库中**，打开歌曲、专辑或艺人的 `…` 菜单，选择**向普通用户隐藏**，或用**向普通用户显示**撤销。歌曲标签页也可多选后在选择栏中隐藏。
- 管理员仍能看到全部内容。隐藏项带有小型划线眼睛图标，提示会说明是自身隐藏，还是随专辑或艺人隐藏。
- **设置 › 用户 › 向普通用户隐藏**列出所有隐藏艺人、专辑和歌曲，每项旁提供**向普通用户显示**。
- 移动歌曲到其他文件夹，或[升级音乐库](library-upgrade.md)、[替换音频](replace-audio.md)重写文件后，隐藏仍有效。删除文件会清除规则。
- 专辑规则匹配专辑艺人和标题；艺人规则匹配音乐库用于归组的艺人，与音乐库专辑和艺人标签页的名称相同。

::: info 隐藏只影响列表展示
它控制账户在应用中看到的内容，不阻止已知文件地址的人获取文件。不要用它保护敏感文件。
:::

隐藏和显示都会记录在[活动日志](#activity)中。

### 删除歌曲

删除歌曲会让所有人失去磁盘上的文件，因此权限取决于谁下载了它。管理员可删除任何内容。普通用户可删除自己下载的歌曲；若其他人也下载过同一首，删除只会放弃自己的所有权，歌曲仍保留在共享音乐库中。没有账户下载记录的歌曲，例如播放列表监控检查下载、账户功能加入前的下载或[额外文件夹](external-library.md)中的歌曲，只能由管理员删除。删除自己的播放列表不会连带删除他人的文件。

### 每个账户的用量

**设置 › 用户**会在每个账户下列出其拥有的歌曲数量及大小、喜欢记录、播放列表、发起的下载，以及双向流量，即从上游获取和向客户端提供的流量，下方显示所有人的总计。“歌曲”统计账户自己下载的歌曲，而非所有可见歌曲。

## 账户与偏好

**设置 → 常规**首先显示**账户**：可更改用户名或密码，或退出登录。也可从侧边栏退出，手机上则在**更多**中操作。

**常规**中的其他偏好，包括主题、语言、播放器歌词显示和搜索结果中的专辑，均**属于你自己**，会跟随账户应用到所有登录浏览器，不影响其他人。

**设置 → 应用**列出配对到你账户的手机；管理员可看到所有人的手机及所有者。**退出所有设备**会取消你全部应用的配对，并退出所有浏览器。

## 管理用户

管理员可在**设置 → 用户**中：

- **添加用户**：设置用户名（3–32 个字母、数字、`.`、`-` 或 `_`）、密码（至少 8 个字符）和角色。
- **编辑**用户：更改名称，设为管理员或普通用户，或设置新密码。修改密码会退出该用户已登录的浏览器，但应用保持配对。
- **删除**用户：取消其应用配对并退出浏览器。文件仍留在磁盘上，管理员仍可看到；喜欢记录、播放列表、播客订阅、监控、推荐历史和流量计数随账户删除。
- **退出所有用户**：取消每位用户的所有应用配对，并退出每个浏览器，包括你自己。

服务器始终至少保留一位管理员：最后一位管理员不能删除或降为普通用户，你也不能删除自己的账户。

## OpenID Connect

Downtify 可在登录页添加可选的**通过身份提供方继续**按钮，使用 Authelia、Authentik、Keycloak 或 Pocket ID 等 OpenID Connect 提供方认证。本地用户名和密码登录仍保留，除非主动关闭。浏览器流程使用带 PKCE 的 Authorization Code；Downtify 会验证提供方签名的 ID Token，再创建自己的会话 Cookie。

在服务器上设置以下变量，并将下方回调 URL 注册为提供方允许的重定向 URI：

| 变量 | 必填 | 默认值 | 说明 |
|----------|----------|---------|-------------|
| `DOWNTIFY_OIDC_ISSUER` | 是 | | 提供方发现文档中的确切 issuer URL。 |
| `DOWNTIFY_OIDC_CLIENT_ID` | 是 | | 已注册的客户端 ID。 |
| `DOWNTIFY_OIDC_CLIENT_SECRET` | 是 | | 机密客户端的密钥。 |
| `DOWNTIFY_OIDC_REDIRECT_URI` | 否 | 从请求推导 | 公开回调 URL，通常为 `https://music.example.com/api/auth/oidc/callback`。位于反向代理后时应显式设置。 |
| `DOWNTIFY_OIDC_SCOPES` | 否 | `openid profile email` | 以空格分隔的 OIDC scope。 |
| `DOWNTIFY_OIDC_USERNAME_CLAIM` | 否 | `preferred_username` | 用于新 Downtify 用户名的 claim，依次回退到 `email` 和 `sub`。 |
| `DOWNTIFY_OIDC_GROUPS_CLAIM` | 否 | `groups` | 包含组名字符串或列表的 claim，支持 `realm_access.roles` 等点分路径。 |
| `DOWNTIFY_OIDC_ALLOWED_GROUPS` | 否 | _（空）_ | 逗号分隔的允许登录组；为空时允许任何已认证身份。 |
| `DOWNTIFY_OIDC_ADMIN_GROUPS` | 否 | _（空）_ | 逗号分隔的管理员组，其成员获得 Downtify 管理员角色，其他人为普通用户。 |

例如，提供方的客户端需要注册回调 `https://music.example.com/api/auth/oidc/callback`，以及 `openid profile email` scope。使用反向代理时，还应配置 [`DOWNTIFY_TRUSTED_PROXIES`](../getting-started/environment-variables.md#mobile-apps-and-sign-in)，或显式设置重定向 URI。

首次成功登录会创建 Downtify 账户。身份以确切的 `issuer` 和 OIDC `sub` 为键，不使用可变的用户名或邮箱。**不会**通过同名用户名或邮箱自动关联已有本地账户；若提供的用户名已被占用，Downtify 会追加稳定后缀。管理员仍可在**设置 → 用户**中管理本地角色；配置的管理员组映射会在每次 OIDC 登录时同步。若映射变化将移除服务器最后一位管理员，Downtify 会拒绝该次登录，直到另有管理员存在。

若要同时关闭网页用户名/密码登录和应用的密码令牌端点，设置 `DOWNTIFY_DISABLE_LOCAL_LOGIN=true`。OIDC 和代码配对仍可使用，不会撤销已有浏览器会话或设备令牌。此设置要求完整 OIDC 配置，与完全移除认证的 `DOWNTIFY_DISABLE_AUTH` 不同。

## 活动

管理员的**设置 → 活动**类似 Jellyfin 仪表板，会显示：

- **正在播放**：每个浏览器和应用播放的内容、播放者、歌曲进度和是否暂停，每隔几秒刷新。
- **历史记录**：登录及失败登录的来源地址、退出、播放歌曲、下载、添加喜欢、删除文件、向普通用户隐藏或显示歌曲、应用配对或取消配对、账户添加修改删除、密码和设置更改。可按用户或操作类型筛选。已保存设置只列出名称，不显示值。记录保留 90 天。

应用也会报告播放内容，参见[移动客户端协议](../mobile-client-contract.md#8-report-plays)。

## 关闭账户功能

只有你能访问的服务器，例如本机运行，或已经位于要求密码的服务之后，可能不需要账户。设置 `DOWNTIFY_DISABLE_AUTH=true`，参见[环境变量](../getting-started/environment-variables.md#mobile-apps-and-sign-in)：

```yaml
environment:
  - DOWNTIFY_DISABLE_AUTH=true
```

此时：

- 不显示登录页，任何打开 Downtify 的人都作为第一位管理员使用，新服务器上为 `admin`。
- 退出按钮、**设置 → 用户**、**设置 → 常规**中的**账户**部分，以及**设置 → 应用**中的**退出所有设备**都会隐藏。
- 手机仍可配对到该管理员，**设置 → 活动**仍显示各设备的播放内容。
- 主题、语言和其他**常规**偏好按该管理员保存。

::: warning 任何能访问服务器的人都拥有全部权限
关闭账户后，不会检查身份：局域网中的所有人，或端口对外开放时互联网上的任何人，都可以修改设置、删除音乐和配对手机。其他人能访问的服务器不要关闭账户。
:::

将其设为 `false` 或移除后，会再次要求登录，账户、密码和应用保持原样。

## 忘记密码？

在服务器上运行以下命令，会将 `admin` 密码重置为 `downtify`；若账户被重命名或删除，会重新创建为管理员。其他账户和已配对应用不受影响：

```bash
docker exec downtify python main.py auth-reset
```

不使用 Docker 时，在 Downtify 文件夹中运行 `python main.py auth-reset`，或 `uv run python main.py auth-reset`。之后登录并修改密码。
