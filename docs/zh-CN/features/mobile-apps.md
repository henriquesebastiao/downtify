# 移动应用

Downtify 可为手机应用提供服务：直接从服务器浏览和流式播放音乐库，并将歌曲保存在手机上供离线收听。应用可使用用户名和密码登录，也可通过**设置 → 应用**中的代码配对；已配对应用和服务器名称也在该页面。哪些人可以使用服务器，由[用户与登录](users.md)中的账户决定。

::: warning 移动应用仍为实验功能
**设置 → 应用**标记为“实验功能”。本页描述的服务器端已完成并可用，但 **Android 应用尚未发布任何版本**，不同 Downtify 版本之间的配对和流式播放细节仍可能变化。

Android 应用在 [henriquesebastiao/downtify-android](https://github.com/henriquesebastiao/downtify-android) 公开开发。iPhone 和 iPad 应用位于 [michaelmoskie/Downtify-IOS-Client](https://github.com/michaelmoskie/Downtify-IOS-Client)，需要 iOS 17 或更新版本，支持登录或二维码配对、音乐库播放、离线下载，以及后台和锁屏控制。其他客户端也可使用相同 API 开发，参见[移动客户端协议](../mobile-client-contract.md)。
:::

## 从应用登录

输入服务器地址，或在**在此网络中找到**下选择服务器，然后使用与网页端**相同的用户名和密码**登录。手机会成为你的一个**已配对应用**，与下方通过代码配对的结果相同：以你的身份播放，保存独立密钥而不保存密码，可通过**取消配对**停用。

错误密码与网页端登录一起受到速率限制。关闭账户功能时（`DOWNTIFY_DISABLE_AUTH`），没有可用的登录凭据，请改用代码配对。

## 配对手机

配对无需在手机上输入密码，适合网页已经打开，或你不想在该手机上输入密码的情况。

1. 打开**设置 → 应用**并点击**配对手机**。
2. 在应用中选择**扫码**，将摄像头对准二维码，或输入下方显示的 8 字符代码（`K7QM-2XPD`，大小写和连字符不影响）。
3. 手机配对成功后，对话框会确认，并将其列在**已配对应用**下。

手机配对到**你的账户**：以你的身份播放，活动也归属于你。任何拥有账户的人都可以配对自己的手机。

代码只能使用**一次**，有效期为**五分钟**，错误代码尝试也受速率限制。手机获得并保存自己的密钥；服务器只保存其哈希。

**已配对应用**会列出你的手机及其平台、最近在线时间和来源地址；管理员可看到所有人的手机及所有者。**取消配对**会立即停用手机：下一次请求会失败，已打开的连接会关闭，手机分享的链接（参见[投放](#casting)）也会失效。再次使用需重新配对。

## 已配对应用的权限

已配对应用可以浏览、播放、标记喜欢、离线保存歌曲，以及请求服务器下载音乐，但不能更改设置、凭据或删除文件；这些操作需要在网页端以管理员身份登录。

**设置 → 应用 → 退出所有设备**会取消你全部应用的配对，并退出所有浏览器，包括当前浏览器。登录、账户和忘记密码的处理方法见[用户与登录](users.md)。

## 在局域网中发现服务器

服务器通过 mDNS / Bonjour，以 `_downtify._tcp` 在局域网中广播，因此应用可在**在此网络中找到**下列出其名称、地址和版本，无需手动输入。名称取自**设置 → 应用 → 服务器名称**，修改前使用机器的主机名。

::: info Docker 默认网络会隐藏广播
使用 Docker 默认的 *bridge* 网络时，广播只在 Docker 内部传播，手机无法发现。可使用 `network_mode: host` 运行容器（参见 [Docker Compose](../getting-started/docker-compose.md#finding-the-server-from-the-apps)），或在应用中手动输入服务器地址，其他功能不受影响。
:::

设置 `DOWNTIFY_DISCOVERY=false` 可停止广播。

## 流式播放音质

应用可按**原始格式**播放文件，或请求服务器生成较小的副本：96–320 kbps 的 Opus、AAC 或 MP3，适合移动数据网络。首次以这种方式播放歌曲时，服务器会用 ffmpeg 生成副本，普通歌曲通常需要几秒，并保留副本，因此可以像普通文件一样跳转进度，再次播放也无需等待。

- 已足够小的文件，即比特率不高于请求值的有损文件，会原样传输，不重新编码。
- 副本保存在 `/data/transcode_cache`，默认最多 2 GB，优先移除最久未播放的副本。同时最多生成两份。这两个限制都可通过[环境变量](../getting-started/environment-variables.md#mobile-apps-and-sign-in)设置。
- 手机在副本生成期间放弃请求时，服务器会停止生成。

## 音量标准化

Android 应用可使用与网页播放器相同的测量数据，让歌曲以相近响度播放：在其**设置 → 播放**中开启**标准化播放音量**。从下一首歌曲开始生效，未测量的歌曲保留原音量。只有完整下载且与服务器测量文件匹配的离线副本，才会使用测量数据。参见[音量标准化](playback-normalization.md)。

## 投放

应用可将歌曲投放到 Chromecast 或其他自行获取音频的播放器。应用从服务器取得仅用于该歌曲的限时链接，默认一小时内有效，而且手机必须保持配对；链接不包含手机密钥。

## 反向代理

如果 Downtify 位于 nginx、Caddy、Traefik 等反向代理后，用于 HTTPS 或外部访问：

- **转发 WebSocket。** `/api/ws` 需要转发 `Upgrade`/`Connection` 请求头。Caddy 和 Traefik 默认支持；nginx 需设置 `proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade";`。
- **原样转发 Range 请求**，不要缓冲音频响应。nginx 的 `proxy_buffering off;` 应用于 `/api/v1/` 和 `/downloads/`，否则会影响进度跳转和大文件。
- **告知 Downtify 信任哪个代理。** 将 `DOWNTIFY_TRUSTED_PROXIES` 设为代理地址，例如 `172.18.0.0/16`。只有这样，Downtify 才会使用 `X-Forwarded-For` 获取客户端地址，用于速率限制和已配对应用的最近在线信息，并使用 `X-Forwarded-Proto`/`X-Forwarded-Host` 将登录 Cookie 标记为安全和检查请求来源。未设置时会忽略这些请求头，因为任何人都可能伪造。
- **外部可访问的服务器应使用 HTTPS**：密码和应用密钥会随每次请求传输。
