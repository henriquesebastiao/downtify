# 相似歌曲

**Similar** 使用 YouTube Music 的电台混音查找与你指定歌曲风格相近的曲目，也就是 YouTube 在该歌曲之后接着播放的内容。无需 API 密钥或额外配置。

## 使用方法

从侧边栏（位于 **Charts** 下方；手机上位于 **More** 菜单中）打开 **Similar**。输入**艺人**或**歌曲**名称即可，然后点击 **Find similar**。只输入艺人时，系统会以该艺人的热门歌曲作为起点。

也可以直接从应用中的歌曲行开始查找：每行都有 **Similar** 按钮。搜索、排行榜和发现页面中的按钮显示为下载按钮旁的魔棒图标；热门歌曲和粘贴的链接中显示为轮廓图标；媒体库、专辑、艺人和播放列表歌曲行则可从上下文菜单打开。点击后会自动进入此页面，并开始搜索该歌曲。搜索结果也可以直接从所在行完整播放，无需先下载。

- **完整播放**：点击封面，歌曲会由此服务器串流到内置播放器，无论是否已下载都可以播放。
- **下载**：每一行都已关联对应视频，可直接下载。Downtify 会将匹配结果加入队列，并使用与其他下载相同的[匹配流程](../how-it-works.md)。随后该行会显示下载进度；歌曲进入媒体库后会显示勾选标记。
- **持续加载**：滚动到列表末尾会从最后一首歌曲自己的混音中加载下一页；播放到最后一行后，队列也会以相同方式继续扩展，列表不会结束。
