# 替换音频

Downtify 会自动为每首歌曲选择音频，但有时选中的版本并不正确：可能是同名歌曲、现场版、混音版，或带有很长前奏的上传音源。**Replace audio** 可让你手动选择正确版本。曲目在各处的关联保持不变，包括播放列表、M3U 文件、喜欢的歌曲和配对应用；只有音频内容会更换。

只有管理员可以替换音频（参见[用户与登录](users.md#admins-and-users)）。

## 替换曲目的音频

1. 在 **Library** 中打开曲目菜单（右键单击或点击 **⋯** 按钮），然后选择 **Replace audio…**。
2. Downtify 会在 **YouTube Music** 和 **YouTube** 上搜索“艺人 - 标题”，并列出搜索结果。你可以修改搜索词，也可以粘贴一个 YouTube 或 YouTube Music 视频/歌曲链接，或 SoundCloud 曲目链接，以精确指定所需音源。
3. 选择一个版本。每个结果都会显示来源和时长，并与当前文件的时长对照。与文件时长相差不超过 3 秒的版本会突出显示。点击 ↗ 按钮可在 YouTube 上打开该结果，选择前可以先试听。
4. 点击 **Replace audio**。替换过程与下载相同，会在对话框和 **Queue** 中显示进度；完成后对话框会提示。

如果替换失败（例如视频不可用，或 YouTube 要求登录；参见 [YouTube cookies](youtube-cookies.md)），原文件会保持不变。在 Queue 中点击 **Retry** 可重试同一视频；粘贴另一个链接则会改用该链接替换。

## 使用设备上的文件

当正确的版本不在 YouTube 上时（CD 抓轨、Soulseek 下载、别人发给你的文件），可以使用你自己的文件：

1. 在对话框的**或使用设备上的文件**下，点击**选择文件…**并选取音频文件。
2. 点击**替换音频**。文件会被上传，检查是否为可读取的音频，并获得旧文件的标签。

与曲目格式相同的文件（`.mp3` 曲目对应 `.mp3`）会原样使用。其他格式（`.mp3`、`.flac`、`.m4a`、`.ogg`、`.opus`、`.wav`、`.aiff`、`.aac` 或 `.webm`）会按[下载设置](download-settings.md)中选择的比特率转换为曲目的格式，因此有相同格式时请优先使用。仅音乐库模式下也可使用，因为不会从互联网获取任何内容。

## 下载不会改动已替换的文件

开启**文件存在时重新下载**后，之后再次下载同一首歌（来自另一个受监控播放列表、艺人关注或播放列表下载）会用自动匹配找到的内容覆盖你的替换。因此，Downtify 会记住你以任一方式替换过音频的每个文件，此类下载会将其视为已下载。[升级音乐库](library-upgrade.md)也不会替换其音频；其封面、歌词和标签仍可升级。

对话框会显示曲目的音频是否已手动替换。**允许下载替换它**可为该文件取消此保护。

## 保持不变的内容

- **文件路径和格式。** 新音频会写入同一路径，并保持原格式：`.mp3` 仍为 MP3（比特率采用[下载设置](download-settings.md)中的选择），`.flac` 仍为 FLAC，以此类推。因此，所有指向该文件的播放列表、M3U 文件、喜欢的歌曲、Navidrome 条目和配对应用都仍指向原位置。
- **标签。** 标题、艺人、专辑、曲目编号、年份、封面、内嵌歌词及其他标签都会从旧文件原样复制到新音频中。`.lrc` 侧车文件不会改变。同步歌词是按旧音频定时的；如果新版本的起始位置不同，歌词时间可能会错位。
- **日期。** 文件保留原修改日期，因此不会在“最近添加”列表中突然排到最前面。

只有 Downtify 支持写入的 `.mp3`、`.flac`、`.m4a`、`.ogg` 和 `.opus` 文件可以替换。

## 工作原理

选中的视频会下载到原文件旁，使用媒体库会忽略的临时文件名（`<name>.downtify-upgrade.<ext>`）。随后系统将其转换为原文件格式，检查其是否为可读取的音频，写入旧文件的标签，最后才覆盖旧文件。API 说明见 [API 参考](../api-reference.md#get-apilibraryreplacecandidates)。
