# 支持艺人

Downtify 从 YouTube 下载音乐。遇到喜欢的作品时，**Support the artist** 会告诉你可以在哪里购买，让收入流向创作这些作品的人。

## 打开入口

| 位置 | 打开的内容 |
|-------|---------------|
| 搜索结果和排行榜 | 歌曲行上的 **tag** 按钮，位于 YouTube Music 链接旁（大屏幕上悬停时显示） |
| Library 中歌曲的 **⋯** 菜单，以及当前播放页面 | 对应歌曲 |
| 专辑的 **⋯** 菜单 | 对应专辑 |
| 艺人的 **⋯** 菜单 | 该艺人的全部作品 |

## 购买链接

对歌曲、专辑或艺人，对话框会列出：

| 商店 | 链接 |
|------|------|
| **iTunes Store** | 如果商店中明确存在对应项目（艺人和标题一致），则打开该项目并显示价格；否则打开 Apple Music 搜索结果。 |
| **Bandcamp** | 搜索结果。Bandcamp 会将大部分销售收入交给艺人，许多艺人也会在此直接销售作品。 |
| **Qobuz** | 搜索结果。Qobuz 销售无损及高解析度下载。 |
| **官方网站** | 如果艺人的[个人资料](artist-images.md)中填写了网站，则显示其官方网站。 |

iTunes Store 链接会根据浏览器语言中的国家/地区信息打开相应商店（`pt-BR` 会打开巴西商店并以雷亚尔显示价格；没有地区标记的语言则打开美国商店）。如果歌曲只能作为专辑的一部分销售，则不会显示单曲价格。

Bandcamp 和 Qobuz 没有公开查询接口，因此链接会搜索艺人和标题（或专辑、艺人名称）。购买前请确认搜索结果对应正确的版本。

::: info 仅提供链接
Downtify 不销售商品，也不会从这些链接中获利。为了填充对话框，它只会向 Apple 的公开 iTunes Search API 发送一次请求，查询内容仅包含艺人和标题，并在服务器运行期间缓存结果。在你打开链接之前，不会有其他信息离开你的服务器。
:::

## 应用中的接口

应用通过 [`GET /api/buy`](../api-reference.md#get-apibuy) 获取相同的链接。
