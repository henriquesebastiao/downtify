# 内置播放器

Downtify 内置网页播放器，无需其他应用即可收听下载的音乐。在音乐库的任意歌曲、专辑、艺人或播放列表上点击播放，或播放队列中的已完成下载，即可启动播放器。

## 播放栏

载入歌曲后，每页底部都会浮动显示播放栏，包括封面、标题和艺人、随机播放、上一首、播放/暂停、下一首、循环、已播放及总时长，以及歌词和接下来播放面板的入口。歌词入口可以[隐藏](#hiding-the-lyrics)。宽屏还提供音量滑块，以及位于播放栏顶边的进度条；手机上只保留主要控件，并显示细进度线。

标题旁有一个心形按钮，用于[添加喜欢](liked-songs.md)。手机播放栏为了给标题留出空间，不显示该按钮，但**正在播放**和歌曲列表中仍有。

点击标题、封面或展开按钮，即可打开**正在播放**。

## 正在播放

这是一个全屏视图，色彩取自当前专辑封面：

- **大封面**、标题和艺人，点击艺人或“正在播放专辑/播放列表/艺人作品”等来源标签可跳转到对应页面；标题旁有心形按钮，可[添加喜欢](liked-songs.md)。封面和歌词会随窗口缩小，即使只改变高度，也会保持在页头下方。
- **进度条**：点击、拖动，或聚焦后使用方向键。播放时，已播放部分会显示取自封面颜色的柔和波纹；暂停时变平，系统要求减少动态效果时保持静止。
- **播放控件**：随机播放、上一首、播放/暂停、下一首、循环（关闭 → 列表循环 → 单曲循环）。
- **音量**：提供静音开关，重启浏览会话后仍保留。手机上隐藏，由硬件音量按钮控制。
- **睡眠定时器**：可在 15、30、45、60 或 90 分钟后停止，或在当前歌曲结束时停止。剩余时间显示在定时器按钮旁。
- **文件信息**：当前文件的格式和大小。

宽屏上，封面旁提供五个面板；手机上则替换封面显示：

- **歌词**：时间轴歌词会突出当前行，并随歌曲滚动；点击歌词行可跳转到对应位置。纯文本歌词按原样显示。歌词来自歌曲旁的 `.lrc` 文件或嵌入标签，参见[歌词](lyrics.md)。可以隐藏此面板，参见[隐藏歌词](#hiding-the-lyrics)。
- **卡拉OK**：使用相同歌词，方便跟唱。歌词以超大居中行占据屏幕，封面、标题和艺人移到页头关闭按钮旁，替代原来的播放来源标签；宽屏页头还显示下一首歌曲。接下来播放栏会隐藏，播放控件缩小，宽屏上与进度条合为一行，但所有操作仍可用。当前行从左到右填充，前奏和间奏期间有三个点提示进入时机。歌词后方的舞台烟雾使用封面颜色，从屏幕右上方飘入，最多覆盖到中间，正在演唱的歌词背景保持清晰。暂停时烟雾停止，系统要求减少动态效果时不显示。LRC 只记录每行开始时间，因此填充按估计的行时长进行。点击一行可跳转；纯文本歌词以大字显示，但没有时间轴效果。
- **接下来播放**：播放队列。可拖动调整歌曲顺序、移除单首歌曲，或清空当前歌曲之后的全部内容。
- **详情**：标题、艺人、专辑、曲目编号、年份、时长、格式、大小、添加日期和文件路径。
- **均衡器**：用十个频段调整音色，参见[均衡器](#equalizer)。

正在播放视图会反映在页面地址中（`?np=1`，以及 `&panel=lyrics|karaoke|queue|details|equalizer`），因此浏览器后退按钮可关闭它，刷新后仍会保持打开。

宽屏上可通过卡拉OK 页头的**在新窗口中打开**按钮投影歌词。歌词会在独立窗口中显示，适合投影仪或第二块屏幕；主屏幕的正在播放视图会关闭，方便在演唱期间继续浏览 Downtify。

新窗口只显示歌曲、封面、下一首和卡拉OK 歌词，不提供播放控件。所有控制均在主窗口完成，投影窗口会立即同步：直接播放另一首会立即替换正在演唱的歌曲，**下一首播放**和**添加到队列**则只安排后续歌曲，不打断当前播放。

将窗口拖到投影屏幕后，点击右下角的**全屏**。鼠标几秒不移动后，按钮和指针会隐藏。系统需要将桌面扩展到投影仪，而非镜像显示。若浏览器阻止窗口，请允许 Downtify 弹出窗口后再次点击按钮。

请保持主窗口打开，因为音频在主窗口中播放。页面切换不影响播放；刷新主窗口会暂停音乐，需再次点击播放，投影窗口随后会自动同步。关闭主窗口会停止音乐，投影窗口将停留在等待状态，此时也应关闭投影窗口并重新打开。两个窗口必须位于同一台电脑的同一个浏览器。

## 隐藏歌词

如果更喜欢只看封面和队列，可关闭**设置 → 常规 → 播放器 → 在播放器中显示歌词**。立即生效，并移除播放器中的所有歌词入口：

- **歌词**和**卡拉OK**面板及标签页，手机上则移除正在播放页脚中的对应按钮；
- 播放栏中的歌词按钮；
- `L` 快捷键，同时从快捷键列表（`?`）中移除。

正在播放视图此后默认打开**接下来播放**。关闭前保存的 `&panel=lyrics` 链接也会跳转到该面板，不会进入空标签页。隐藏期间播放器完全不会请求歌曲歌词。

::: info 隐藏不等于删除
这只改变播放器显示内容。文件中已嵌入的歌词和音频旁的 `.lrc` 文件都会保留，媒体服务器和其他播放器仍能读取。下载也仍会获取歌词，这是**标签与歌词**下独立的**下载歌词**设置控制的，参见[歌词](lyrics.md)。
:::

与主题和均衡器一样，此选择保存在浏览器的 `localStorage` 中，按设备和浏览器分别生效，而非按 Downtify 服务器生效。可以在手机上隐藏，在桌面上保留。

## 均衡器

正在播放的**均衡器**面板提供十段图形均衡器，也可按 `E` 打开。它标记为**实验功能**，仍可能变化，或在部分浏览器中表现异常，参见[浏览器支持](#browser-support)。

- **频段**为 31、62、125、250、500 Hz 和 1、2、4、8、16 kHz，各可在 ±12 dB 范围内以 0.5 dB 步长调整。31 Hz 和 16 kHz 使用搁架滤波器，也会提升或降低其下方或上方的全部频率。可拖动频段，或聚焦后使用方向键；`Page Up`/`Page Down` 每次调整 1 dB，`Home`/`End` 到达上下限。双击重置为 0。
- **预设**：平直、低音增强、高音增强、人声、摇滚、电子和原声。之后移动任意频段会切换为**自定义**。
- **前级增益**：在所有频段之外额外调整 ±12 dB。
- **开启/关闭开关**和**重置**，重置后为平直、前级增益 0、关闭。移动频段或选择预设也会开启均衡器。
- 滑块后方的曲线表示所有频段的合成响应。

提升频段可能让高音量音乐超过满幅并失真，因此 Downtify 会按曲线的最大增益自动降低音量，面板会显示降低了多少。这样峰值保持在 0 dB，增强预设改变的是音色，而不只是变响。将前级增益提高到 0 dB 以上会移除这部分保护，面板会警告响亮片段可能失真。

设置保存在浏览器的 `localStorage` 中，适用于所有标签页的全部播放，直到再次修改。它按浏览器生效，而非按 Downtify 服务器生效。

### 浏览器支持

均衡器使用 Web Audio API，当前浏览器均可使用。开启前，播放完全不经过 Web Audio；开启后，本次访问余下的音频都会经过它，关闭开关只会将所有频段恢复平直。

::: warning iPhone 和 iPad 上的 Safari
iOS 可能在锁屏或切换应用时暂停 Web Audio，导致均衡器开启时播放停止。若要熄屏收听，请关闭均衡器并重新加载页面。
:::

## 创建播放队列

播放专辑、艺人、播放列表或歌曲列表时，会按顺序加入队列，并从所选歌曲开始。对合集选择**随机播放**会以随机顺序开始。未下载歌曲也能在队列中完整播放，由服务器流缓存提供；当前歌曲播放时会提前准备下一首，因此可连续播放未下载条目，即使浏览器本身无法访问 YouTube。匹配未下载歌曲时，播放器会跳过与已知时长相差超过 10 秒的搜索结果。流式歌曲不会保存、添加喜欢，也不会在刷新后保留。

每首歌曲的菜单（**⋯** 按钮，或桌面端右键）提供：

- **下一首播放**：插入到当前歌曲之后；
- **添加到队列**：追加到末尾；
- **前往专辑** / **前往艺人**；
- **保存到此设备**：通过浏览器下载文件；
- **从音乐库删除**。

音乐库中选择多首歌曲时也可执行相同操作。

队列、当前歌曲及位置、随机播放和循环状态都会记住，重新打开 Downtify 可从上次位置继续；超过 2000 首歌曲的队列不会保存。已删除文件会自动从队列中移除。

## 键盘与媒体按键

| 按键 | 操作 |
|-----|--------|
| `Space` | 播放/暂停 |
| `←` / `→` | 快退/快进 5 秒 |
| `Shift` + `←` / `→` | 上一首/下一首 |
| `↑` / `↓` | 调整音量 |
| `M` | 静音 |
| `S` | 随机播放 |
| `R` | 循环 |
| `L` | 打开歌词，[隐藏](#hiding-the-lyrics)时除外 |
| `Q` | 打开接下来播放 |
| `E` | 打开均衡器 |
| `Ctrl` / `⌘` + `K` 或 `/` | 搜索 |
| `Ctrl` / `⌘` + `F` | 搜索播放列表，在播放列表页面生效 |
| `G` 后按 `L` / `D` | 前往音乐库/队列 |
| `Esc` | 关闭正在播放 |
| `?` | 显示全部快捷键 |

在输入框中键入或对话框打开时，不处理快捷键。

播放器也通过 Media Session 向操作系统报告当前歌曲，因此锁屏控件、耳机按钮和键盘媒体键都可使用，系统支持时还会显示封面。

## 工作原理

歌曲来自音乐库列表（`GET /tracks`），从文件标签读取标题、艺人、专辑、曲目编号、年份和时长。文件通过 `/downloads` 静态挂载提供；[保留原位](slskd-navidrome.md#leave-files-in-place)的 slskd 下载通过 `/media/slskd/…` 播放。封面来自 `/cover`，歌词来自 `/lyrics`，参见 [API 参考](../api-reference.md#file-management)。

播放使用浏览器原生 HTML5 音频，无需插件或额外进程。

## 支持的格式

播放器可播放浏览器 HTML5 音频引擎支持的任何格式。现代浏览器通常都支持 MP3、M4A/AAC、OGG 和 OPUS。FLAC 支持因浏览器而异：Chrome 和 Edge 原生支持，Firefox 和 Safari 可能不支持。
