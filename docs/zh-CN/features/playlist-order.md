# 播放列表顺序与重复歌曲

你在音乐库中通过**新建播放列表**、**保存副本**、[解除来源关联](library-catalog.md#detach-an-imported-playlist)或[从音乐文件夹导入](external-playlists.md)创建的播放列表，会保留你指定的歌曲顺序，也允许同一首歌曲播放多次。跟随 Spotify、YouTube Music 或 Deezer 链接的播放列表保留来源顺序；**喜欢的歌曲**则按添加喜欢的时间排序。

## 调整播放列表顺序

1. 打开播放列表，在歌曲上方排序选择器旁点击**调整顺序**。
2. 移动歌曲：
    - 用鼠标将歌曲行拖到新位置；
    - 或使用每行的**上移**和**下移**箭头，宽屏还提供**移到最前**和**移到最后**。焦点会留在箭头上，方便用键盘连续移动同一首歌曲。
3. 点击**保存顺序**，或选择**取消**保留原样。

保存后，页面排序会切换为**播放列表顺序**，显示刚保存的顺序。顺序还会写入播放列表的 M3U 文件，Jellyfin、Navidrome、Plex 等读取该文件的媒体服务器也会采用。

所有者、管理员和播放列表的[编辑者](collaborative-playlists.md)都可以调整顺序，并有以下保护：

- **不会丢失他人的修改。** 若你调整顺序期间有人添加或移除歌曲，保存时会重新加载播放列表并要求再次排序，不会覆盖他人的修改。
- **对你隐藏的歌曲保持原位。** 管理员[向普通用户隐藏](users.md#hiding-from-users)的歌曲不会显示在你的列表中，保存后仍保留其原位置。

## 重复添加歌曲

添加列表中已有的歌曲时，会先询问：

- 在歌曲 **⋯** 菜单中选择**添加到播放列表**后，对话框会提示**已在此播放列表中**。选择**仍然添加**可在末尾再添加一次，或选择**不添加**。一次添加多首歌曲时，只会统一询问已有的歌曲，其他歌曲无论如何都会添加。
- 在播放列表页面的**添加歌曲**对话框中，已有歌曲会标记为**已添加**。勾选后会再次添加。

每次出现都作为独立一行：在对应位置播放，有自己的编号，也可以单独移动。**保存副本**会保留重复项。播放列表最多容纳 500 首歌曲，重复项也计入。

## 移除一个重复项

在某行 **⋯** 菜单中选择**从播放列表移除**，只会移除该行，同一歌曲的其他重复项保持原位。

## 应用与脚本

- [`PUT /api/library/playlists/order`](../api-reference.md#put-apilibraryplaylistsorder) 保存新顺序，包含调用者可见的每首歌曲及重复项。若播放列表在此期间发生变化，返回 `409`。
- [`POST /api/library/playlists/tracks`](../api-reference.md#post-apilibraryplayliststracks) 接受 `allow_duplicates` 以再次添加歌曲，通过 `already` 返回跳过的歌曲，并接受 `remove_entries` 以移除一个重复项。
- [`GET /playlists`](../api-reference.md#get-playlists) 和 [`GET /api/v1/playlists`](../api-reference.md#get-apiv1playlists) 返回的播放列表歌曲行，会按顺序为每个重复项列出一行。Android 应用会显示全部重复项；调整顺序需在网页端进行。
