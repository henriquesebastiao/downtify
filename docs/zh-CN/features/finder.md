# Finder

**Finder** 可用于在下载前浏览 Deezer 曲库。你可以搜索 Deezer，再打开艺人页面，以并排的三列浏览内容，类似 macOS Finder 的分栏视图：艺人、其作品目录，以及某张专辑中的曲目。无需 Deezer 账户或 API 密钥。

## 搜索

从侧边栏打开 **Discover**（手机上：**More → Discover**）：Finder 的搜索框位于页面顶部，旁边会显示最近的 Finder 搜索记录。搜索会用结果替换 Discover 推荐内容；结果包括歌曲、专辑和艺人，并提供 **All / Songs / Albums / Artists** 筛选标签，体验与常规 Search 页面类似，但结果仅来自 Deezer。清空搜索框（点击 **×**）或返回即可再次查看推荐内容；点击最近搜索可重新执行，点击 **Clear** 可清除所有记录。最近搜索仅保存在当前浏览器中。

在 Discover 推荐的艺人上选择 **Find songs**（该艺人的 **⋯** 菜单项），会在此处以搜索结果形式列出艺人歌曲：系统按艺人名称查询 Deezer，并通过 Deezer ID 精确匹配该艺人，排除同名艺人或仅仅歌曲名相同的结果，最多列出前几百首歌曲。

- **歌曲**可完整试听，也可像其他搜索结果一样下载。Downtify 会根据标题、艺人和时长在 YouTube Music 上匹配歌曲（失败时回退到 YouTube）。点击歌曲标题会在分栏视图中打开其专辑，并突出显示该曲目。
- **专辑**会在对应艺人的页面中打开，并选中该专辑。点击封面上的下载按钮会将整张专辑加入队列。
- **艺人**会在分栏视图中打开该艺人页面。

## 分栏视图

| 栏 | 显示内容 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Artist** | 艺人照片、专辑数量、界面语言对应的简介（可展开）、最受欢迎的 10 首曲目，以及“Fans also like”（相关艺人）。 |
| **Discography** | 按发行时间从新到旧列出所有专辑、单曲、EP 和合辑，并显示封面、标题、发行类型、年份和曲目数量。可按发行类型筛选。 |
| **Tracks** | 当前选中专辑的封面和标题、艺人、年份、曲目数量和时长。信息面板列出发行日期、厂牌、流派、制作人员和 UPC。下方列出专辑曲目；下载前可完整试听，下载后则从媒体库播放。**Download album** 按钮可将全部曲目加入队列。 |

点击热门曲目会选中其专辑并突出显示该曲目，两个分栏会平滑滚动到相应位置（如果系统设置了减少动态效果，则立即滚动）。专辑曲目显示后，歌曲会开始完整播放：从流媒体播放，或在曲目已存在于媒体库时播放本地文件。播放时再次点击不会暂停；通过指向曲目的链接打开页面时不会自动播放。点击相关艺人可打开其页面，浏览器后退按钮可返回上一个艺人。分栏上方的路径栏（**Discover › artist › album**）可返回搜索页面（如果分栏不是从 Discover 打开的，则返回 Discover），或仅返回艺人页面。当前打开的内容会保存在 URL 中，因此刷新后仍会保留，也可加入书签。

在宽屏上，可拖动两列之间的边缘来调整宽度，也可以聚焦边缘后使用方向键。双击可恢复默认宽度。艺人和作品目录栏顶部的箭头按钮可将分栏折叠为仅显示图片：艺人照片、热门曲目封面和相关艺人照片，或专辑封面。每张图片仍可执行对应整行的操作，悬停时会显示名称。列宽和折叠状态仅在当前页面会话中有效，不会保存；刷新或离开 Finder 后会重置。

在手机上，分栏并排显示，可左右滑动切换。选择专辑后会滑动到曲目栏。

::: info 曲目数量为何稍后才显示
Deezer 的作品目录列表不包含曲目数量，因此 Downtify 会分批查询每张专辑的曲目数，并遵守 Deezer 每 5 秒最多 50 次请求的限制。查看时数量会逐步显示，并缓存至 Downtify 重启。无法获取曲目数的专辑会显示 `…`。
:::
