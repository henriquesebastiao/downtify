# 导入文件夹中的播放列表

进入 Library → Playlists → Import folder playlists，可扫描已配置的额外音乐文件夹，查找 M3U 和 UTF-8 编码的 M3U8 文件。预览可用、缺失和重复的条目，选择需要导入的播放列表，并明确确认导入。对于常见于 Deemix 导出的通用 `playlist.m3u8` 文件，会使用其所在文件夹名称作为播放列表名称。相对路径以播放列表文件所在目录为基准解析。

导入会创建私有、可编辑的 Downtify 播放列表，并引用已有音频文件。导入不会修改源播放列表或音频，不会移动外部文件，也不会自动导入所有候选项。同一账号重复导入时会复用之前创建的播放列表；不同账号会得到独立副本，名称冲突时会追加后缀。空文件仍会出现在预览中；不可用的条目不会加入最终播放列表。

只接受位于已配置音乐根目录中的现有音频。URL 和越出这些根目录的路径都会被排除。如果源文件发生变化，必须重新预览。

限制：每个文件最大 2 MiB、最多 20,000 行；最多扫描 500 个候选文件 / 100,000 个条目；每个请求最多选择 50 个播放列表。界面会显示离线文件夹和扫描限制。
