# 仅媒体库模式

管理员可以在 **Settings → General → Use only the library** 中启用此模式。默认关闭。这是一项适用于所有账号、浏览器和已配对 Android 应用的全服务器音乐策略。

搜索会匹配服务器媒体库中可见的标题、艺人和专辑。现有页面、导航和播放器保持原有布局。搜索、Discover 和 Charts 使用本地曲目、专辑、艺人和播放列表。相似曲目根据保存的艺人、专辑以及（如有）流派标签进行排序；这是基于元数据的匹配，不是声学分析。搜索起点和重复录音会排除在结果之外；如果起点未知，或媒体库中没有相关曲目，则返回空结果，不会回退到外部电台服务。现有媒体库可见性规则仍然有效。添加到服务器的本地音乐文件夹也属于媒体库，包括只读挂载。

外部音乐搜索、链接解析、预览、串流（包括串流缓存文件）、下载、替换和在线媒体库升级都会被拒绝。自动监控的播放列表以及 Spotify 缓存预热会停止获取内容，但不会删除订阅、修改上次检查时间或消耗待处理任务。关闭此模式后，这些任务会恢复。此设置不会删除音频或清空媒体库，也不会启动任何新下载。

## 安全切换

启用前请等待正在进行的下载、检查或在线升级完成。如果仍有外部音乐任务正在运行，启用操作会返回 HTTP 409；不会取消任务，也不会部分保存设置。任务结束后请重新保存。JSON 设置项为 `library_only`，且只接受布尔值。

服务器会立即执行此策略。当前客户端会收到 `music_policy_changed` WebSocket 事件，并每 15 秒定期刷新策略，也会在重新连接时刷新。客户端会丢弃外部搜索结果和串流队列条目；本地播放和剩余本地曲目的顺序会保留。客户端接收到策略变更后，之前缓冲的外部音频也会停止。旧客户端无法调用服务器的外部音乐接口，但只有更新后的客户端才能清除已经缓冲的音频。

## Android 与连接要求

应用会从 `GET /api/server/info` 读取 `library_only`，并与已配对服务器信息一同保存。旧服务器缺少此字段时按关闭处理。Android 应用会搜索已同步的媒体库、接收本地相似曲目结果，并继续播放媒体库中已下载的文件。

手机需要连接服务器，才能串流媒体库文件或请求相似歌曲。将文件保存在手机上属于单独的离线下载功能。此模式不会把服务器变成互联网防火墙；更新检查等非音乐管理功能不受影响。

## API 兼容性

`POST /api/settings/update` 接受 `{"library_only": true}`（仅管理员可用）。`GET /api/settings` 返回持久化的布尔值。`GET /api/server/info` 新增同一布尔字段，但不会修改 `api_version`。

搜索和相似歌曲接口保持原有响应结构。本地歌曲行包含 `source: "library"`、`file` 和 `song_id: "library:<file>"`；`url` 为空，也不包含外部预览。应使用现有媒体库文件，或将其与移动同步 feed 匹配；不要通过外部来源解析该行。艺人/专辑搜索接口会以相同响应结构返回本地卡片；这些卡片会打开现有媒体库艺人页和专辑页。被阻止的外部音乐接口返回 HTTP 409，并附带说明信息。关闭此设置后，接口和来源设置恢复原有行为。
