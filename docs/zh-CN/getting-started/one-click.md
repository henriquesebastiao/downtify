# 一键安装

Downtify 已上架多个主流家庭服务器平台的应用商店，无需使用命令行。

## 支持的平台

| 平台 | 应用商店链接 |
|----------|-----------|
| **Umbrel** | [apps.umbrel.com/app/downtify](https://apps.umbrel.com/app/downtify) |
| **CasaOS** | [casaos.zimaspace.com](https://casaos.zimaspace.com/) |
| **HomeDock OS** | [homedock.cloud/apps/downtify](https://www.homedock.cloud/apps/downtify/) |

各平台会自动处理 Docker 镜像、卷和重启策略。安装后，可从平台控制面板打开 Downtify；默认端口为 **8000**。

## 更新

更新通过相应平台的应用商店管理。发现新版本时，打开 Downtify 应用条目并点击 **Update**。音乐库和设置会自动保留。

## 自定义配置

通常可以在各平台的应用设置面板中配置环境变量（参见[环境变量](environment-variables.md)）。具体位置请查阅相应平台的文档。
