# Установка в один клик

Downtify есть в магазинах приложений самых популярных платформ для домашних серверов. Командная строка не нужна.

## Поддерживаемые платформы

| Платформа | Ссылка на магазин |
|----------|-----------|
| **Umbrel** | [apps.umbrel.com/app/downtify](https://apps.umbrel.com/app/downtify) |
| **CasaOS** | [casaos.zimaspace.com](https://casaos.zimaspace.com/) |
| **HomeDock OS** | [homedock.cloud/apps/downtify](https://www.homedock.cloud/apps/downtify/) |

Каждая платформа сама заботится об образе Docker, томах и политике перезапуска. После установки откройте Downtify с панели платформы — порт по умолчанию **8000**.

## Обновление

Обновления управляются через магазин приложений платформы. Откройте карточку Downtify и нажмите **Обновить**, когда выйдет новая версия. Ваша музыкальная библиотека и настройки сохраняются автоматически.

## Особые настройки

Переменные окружения (см. [Переменные окружения](environment-variables.md)) обычно можно задать в панели настроек приложения на каждой платформе. Где именно — смотрите в документации вашей платформы.
