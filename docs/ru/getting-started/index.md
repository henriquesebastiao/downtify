# Начало работы

Downtify — это веб-приложение для домашнего сервера, которое скачивает музыку из Spotify: без API-ключей, без аккаунта и без подписки Premium. Всё работает внутри одного Docker-контейнера.

## Что потребуется

- **Docker** (или Docker Compose) — единственное требование к хост-машине
- Машина с доступом в интернет
- Тома или папка, куда будет сохраняться музыка

## Дальнейшие шаги

Когда Downtify запустится, откройте в браузере [http://localhost:8000](http://localhost:8000). Вставьте в строку поиска ссылку на трек, альбом или плейлист Spotify и нажмите **Скачать**.

Почитайте остальную документацию, чтобы узнать о [настройках загрузок](../features/download-settings.md), [мониторе плейлистов](../features/playlist-monitor.md), [встроенном плеере](../features/player.md) и не только.
