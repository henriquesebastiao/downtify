# Отображаемые названия плейлистов

Используйте **Переименовать** у импортированного или синхронизируемого плейлиста, чтобы выбрать его
название внутри Downtify. Это меняет только отображаемое название: URL источника, идентификатор
источника, файлы, права доступа и синхронизация остаются прежними. Последующие
синхронизации сохраняют пользовательское название. **Вернуть название источника**
удаляет его. Downtify не переименовывает плейлист на Spotify, YouTube или Deezer.

Переименовать плейлист может только владелец или администратор. Любимые песни сохраняют
своё зарезервированное название. Названия должны быть непустыми, не длиннее 120 символов и
не должны совпадать с другим плейлистом, видимым владельцу.

Локально созданные плейлисты сохраняют своё прежнее поведение переименования.
Ответ мобильного приложения о плейлисте добавляет `display_name`; `name` остаётся стабильным
ключом поиска. Совместимые клиенты должны показывать название и продолжать использовать `name`
в запросах к API. Старые клиенты продолжают использовать исходное название.
