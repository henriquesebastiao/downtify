# Уведомления об обновлениях

Downtify раз в час проверяет свою [страницу GitHub Releases](https://github.com/henriquesebastiao/downtify/releases). Когда выходит более новая версия, уведомление появляется внизу боковой панели на каждой странице — на телефонах это точка на вкладке **Ещё** и строка вверху её листа — а также в **Настройки → О программе**:

> ✦ Доступно обновление 3.0.1

Нажмите на него, чтобы открыть этот релиз на GitHub.

## Как это работает

- Фоновая задача в бэкенде (`downtify/update_check.py`) запрашивает последний релиз из API GitHub один раз сразу при запуске, затем каждый час. Она работает в отрыве от всего остального: пользовательский интерфейс её не ждёт.
- Веб-интерфейс раз в час читает кешированный результат из `GET /api/check_update` (см. [Справочник API](../api-reference.md)) и показывает уведомление, когда найдена более новая версия.
- Версии сравниваются численно (`2.10.0` < `2.9.0` — ложь, в отличие от обычного сравнения строк), а необязательный префикс `v` в теге релиза игнорируется.

## Если GitHub недоступен

Неудавшаяся проверка (хост без сети, ограничение частоты GitHub) записывается в журнал и просто повторяется в следующий часовой проход — предыдущий результат, если он есть, действует до тех пор. Проверка никогда не блокирует ничего из того, что делает Downtify; ошибки для пользователя здесь нет.

## Ничего не скачивается автоматически

Это лишь *сообщает* вам о существовании новой версии — Downtify не обновляет сам себя. Чтобы обновиться по-настоящему, подтяните новый образ и пересоздайте контейнер:

```bash
docker compose pull
docker compose up -d
```
