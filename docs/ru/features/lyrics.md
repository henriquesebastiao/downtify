# Тексты

Downtify ищет тексты во время загрузки трека и встраивает их в файл, плюс сохраняет sidecar-файл `.lrc`, когда они синхронизированы по времени.

## Включение текстов

Тексты **включены по умолчанию**. Выключить их можно в **Настройки → Теги и тексты → Скачивать тексты**.

## Провайдеры и порядок резервных вариантов

Каталоги различаются: песня, о которой один провайдер никогда не слышал, часто есть у другого. Поэтому Downtify хранит упорядоченный список провайдеров и пробует их по одному, останавливаясь на первом, у которого что-то есть.

| Провайдер | Тексты | Примечания |
|----------|--------|-------|
| **[LRCLIB](https://lrclib.net)** | Обычные и синхронизированные по времени | Бесплатная база сообщества, без ключа. Сопоставление по названию, основному артисту, альбому и длительности. |
| **NetEase Cloud Music** | Обычно синхронизированные по времени | Большой каталог, силён в азиатских релизах и часто в западных тоже. Сопоставление по названию, артисту и длительности; совпадение, у которого артист написан иначе (например, традиционный и упрощённый китайский), принимается только когда совпадают и название, и длительность. |

В **Настройки → Теги и тексты → Провайдеры** можно перетащить провайдеров в нужный порядок или использовать стрелки и выключить любого из них. Хотя бы один остаётся включённым; чтобы совсем перестать искать тексты, используйте переключатель **Скачивать тексты**.

::: info А как же Genius, Musixmatch и AZLyrics?
Они недоступны, и Downtify больше их не предлагает:

- **AZLyrics** запрещает стороннее использование своих текстов прямо на странице.
- Настольный API **Musixmatch** отвечает пустым токеном, если у вас нет учётных данных, которые он не выдаёт приложениям.
- `robots.txt` у **Genius** запрещает конечную точку поиска, нужную для нахождения страницы песни.

Сохранённые настройки, где они ещё указаны, продолжают работать: имена игнорируются, а список, в котором больше ничего не осталось, откатывается к провайдерам по умолчанию.
:::

## Пропуск провайдеров, у которых ничего не было

После поиска Downtify записывает для каждой песни, какие провайдеры ответили, а какие вернулись пустыми, в `downtify_library.db` в `/data`.

Провайдера, у которого ничего не было для песни, больше не спрашивают о ней **30 дней**, поэтому повторные загрузки и большие проходы по библиотеке не повторяют одни и те же неудачные поиски. После этого его пробуют снова, поскольку каталоги растут. Провайдер, у которого тексты *были*, никогда не пропускается, поэтому заново скачанный файл их получает.

## Встраивание

| Формат | Тег обычных текстов | Тег синхронизированных текстов |
|--------|-----------------|------------------|
| MP3 | `USLT` (ID3) | `USLT` с временными метками |
| FLAC | `LYRICS` (комментарий Vorbis) | `LYRICS` с содержимым LRC |
| M4A | `©lyr` | `©lyr` с содержимым LRC |
| OGG / OPUS | `LYRICS` (комментарий Vorbis) | `LYRICS` с содержимым LRC |

## Sidecar-файл .lrc

Когда доступны синхронизированные тексты, Downtify также сохраняет файл `.lrc`. По умолчанию он лежит **рядом с аудио** с тем же базовым именем. В **Настройки → Теги и тексты** это можно выключить и выбрать вместо этого **папку текстов** (по умолчанию `/data/lyrics`). Эта папка должна быть **вне** `/downloads`, дерева slskd и любых дополнительных музыкальных папок — относительный путь аудио воссоздаётся внутри неё (`Artist/Album/track.lrc`). Медиаплееры, которые читают внешние тексты (и [встроенный плеер](player.md#now-playing)), по-прежнему подхватывают sidecar-файл. Изменение этой настройки и запуск **Синхронизации** на дополнительной папке копирует существующие файлы `.lrc` в новое место; исходный файл удаляется, когда это дерево доступно для записи, и остаётся на месте при монтировании только для чтения. Файл `.lrc` записывается, даже если тексты уже встроены в теги.

Удаление трека со страницы Библиотеки удаляет `.lrc` (рядом с файлом и в выделенной папке) вместе с аудио, поэтому тексты никогда не остаются осиротевшим файлом.

## Когда ничего не найдено

Если ни у одного провайдера нет песни, загрузка продолжается как обычно — аудиофайл сохраняется без текстов, и ошибка не возникает.
