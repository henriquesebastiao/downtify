# Тексты

Downtify ищет тексты во время загрузки трека и встраивает их в файл, плюс сохраняет sidecar-файл `.lrc`, когда они синхронизированы по времени.

## Включение текстов

Тексты **включены по умолчанию**. Выключить их можно в **Настройки → Теги и тексты → Скачивать тексты**.

## Провайдеры и порядок резервных вариантов

Каталоги различаются: песня, о которой один провайдер никогда не слышал, часто есть у другого. Поэтому Downtify хранит упорядоченный список провайдеров и пробует их по одному, останавливаясь на первом, у которого что-то есть.

| Провайдер | Тексты | Примечания |
|----------|--------|-------|
| **[LRCLIB](https://lrclib.net)** | Обычные и синхронизированные по времени | Бесплатная база сообщества, без ключа. Сопоставление по названию, основному артисту, альбому и длительности; если так не находится ничего синхронизированного, пробуется и его поиск, и совпадение принимается по названию, артисту и длительности (в пределах нескольких секунд). |
| **NetEase Cloud Music** | Обычно синхронизированные по времени | Большой каталог, силён в азиатских релизах и часто в западных тоже. Сопоставление по названию, артисту и длительности; совпадение, у которого артист написан иначе (например, традиционный и упрощённый китайский), принимается только когда совпадают и название, и длительность. |
| **Kugou Music** | Синхронизированные по времени | Большой каталог, силён в китайских релизах и со множеством западных. Сопоставление как у NetEase; строка с названием и авторы песни в начале отбрасываются. |

В **Настройки → Теги и тексты → Провайдеры** можно перетащить провайдеров в нужный порядок или использовать стрелки и выключить любого из них. Хотя бы один остаётся включённым; чтобы совсем перестать искать тексты, используйте переключатель **Скачивать тексты**. Провайдер, добавленный в обновлении, начинает выключенным, если вы уже сохранили свой список: включите его там.

### Только синхронизированные тексты

**Настройки → Теги и тексты → Только синхронизированные тексты** (по умолчанию выключено) оставляет только тексты с временными метками: провайдер, у которого для песни есть лишь обычный текст, считается не нашедшим ничего, и спрашивается следующий. [Обновление библиотеки](library-upgrade.md) тогда также считает трек только с обычным текстом треком без текста. Синхронизированный текст, который у файла уже есть, учитывается в любом случае: sidecar-файл `.lrc`, текст с временными метками во встроенных тегах или фрейм ID3 `SYLT` (такие бывают у файлов из других приложений). При включённой настройке синхронизированный текст, найденный Downtify для трека, заменяет обычный — в sidecar-файле `.lrc` и в собственном теге текста файла, так что плееры, читающие только теги, тоже показывают его синхронизированным. Сканирование также сообщает, у скольких треков без текста был только обычный.

### Поиск текстов для треков без них

**Библиотека → Обновление библиотеки → Найти треки и тексты** находит в библиотеке треки без текста и сразу ищет для них тексты, с индикатором прогресса. По завершении сообщается, сколько треков получили текст, для скольких ничего не нашлось и сколько завершились ошибкой. См. [Обновление библиотеки](library-upgrade.md#while-it-runs).

::: info А как же Genius, Musixmatch и AZLyrics?
Они недоступны, и Downtify больше их не предлагает:

- **AZLyrics** запрещает стороннее использование своих текстов прямо на странице.
- Настольный API **Musixmatch** отвечает пустым токеном, если у вас нет учётных данных, которые он не выдаёт приложениям.
- `robots.txt` у **Genius** запрещает конечную точку поиска, нужную для нахождения страницы песни.

Сохранённые настройки, где они ещё указаны, продолжают работать: имена игнорируются, а список, в котором больше ничего не осталось, откатывается к провайдерам по умолчанию.
:::

## Пропуск провайдеров, у которых ничего не было

После поиска Downtify записывает для каждой песни, какие провайдеры ответили, а какие вернулись пустыми, в `downtify_library.db` в `/data` (на бэкенде SQLite по умолчанию; с PostgreSQL — в базе PostgreSQL).

Провайдера, у которого ничего не было для песни, больше не спрашивают о ней **30 дней**, поэтому повторные загрузки и большие проходы по библиотеке не повторяют одни и те же неудачные поиски. После этого его пробуют снова, поскольку каталоги растут. Провайдер, у которого тексты *были*, никогда не пропускается, поэтому заново скачанный файл их получает.

## Встраивание

| Формат | Тег обычных текстов | Тег синхронизированных текстов |
|--------|-----------------|------------------|
| MP3 | `USLT` (ID3) | `USLT` с временными метками |
| FLAC | `LYRICS` (комментарий Vorbis) | `LYRICS` с содержимым LRC |
| M4A | `©lyr` | `©lyr` с содержимым LRC |
| OGG / OPUS | `LYRICS` (комментарий Vorbis) | `LYRICS` с содержимым LRC |

## Sidecar-файл .lrc

Когда доступны синхронизированные тексты, Downtify также сохраняет файл `.lrc`. По умолчанию он лежит **рядом с аудио** с тем же базовым именем. В **Настройки → Теги и тексты** это можно выключить и выбрать вместо этого **папку текстов** (по умолчанию `/data/lyrics`). Эта папка должна быть **вне** `/downloads`, дерева slskd и любых дополнительных музыкальных папок — относительный путь аудио воссоздаётся внутри неё (`Artist/Album/track.lrc`). Медиаплееры, которые читают внешние тексты (и [встроенный плеер](player.md#now-playing)), по-прежнему подхватывают sidecar-файл. Изменение этой настройки и запуск **Синхронизации** на дополнительной папке копирует существующие файлы `.lrc` в новое место; исходный файл удаляется, когда это дерево доступно для записи, и остаётся на месте при монтировании только для чтения. Файл `.lrc` записывается, даже если тексты уже встроены в теги.

Удаление трека со страницы Библиотеки удаляет `.lrc` (рядом с файлом и в выделенной папке) вместе с аудио, поэтому тексты никогда не остаются осиротевшим файлом.

## Настройка синхронизации

Найденный в интернете текст иногда немного опережает скачанное аудио или отстаёт от него: другая версия песни, более длинное вступление. Чтобы исправить песню, включите её, откройте **Играет сейчас → Текст песни** и нажмите кнопку с секундомером в правом верхнем углу текста — **Настроить синхронизацию текста**:

- **−** показывает текст раньше, а **+** позже, на десятую долю секунды за нажатие, до минуты в каждую сторону. Текст сразу следует новому времени, так что можно подбирать его прямо во время воспроизведения.
- **Сохранить** записывает изменение в файлы песни; **Сбросить** возвращает сохранённое время.

При сохранении переписываются сами метки времени — в файле `.lrc` и, если в тегах файла есть синхронизированный текст, в них тоже (включая кадры `SYLT` в MP3). Поэтому исправление видно и в других плеерах, которые читают `.lrc` или теги, и в приложениях. Файл только для чтения сохраняет свои теги; меняется только `.lrc`. Строка `[offset:N]` в `.lrc` при сохранении учитывается в метках времени, а плеер Downtify учитывает её и до этого.

Кнопка появляется только у песен библиотеки с синхронизированным текстом. Настроить его может любой вошедший пользователь; изменение видно в [журнале активности](users.md#activity) как **Настроена синхронизация текстов**. Endpoint — [`POST /api/library/lyrics/offset`](../api-reference.md#post-apilibrarylyricsoffset).

## Когда ничего не найдено

Если ни у одного провайдера нет песни, загрузка продолжается как обычно — аудиофайл сохраняется без текстов, и ошибка не возникает.
