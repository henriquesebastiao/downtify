# Импорт библиотеки (CSV)

Уже экспортировали свою библиотеку из другого сервиса? Импортируйте CSV и поставьте в очередь на загрузку все треки разом, вместо того чтобы заново добавлять песни по одной.

## Поддерживаемые экспортёры

| Инструмент | Примечания |
|------|-------|
| [Soundiiz](https://soundiiz.com/) | |
| [TuneMyMusic](https://www.tunemymusic.com/) | |
| [Exportify](https://github.com/watsonbox/exportify) | |

Downtify не встраивает жёстко точную схему столбцов какого-либо одного инструмента. Вместо этого он сопоставляет строку заголовка CSV без учёта регистра с набором известных псевдонимов (`Title` / `Track` / `Track Title` / `Track Name` / `Song` / …, `Artist` / `Artists` / `Artist Name` / `Artist Name(s)` / … и `Album` / `Album Name` / `Album Title` / …), поэтому экспорт любого из трёх — или самодельный CSV с теми же именами столбцов — работает без переименования чего-либо.

Название и артист обязательны. Альбом читается, когда есть, и сохраняется как имя альбома трека (Очередь, подбор аудио и теги файла). Другие столбцы, которые включают некоторые экспортёры (ISRC, URI трека Spotify, длительность), игнорируются. Каждая строка распознаётся так же, как поиск свободным текстом, через YouTube Music.

## Как импортировать

1. На главной странице нажмите **Импортировать CSV библиотеки** под строкой поиска.
2. Выберите свой экспортированный файл `.csv`.

Файл целиком читается в вашем браузере и отправляется на сервер как обычный текст — больше его не загружается никуда. Downtify разбирает его, ставит в очередь каждую распознанную строку, и вы попадёте в Очередь загрузки, где прогресс поступает по WebSocket точно как при любой другой пакетной загрузке.

Импортированный пакет получает имя по файлу (имя без `.csv`) и, как любая другая загрузка плейлиста, получает [файл M3U](m3u-export.md), если тот параметр включён.

## Ограничения и обработка ошибок

- Не более **2 000 строк** на файл. Большие экспорты разделите на несколько файлов.
- Строки без названия или артиста молча пропускаются. Отсутствующий столбец альбома или пустая ячейка альбома — не проблема: YouTube Music может позже всё же заполнить альбом.
- Несколько артистов в одной ячейке (разделённые `,` или `;`) разбиваются в список.
- Если в заголовке нет распознаваемого столбца названия/артиста, весь импорт сразу отклоняется с ошибкой, называющей найденные им столбцы — в очередь не ставится ничего.

## Как обойти лимиты запросов

Импорт большой библиотеки ставит в очередь много поисков и загрузок YouTube Music за короткое время — лёгкий путь получить ограничение частоты. Перед импортом большого файла подумайте о снижении **[Параллельных загрузок](download-settings.md#parallel-downloads)** и включении **[Задержки между загрузками](download-settings.md#delay-between-downloads)** в Настройках.
