# Куки YouTube

Downtify берёт аудио с YouTube. Чаще всего это работает анонимно — но не всегда:

- **Explicit-треки и треки с возрастным ограничением.** YouTube отдаёт их только вошедшему взрослому аккаунту. Без куки загрузка завершается ошибкой.
- **Проверки на ботов.** На IP-адресах датацентров (VPS, некоторые VPN) YouTube периодически отвечает «Sign in to confirm you're not a bot» вместо аудио.

Передача `cookies.txt` исправляет и то и другое: тогда yt-dlp общается с YouTube так же, как ваш вошедший сеанс браузера.

## Загрузка cookies.txt (рекомендуется)

1. Установите расширение для экспорта куки: [Get cookies.txt LOCALLY](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc) (Chrome/Edge) или [cookies.txt](https://addons.mozilla.org/en-US/firefox/addon/cookies-txt/) (Firefox)
2. Откройте `youtube.com`, **войдя в свой аккаунт Google**, и экспортируйте куки для этого сайта — файл должен быть в формате **Netscape**
3. В Downtify откройте **Настройки** (⚙️) → **Куки YouTube** → **Загрузить cookies.txt**

Файл проверяется при загрузке — файл, который не является cookie-файлом Netscape, сразу отклоняется, а не молча ломает все последующие загрузки. Если в нём нет куки `youtube.com` или `google.com`, вы получите предупреждение, поскольку обычно это значит, что файл экспортирован из не той вкладки.

После загрузки его можно **заменить** (загрузить другой файл) или **удалить** на том же экране.

::: tip Это путь, работающий на любой платформе
Загрузка через веб-интерфейс не требует bind-монтирований, путей к файлам и оболочки — именно поэтому она работает в Docker Desktop для Windows, где смонтировать `cookies.txt` в контейнер до ужаса неудобно.
:::

## Где он хранится

Загруженный файл записывается в `cookies.txt` внутри каталога данных Downtify (по умолчанию `/data`) — тот же том, где лежат `settings.json` и база данных Монитора плейлистов. Поэтому он **переживает обновления контейнера**: вытягивание нового образа и пересоздание контейнера сохраняют ваши куки, пока `/data` остаётся именованным томом или примонтированным каталогом.

## Использование переменной окружения вместо этого

Существовавшая ранее переменная [`DOWNTIFY_COOKIES_FILE`](../getting-started/environment-variables.md#anti-bot-youtube) всё ещё работает и **имеет приоритет**:

```yaml
services:
  downtify:
    volumes:
      - ./cookies.txt:/cookies.txt:ro
    environment:
      - DOWNTIFY_COOKIES_FILE=/cookies.txt
```

Когда она задана, экран настроек показывает раздел куки как заблокированный и отказывает в загрузке и удалении — этим развёртыванием управляет та конфигурация, и Downtify не должен перезаписывать файл, которым не управляет. Уберите переменную (и пересоздайте контейнер), чтобы управлять куки через веб-интерфейс.

`DOWNTIFY_COOKIES_FROM_BROWSER` читает куки прямо из профиля браузера, но для этого хранилище куки браузера должно быть доступно *внутри* контейнера, поэтому в Docker это редко применимо.

## Чтобы они продолжали работать

- Куки истекают. Если загрузки треков с возрастным ограничением снова начнут срываться, экспортируйте свежий файл и загрузите его как замену.
- Экспорт из **приватного окна / окна инкогнито**, которое затем закрывается, даёт более долгоживущий сеанс, поскольку закрытие обычного окна может сделать экспортированный сеанс недействительным.
- В некоторых регионах перед тем, как YouTube вообще станет отдавать контент с возрастным ограничением, требуется полная проверка личности на аккаунте Google. Одного входа в аккаунт не всегда достаточно.

::: warning Обращайтесь с файлом как с паролем
`cookies.txt` содержит действующие токены сеанса вашего аккаунта Google. Тот, кто может его прочитать, может действовать от вашего имени на YouTube. Downtify хранит его с правами только для владельца там, где файловая система это поддерживает, и никогда не выдаёт его содержимое через API — только то, настроен ли файл, его размер и когда он менялся. Используйте одноразовый аккаунт Google, если не хотите рисковать основным.
:::
