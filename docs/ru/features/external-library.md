# Существующие музыкальные папки

Библиотека Downtify собирается из скачанных самим Downtify файлов — плюс любые **дополнительные папки**, на которые вы его нацелите. Эти папки не копируются в `/downloads`. Downtify читает теги каждого файла (название, артиста, альбом, номер трека, год), пропускает песни, которые у вас уже есть, и раскладывает остальные под подходящим артистом в Библиотеке и плеере.

## Добавление папок

1. Смонтируйте папку с хоста в контейнер (Docker). Путь, который вы вводите в Настройках, находится **внутри контейнера** — то же правило, что для [папки загрузок slskd](slskd-navidrome.md).
2. Откройте **Настройки → Библиотека**.
3. Под заголовком **Существующие музыкальные папки** добавьте один или несколько путей (например, `/music/collection`). Поле предлагает каталоги по мере ввода.
4. **Сохранить**, если хотите пока оставить без синхронизации, или нажмите **Синхронизировать папки** — список сохранится, и сканирование начнётся сразу.

```yaml
services:
  downtify:
    volumes:
      - ./downloads:/downloads
      - /path/on/host/to/mp3s:/music/collection
      - downtify_data:/data
```

Тогда папка в Настройках — это `/music/collection`.

::: warning Файлы остаются на месте
Синхронизация не копирует файлы в `/downloads`. Когда папка доступна для записи, Downtify **записывает** в эти файлы те же дополнения, что и при скачивании: тексты (и sidecar-файл `.lrc` — рядом с файлом или в папке, выбранной в Настройках), обложку, если у файла её нет, и жанр из iTunes, когда удаётся. Последующая синхронизация допишет отсутствующий sidecar-файл, даже если тексты уже в тегах, и **перенесёт** существующий `.lrc` в то место, которое выбрано в Настройках на этот момент, когда исходный файл доступен для записи. Удаление трека из Библиотеки по-прежнему удаляет этот файл с диска.
:::

::: tip Монтирования только для чтения
Смонтируйте коллекцию `:ro`, если не хотите, чтобы Downtify переписывал MP3. Синхронизация всё равно индексирует их. Положите файлы `.lrc` в [папку текстов](lyrics.md#sidecar-lrc-file) (выключите **Держать .lrc рядом с аудио**). Недостающие обложки сохраняются под `/data/cover_cache` (эндпоинт обложек Библиотеки), а не в MP3. Жанр iTunes хранится в базе метаданных библиотеки Downtify, а не в файле. Файл `.lrc`, уже лежащий рядом с файлом «только для чтения», **копируется** в папку текстов, а оригинал остаётся на месте.
:::

## Что делает синхронизация

1. Обходит каждую настроенную папку в поисках воспроизводимого аудио (те же форматы, что во всей остальной библиотеке: MP3, M4A, FLAC, OGG, WAV, AAC, OPUS).
2. Читает встроенные теги. Файл без названия/артиста откатывается к `Artist - Title` из имени файла, как и остальные строки библиотеки.
3. **Пропускает** файл, когда эта песня уже в библиотеке (тот же артист + название, и длина в пределах нескольких секунд, когда известно обоим) — был ли он скачан Downtify или пришёл из другой дополнительной папки.
4. **Сопоставляет артистов** с уже имеющимися в библиотеке названиями (`The Beatles` и `Beatles` становятся одним артистом). Названия, не совпавшие с известным артистом, появляются новым артистом. Новые артисты становятся в ту же очередь на заполнение профиля (фото/биография, когда эти настройки включены), что и готовая загрузка.
5. **Пишет теги, как при скачивании**, когда папка доступна для записи. Для каждого импортированного трека используются те же провайдеры текстов, поиск обложки (только когда в файле нет обложки) и поиск жанра в iTunes, как при скачивании. Тексты пишутся в файл; sidecar-файл `.lrc` кладётся рядом с аудио или в выбранную вами в Настройках [папку текстов](lyrics.md#sidecar-lrc-file). Обложка и жанр следуют [Настройкам загрузок](download-settings.md) (`download_cover_art`, `download_lyrics`). На монтировании **только для чтения** MP3 не переписывается: недостающая обложка хранится под `/data/cover_cache`, жанр — в каталоге библиотеки, а файлы `.lrc` идут в папку текстов, если вы её выбрали. Запросы идут порциями размером **Параллельные загрузки**; настройка **Пауза между поисками при синхронизации** в Настройки → Загрузки и файлы делает паузу между этими порциями, чтобы большие папки не упирались в лимиты провайдеров.
6. Инвалидирует кэш путей библиотеки, так что страница Библиотеки и плеер видят результат, не дожидаясь обычного короткого TTL сканирования.

Синхронизация идёт **в фоне**. Настройки можно покинуть; вернувшись, пока она ещё работает, увидите, что всё ещё идёт синхронизация. Когда она завершится, Настройки покажут **журнал последней синхронизации** (импортировано / дубликат / ошибка, плюс заметки о текстах/обложках).

Запустите **Синхронизировать папки** снова, когда положите в эти папки новые файлы. Сохранение списка папок без синхронизации всё равно включит их в ближайшее сканирование библиотеки (около минуты, либо следующая загрузка/удаление).

Удаление папки из списка её **отвязывает**: эти треки уходят из Библиотеки и плеера, а созданные Downtify дополнения (sidecar-файлы `.lrc`, кэшированные обложки) удаляются. Аудиофайлы на диске остаются на месте.

Папки, которых не существует или которые не читаются, сообщаются после синхронизации; остальные всё равно сканируются.

## Пути в библиотеке

Файлы дополнительных папок используют виртуальный путь `ext/<id>/…` (id — хэш пути папки, поэтому список можно пересортировать). Плеер и `GET /media/…` используют этот путь, как `slskd/…` для оставленных на месте файлов Soulseek.

Папка, которая уже лежит **внутри** `/downloads` (или папки-источника slskd), здесь игнорируется — это дерево и так библиотека.

## API

| Метод | Путь                          | Описание                                                                      |
| ------ | ----------------------------- | -------------------------------------------------------------------------------- |
| `POST` | `/api/library/external/sync`  | Запустить фоновое сканирование. Необязательное тело `{folders: ["/path", …]}` сначала сохраняется. |
| `GET`  | `/api/library/external/sync`  | Текущая задача или последний завершившийся журнал.                                |
| `POST` | `/api/library/external/unmap` | Отвязать одну папку от библиотеки, не удаляя аудио.                               |

Формат ответа см. в [справочнике API](../api-reference.md#post-apilibraryexternalsync).

## Основная папка библиотеки

Выберите **Настройки → Библиотека → Основная папка библиотеки**, чтобы предпочесть одну из зарегистрированных дополнительных папок. Значение по умолчанию сохраняет прежнее поведение. Требуется совпадение артиста, полного названия (включая версию) и альбома; неизвестные метаданные не прячут другой файл. Выбранный источник может представлять запись, в другой копии которой есть вступления или концовки из клипа.

Это настройка отображения, а не перенос данных. Исходные файлы, сохранённые пути плейлистов, владение, отметки «нравится» и правила видимости не переписываются и не удаляются. Значки плейлистов объединяются на показанном представителе; явно сохранённые плейлисты по-прежнему играют свои исходные пути. Разные альбомы и версии в выбранной папке остаются раздельными. Пустая или недоступная папка откатывается к остальной библиотеке. Её удаление сбрасывает настройку.
