# Import playlists from added folders

Library → Playlists → Import folder playlists scans configured extra music
folders for M3U and UTF-8 M3U8 files. Preview the available, missing and repeated
entries, select the desired playlists, and explicitly add the selection.
Generic `playlist.m3u8` files use their containing folder's name, as commonly
generated by Deemix. Relative entries are resolved from the playlist's folder.

Imports create private editable Downtify playlists referencing the existing
audio. They never modify source playlists or audio, never move external files,
and never import all candidates automatically. Repeating an import for the same
account reuses the existing imported playlist. Different accounts get independent
copies and colliding names receive a suffix. Empty files remain visible in the
preview; unavailable entries are excluded from the resulting playlist.

Only existing audio inside configured music roots is accepted. URLs and paths
escaping those roots are excluded. A changed source must be previewed again.
Limits: 2 MiB and 20,000 lines per file, 500 candidates / 100,000 scanned entries,
and 50 selected playlists per request. Offline folders and scan limits are shown.
